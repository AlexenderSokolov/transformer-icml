## 4. Complete finite two-clock source

Hereafter K>=22 and a=floor((K-6)/4)>=4. Choose four disjoint alphabets of size a,

    A={0,...,a-1}, B={a,...,2a-1},
    C={2a,...,3a-1}, D={3a,...,4a-1},

They fit since 4a+6<=K. Unused labels have zero mass on the reachable source.

Choose a word w_0,...,w_(a^2) over {0,...,a-1}, starting and ending at 0, whose a^2 adjacent ordered pairs are all distinct. An explicit finite rule is the lexicographically first Euler circuit, starting at 0, in the directed complete graph on a symbols, loops included. Existence needs no external theorem: each vertex has equal in/out degree; follow unused outgoing edges until returning to the start (balance prevents getting stuck elsewhere), and splice in unused closed walks at visited vertices until all edges are used. Strong connectivity ensures an unused edge remains reachable from the visited walk until all edges are covered. At most a^2 edges are consumed. Lexicographic ordering among the finite circuits makes the rule unique. This is a finite mathematical clock specification, not a compiler for F.

Let w^A=w and w^B=w+a coordinatewise; both have length a^2+1. Fix integer m>=2, L=a^2+5, M=(m+1)L-2 and epsilon=1/m. Initialize mu=delta_(p0,q0). Define the following transition rows theta_(x,y), each describing the next emitted symbol.

For stage s=0 use (p_s,q_s,w^s)=(p0,q0,w^A), and for s=1 use (p1,q1,w^B):

    (p_s,q_s) -> w^s_0;
    (q_s,w^s_0) -> w^s_1;
    (w^s_i,w^s_(i+1)) -> w^s_(i+2), 0<=i<=a^2-2.

The final internal A pair instead exits as

    (w^A_(a^2-1),w^A_(a^2)) -> eta;
    (w^A_(a^2),eta) -> zeta;
    (eta,zeta) -> p0 with probability 1-epsilon,
                   p1 with probability epsilon;
    (zeta,p0) -> q0; (zeta,p1) -> q1.

The final internal B pair instead exits as

    (w^B_(a^2-1),w^B_(a^2)) -> a uniform element c of C;
    (w^B_(a^2),c) -> a uniform element d of D, for each c in C;
    (c,d) -> p1 for every (c,d) in C x D;
    (d,p1) -> q1 for every d in D.

All displayed arrows not bearing probabilities are deterministic. Every unspecified pair row is delta_0. Distinct types of rows use disjoint marker/alphabet positions. Within either internal clock every ordered pair appears once, including the last pair whose exit rule replaces, rather than duplicates, an internal successor. Hence no row has conflicting instructions, every row is a probability vector, and all transitions obey the overlap shift (x,y)->(y,z). The table is fixed within the experiment. The parameter m is a public-horizon source choice, not a time-dependent transition rule.

At the boundary pair (p0,q0), one A block emits

    w^A_0,...,w^A_(a^2), eta,zeta,p0,q0       (stay)
or  w^A_0,...,w^A_(a^2), eta,zeta,p1,q1       (activate).

At (p1,q1), each B block emits

with independently uniform c,d. Each block has exactly L emitted symbols/transitions. Activation is irreversible. The common phase L-2 is the gate pair (eta,zeta) in A and the query pair (c,d) in B. Thus the clock lengths and bridge length agree exactly, not only in order.
