## 1. 对象、输入与信息权限

K≥2，N≥3，M=N−2，β>0 固定，γ=exp(β)−1。
对 j=3,…,N，S_j=(X_{j−2},X_{j−1})，Y_j=X_j。
记 c_j=e_{S_j}∈R^{K²}，v_j=e_{Y_j}∈R^K，
a_s=M^{-1}Σ_j 1{S_j=s}v_j，u_s=M^{-1}Σ_j1{S_j=s}。
当 n_s>0 时 a_s=u_s p̂_s；当 n_s=0 时 a_s=0，不定义除以零的 p̂_s。
记 r=M^{-1}Σ_jv_j，v⁰=K^{-1}1。

原始输入是 token one-hot x_i=e_{X_i}。允许两个固定零起始槽（非训练数据），以及一个位于 N+1 的预测槽，其原始 token 通道为零。
长度 N 是网络族索引；λ_N=1/M 可作为已声明参数，不声称从比例免费恢复次数。
真实预测槽的情境从 X_{N−1},X_N 复制。为定义 max_s 风险，Pi_N(H;s) 是同一读出接受显式情境 s 的评估；一次调用只有一个查询，并非免费同时生成 K² 个输出。
若改用 K² 个查询同时输出整表，须额外计 K² 个预测槽及对应注意力工作量。

本版本采用 D3 明许的固定局部前驱掩码，不把精确复制归功于有限分差软定位。所有计算都是前向构造，不主张参数能由训练找到。

## 2. 真实局部绑定、特征、Q/K/V 与残差

**绑定层。** 两个局部注意力头：第一个在位置 i 只允许访问 i−1，第二个只允许访问 i−2；Q=K=0，V 为原始 token one-hot。
单元素 softmax 权重为 1。输出分别写入原来为零的 a_i,b_i 残差槽，原始 x_i 保持。
负索引或 0 索引指固定零起始槽；这些槽永远不进入全局历史集合。
在历史位置 i=j，a_j=e_{X_{j−1}}，b_j=e_{X_{j−2}}。
在预测槽 i=N+1，a_*=e_{X_N}，b_*=e_{X_{N−1}}。

**情境层。** 对每个 (h,k)∈[K]²，点式 ReLU 生成

    c_i(h,k) = ReLU(b_i(h)+a_i(k)−1).

在精确 one-hot 输入上它等于 e_{(X_{i−2},X_{i−1})}，共 K² 个特征；不使用乘法或测试参数 θ。
历史 value 只取 x_j，不依赖查询。原始 x、复制 a,b 与 c 走独立残差槽；此阶段不使用 LayerNorm/RMSNorm。

**全局汇总层。** 预测槽只允许读 j=3,…,N（固定合法位置掩码，因果）；前两个原始 token、起始槽和预测槽均不进入分母。

1. 匹配头：Q(c_*)=βc_*，K(c_j)=c_j，V_j=x_j。若 API 使用除以 sqrt(D_qk)，将该因子补入 Q 并计参数尺度。
   得分正是 β1{S_j=s}，D_qk=K²，值维度 K，输出记 q_s。
2. 均匀辅助头：Q=K=0，V_j=(x_j,c_j)∈R^{K+K²}。
   输出 (r,μ)，其中 μ_t=M^{-1}Σ_j1{S_j=t}，并非查询相关 value。

两个头分别写入原为零的 q、r、μ 残差槽；预测槽原有情境 c_*、局部 a_*,b_*、类型与长度常量保留。
因此在全局层后，终端读出完整可见的历史摘要为

    Z(H;s)=(q_s,r,μ,c_*,a_*,b_*,length/type/constants).

原始历史行虽然仍存在，但后续只允许终端点式 FFN，没有再次读取历史的 attention；故没有隐蔽 raw-history bypass。
真实末查询时 a_*,b_* 与 c_* 同义；外部固定查询评估时，若也保留末两项，必须照样计入可见表示。
任何后续计算下界必须使用完整 μ 与这些残差，不能只保留 (q_s,r,u_s)。

**频率选择。** 因为 μ_t∈[0,1] 且 c_* 为 one-hot，

    u_s = Σ_t ReLU(μ_t+c_*(t)−1).

这需要 K² 个 ReLU 与一次求和。μ 的聚合误差若逐坐标≤δ_μ，且精确 c_* 保留，先逐坐标 clip_[0,1] 后的选择误差≤δ_μ；不是 K²δ_μ。
若查询 c_* 本身有误差，此结论不能直接使用，见 §6。

**目前可核查的结构成本。** 两个 attention 层，每层最多两个头（总 head-layer 使用数 4）；每头最大 Q/K 维度 K²；最大 value 维度 K²+K。
预备及终端存储槽总宽度 O(K²+K)，情境和选择各 K² 个 ReLU。
原始历史 N 个槽、两个起始槽、一个终端槽；历史的读取工作量随 N 增长，不由常数层数掩盖。
全局有限得分范围 [0,β]，辅助头分数零；局部 singleton 掩码是单独计费的结构许可，不写成有限得分的硬极限。
这些尚不是完整 R：读出逼近宽度、总点式深度、参数尺度及逐操作精度仍须 §7 的编译。

## 3. 有限历史接口及零计数平滑

精确匹配头分母为 M+γn_s；其分子为 Mr+γMa_s，故

    (1+γu_s)q_s − r = γa_s.                         (I)

这个已知恢复恒等式在此只用于检查真实电路，没有单列为新贡献。
取任意 λ>0，定义 oracle **参照**（尚非免费神经 primitive）

    P^λ_s = (a_s+λv⁰)/(u_s+λ)
          = ((1+γu_s)q_s−r+γλv⁰)/(γ(u_s+λ)).       (II)

式 (II) 是带伪计数 Mλ 的条件频率。它属于 simplex；n_s=0 时准确等于 v⁰。
取 λ=λ_N=1/M，P^λ_s=(n_s p̂_s+v⁰)/(n_s+1)（仅在 n_s>0 的式子中使用 p̂_s）。
当 n_s>0，对任意真实条件分布 p_s，

    TV(P^λ_s,p_s) ≤ TV(p̂_s,p_s)+λ/(u_s+λ).         (III)

证明：P^λ 是 p̂_s 与 v⁰ 的凸组合，用 TV 凸性及 TV(v⁰,p̂_s)≤1。
零计数时直接使用 TV(v⁰,p_s)≤1；此处未将零计数风险隐去。
还可在实际读出后另加 σ∈(0,1) 的均匀平滑，使所有输出≥σ/K；其 TV 代价≤σ。
TV 结论不直接推出统一 KL 界。

## 4. 全统计共同扰动的相对频率误差式

设 q̃=q+e_q，r̃=r+e_r，ũ=u+e_u；先将 q̃,r̃ 的各坐标及 ũ clip 到 [0,1]。
坐标裁剪相对真实 [0,1] 值不增误差；此处不假设 q̃,r̃ 各自和为 1。
定义实际代数目标

    G_λ(q̃,r̃,ũ) = ((1+γũ)q̃−r̃+γλv⁰)/(γ(ũ+λ)).

对每个坐标，**精确**有

    G_λ−P^λ = ((γ^{-1}+ũ)e_q−γ^{-1}e_r
                + e_u(q−P^λ))/(ũ+λ).              (IV)

证明：将右分母乘回，使用 (I) 与 (II)，然后把 γe_u P^λ 移到分子。特别地，频率误差的分子是 q−P^λ，不把本来相消的共同统计当成独立自由量。
由于 q,P^λ∈simplex，|q_i−P^λ_i|≤1。当 |e_u|≤(u+λ)/2 时，ũ+λ≥(u+λ)/2，因而

    ||G_λ−P^λ||_∞
      ≤ 2[(1+γ^{-1})δ_q+γ^{-1}δ_r+δ_u]/(u+λ),   (V)

其中 δ_q、δ_r、δ_u 是对应误差上界。不存在由这个正确恒等式必然导出的 u^{-2} 代价。
误差必须是**同一份历史**精确 q,r,u 之后新增的计算误差；统计波动已共同包含在 (I) 中，不再重复按 1/u 放大。

设一个显式 FFN 计算 z，满足 ||z−G_λ||∞≤η。采用欧氏 simplex 投影 Π_Δ，最终输出

    Pi = (1−σ)Π_Δ(z)+σv⁰.

欧氏投影非扩张、||w||₁≤sqrt(K)||w||₂，给出

    TV(Pi,p_s) ≤ TV(P^λ_s,p_s)
                 +(K/2)(||G_λ−P^λ_s||∞+η)+σ.     (VI)

这一确定性接口没有假设样本独立，也不依赖 θ。投影本身的实现和量化误差不能省略。

## 5. 可显式实现的读出候选；不把除法当 primitive

下列是待编译核对的具体选择，不引用万能逼近当成本证明。

1. clipping：ReLU(x)−ReLU(x−1) 精确实现 [0,1] 裁剪。
2. multiplication：以区间上的折线插值 S_h 逼近平方。网格最大步长 h 时 |S_h(t)−t²|≤h²/4。
   用 (S_h(x+y)−S_h(x−y))/4，乘积误差≤h²/8。折线函数用一层 ReLU hinge 展开，宽度与区间长度/h 成正比。
3. reciprocal：在 [λ,1+λ] 对 1/t 作折线插值 R_h。二阶导数绝对值≤2λ^{-3}，插值误差≤h²/(4λ³)。
   要误差≤η_inv，可取 h≤2sqrt(η_inv λ³)；宽度 O(1+λ^{-3/2}η_inv^{-1/2})。
   该成本只是保守充分界，绝不据此宣称深度必要性。
4. 先用 multiplication 算 (γ^{-1}+ũ)q̃，再减 γ^{-1}r̃、加 λv⁰ 得分子；乘以 R_h(ũ+λ)。
   输入界：ũ,q̃_i,r̃_i∈[0,1]，分子绝对值≤1+γ^{-1}+λ，倒数≤λ^{-1}+η_inv；因此第二次乘法有显式有界矩形域。
   两次乘法和倒数的误差须分别分配，不能只说总误差是 η。
5. simplex 投影可用有限 ReLU 电路精确实现：先用 max/min comparators 排序 z 得 z_(1)≥…≥z_(K)，

       τ = max_{1≤j≤K} (Σ_{i≤j} z_(i)−1)/j,
       Π_Δ(z)_i = ReLU(z_i−τ).

   固定 sorting network 或固定 bubble-sort 比较表可用 O(K²) comparators；max/min 各可由 ReLU 与线性映射实现。
   τ 公式证明：令 k 为正输出坐标数，τ=(Σ_{i≤k}z_(i)−1)/k；j<k 时漏掉的坐标都>τ，使其候选≤τ；j>k 时新增坐标≤τ，亦≤τ。
   反过来，取候选最大值可验证 Σ_i ReLU(z_i−τ)=1，再由投影的一阶最优条件得结论。
   数学实数电路的确切 simplex 性成立；有限算术下如何保证**实际**输出严格在 simplex 仍是承重编译缺口，不用“约等于概率”掩盖。

## 6. 输入绑定、分数与查询残差的误差入口

精确固定掩码版本的绑定误差为零。若要替换为软位置选择：
若每个复制头非目标总权重≤ρ，则 one-hot 复制向量每坐标误差≤ρ。
情境 ReLU 的坐标误差≤2ρ，总 l1 误差≤2K²ρ。
在历史与查询情境都被近似、每坐标误差≤ζ 时，

    |β <c̃_*,c̃_j> − β<c_*,c_j>|
      ≤ β(2ζ+K²ζ²),

因为两个真实情境为 one-hot。历史标签 value 仍由原 x_j 提供；若 value 也受扰，其误差另外计。
若两个 logits 向量 l,l' 满足 ||l−l'||∞≤d，则 softmax 概率的 l1 距离≤2d：沿直线积分导数 diag(p)−ppᵀ 的 ∞→1 范数≤2。
故 [0,1] 值的每个聚合坐标误差≤2d（保守界）；再加 value、加法及 softmax 本身的算术误差。
均匀头若 c_j 误差≤ζ，则每个 μ 坐标误差≤ζ，加上聚合算术误差。

查询受扰还影响频率选择：clip 后 μ̃∈[0,1]，若 c̃_* clip 后逐坐标误差≤ζ_*，则通过 ReLU 的 1-Lipschitz 性，

    |Σ_t ReLU(μ̃_t+c̃_*(t)−1)−u_s|
      ≤ δ_μ + K²ζ_*.

再将所选标量 clip_[0,1] 不增此误差。这是对完整查询残差扰动的一项保守界，不能只对 q,r,u 加误差却宣称覆盖了查询误差。
长历史下 soft positional binding 怎样达到 ρ_N→0、所需得分范围/位置编码/参数成本，尚未证明；本单元不以它替换已付费的 singleton 掩码。

## 8. 下一条候选收敛命题（待独立证明）

对每个固定 K≥2、β>0，存在 D3 的 θ 无关网络族，采用上述两层 attention、显式点式读出、λ_N=1/(N−2) 和趋零的终端平滑，满足

    sup_{H∈[K]^N,s} TV(Pi_N(H;s),P^{λ_N}_s) ≤ ε_N,
    ε_N→0，不使用 π_min(θ) 选择 ε_N。

于是每个固定 D1 θ 上 max_s TV(Pi_N(H;s),p_θ(.|s))→0 a.s.，真实末查询 TV 及其期望亦趋零。
只有当 A1 的构造与精度账本闭合后，上述才成为网络定理；目前只是待证命题。

## 普通中文解释

这一单元把“软注意力里能恢复经验概率”落实到了具体数据流：两个局部头复制前两项，一个全局头读软匹配结果，另一个头同时保存背景分布和全部情境频率。所有历史 value 都不偷看当前查询。
新得到的工作推导是：用正伪计数把零出现与正常出现情境放进同一恢复公式，并精确追踪频率误差；频率足够准时，额外计算误差约按 1/(情境占比+平滑) 放大，没有必要凭粗导数制造 1/u²。
它说明稀有情境为何可能对数值精度更敏感，但还不是完整可靠性下界。最紧要的缺桥是把除法与最终合法概率真正编译、计精度，再接上相关随机历史的一致性；现阶段不宣称完成 T1 或有已接纳新事实。
