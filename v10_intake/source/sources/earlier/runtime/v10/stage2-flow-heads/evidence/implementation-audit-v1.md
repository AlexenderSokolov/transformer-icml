# checkpoint-v1 的首次实现审计补记

本补记保留 checkpoint-v1 原文，供Prover/Verifier一并审查，不新增Fact。

1. §6 前向bit-operation表需要澄清且应保守上调：若逐层dense神经矩阵使用普通
   p位乘法而非利用固定系数的移位结构，每次乘加需O(p²)位操作，故L W²项应为
   **O((N+1)K³p⁶)**，而不是原表的O((N+1)K³p⁵)。后一式只可能在逐项证明
   系数运算为O(p)后成立。本checkpoint采用前者作为有效的保守预算。
2. 稀疏非零O(K²+Kp²)只数算术门和投影系数，不能同时声称这是所有连线/保持成本。
   若每层把每个存活寄存器显式布线，尚须O(LW)=O(K²p³)个wire/保持操作；
   每条地址至少O(log(Kp))位。因此稀疏程序总位数用
   O((K²+Kp²)(p+log(N+K)) + K²p³ log(Kp))，或给出共享寄存器/残差实现的严格缩减。
   dense参数表已经覆盖更大成本，不能据稀疏门数许诺神经参数优势。
3. p位有限attention输出到b位寄存器的最后量化本身可贡献2^−b。
   要证明总head误差eta≤2^−b，需要向下游保留b+常数位再量化、或改成eta≤2·2^−b
   并相应调整(★)与日程。不能把最后一次舍入预算再用一次。
4. 完整码必须区分连续理想attention、有限评价后的dyadic寄存器及位提取神经门。
   位提取只在该已声明网格上正确；不能把它作为连续ReLU的精确floor。
   Prover须明确有限评价规范是否构成D5准许的实施模型，再证明门级实现和参数范围。

以上是具体的成本/精度修正条件；不否定§1–5的条件性代数与定位误差推导，
也不意味着C1已完成。之后若采用更省实现，必须按同资源口径重新比较baseline。
