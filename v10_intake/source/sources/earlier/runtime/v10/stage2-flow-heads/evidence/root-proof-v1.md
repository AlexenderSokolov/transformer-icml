## 4. One finite-history event and explicit risk/resource choices

    t_alpha(j)=sqrt((K log 2+log(2K^2 M/alpha))/(2j)), j≥1,
    TV(C_s/n_s,theta_s)≤t_alpha(n_s),
    |C_s(A)/M−u_s theta_s(A)|≤u_s t_alpha(n_s) for every subset A.

The last inequality is zero at n_s=0 without defining C_s/n_s. The subset
union is a proof device, not an exponential feature table. Define

history-dependent weights summing to one, take the corresponding pointwise
bound, then add alpha in expectation. Conditional on E_N=s the bad-event
term is alpha/pi_s; it is not alpha unless separately proved.

## 5. Full resources and the implementation convention

The network convention is finite-evaluated causal attention followed by
pointwise neural Boolean/ReLU circuits as specified in A. Its neural layers
do not count an attention module as an uncharged oracle: that module's
integer work, bit storage, softmax approximation and program are separate
parts of the complete resource vector. Flattening its integer evaluator
into additional ReLU layers requires its actual unrolled depth/holds and
matrices; the smaller hybrid neural-depth figure is not that flattened cost.

For Pi, A's resource functions give L=O(Kp^2), W=O(Kp), six total heads,
max-layer four, D_qk=2K, B_param/B_arith=O(p) per coefficient/register
(the b_word=128p allocation suffices), score cap 2. Dense coefficient slots
are O(K^3p^4), dense parameter bits O(K^3p^5); sparse program/addresses
including identity holds are O(K^2p^4). Working arrays cost O(nKp^2) bits,
with masks/positions O(n^2+n log(n+1)) stored bits. Dense multiply/add work
costs O(nK^3p^6), not the rejected p^5 bound. Finite uncached attention costs
O(n^2(K+p)p^2). Offline finite logs cost O(p^3 log^2(p+1)) and their declared
scratch. Full-score finite caches, when used, are generated/stored/selected
for BOTH D3 and the comparators; cached D3 attention costs O(n^2Kp^2).
The finite exponential at L2+L3 is separately evaluated: it is not the
product of the separately rounded exponential weights at L2 and L3.

The fixed R vector is (L,W,H,D_qk,B_param,B_arith,score_range), with H

encoding), queries/endpoints and public metadata. Total peak memory adds
the chosen stored program/parameters, stored data and working buffers;

## 10. 普通话交接与仍未解决的问题

本阶段的结论是一个带有负面比较结果的机制分类。两个逐项匹配头确实
能够配合边缘统计和首尾校正恢复条件频率；四个统计头之外还要付费使用
两个局部复制头。真正的历史末尾必须保留。实现不需要知道未知转移表，
同一精度日程能处理一般不均匀的严格正二阶规律，并保证实际末尾预测收敛。

线性字母通道不等于整张神经网络只花线性资源。精度位、乘除、舍入、保持
连线、参数、掩码和缓冲区都已分别收费。有限样本误差还取决于情境出现次数；
归一化因子稳定，不能消除稀有情境最后条件化时的敏感性。末尾情境来自
同一条历史，条件终点坏事件概率必须除以该情境的平稳概率。

三种付费计数舍入方案在共同精度下可以输出逐位相同的结果，但原始差分
读出不因此等同于它们。二元情形，一个强直接计数基线能装进原始实现的
完整实际预算。这阻止宣称该机制普遍更省资源；一般字母表只得到明确取舍，
没有所有算法之间的最优资源边界。并行版本和二元串行预算证明已分开。

可靠性结论也有具体位置：统计汇总后的网格主寄存器在分发副本前受扰动，
复制、查询、实际末尾和后续算术保持准确。小扰动有可靠区；指定P2攻击
可让原差分读出失败。同一未知二阶XOR子族上，未坏P1支持另一个付费读出，
所以不能说所有读出都失败。有限见证的干净/攻击/P1期望风险分别小于.021、
大于.10、小于.032；电路和样本规模很大，说明可实现性而非实用速度。

逐项匹配、差分、包含排除和借助长度恢复计数已有直接先例，本阶段不把
它们重新命名为创新。仍未解决的母问题包括：强算法可自由重新分配预算时的
紧资源边界、训练是否能找到这些电路、更广位置和类型的故障、尖锐非均匀
统计率与log-loss，以及独立于既有文献的发表级中心成果。它们不被本阶段
声明为已证明。根证明须经现有独立网关；即使接纳，Lead仍须最终审计及
阶段交接，不能宣布母问题完成。
