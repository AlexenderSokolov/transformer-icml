## 4. A finite phase set with uniform length and component count

Put rho=1/1000 and alpha=lambda-floor(lambda). On 0<=r<=1/3 define

    q_alpha(r)={3r-2alpha}, H_alpha(r)=q_alpha(r)-2r,

    integral_0^(1/3) q_alpha(r) dr=1/6,

    1/18<=m+(1/3-m)/12=1/36+11m/12,
    m>=1/33.                                              (4.2)

    |E|>=1/33-5rho/3=63/2200>1/40.                         (4.3)

No infinite set of hidden components is used.

Define for a real w

    r={lambda-w}, q_alpha(r)={lambda-3w}.                   (4.4)
