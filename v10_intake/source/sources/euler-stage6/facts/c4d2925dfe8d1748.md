## 4. Complete finite two-clock source

Hereafter K>=22 and a=floor((K-6)/4)>=4. Choose four disjoint alphabets of size a,

    A={0,...,a-1}, B={a,...,2a-1},
    C={2a,...,3a-1}, D={3a,...,4a-1},

and six distinct markers

    p0=4a, q0=4a+1, p1=4a+2, q1=4a+3, eta=4a+4, zeta=4a+5.

They fit since 4a+6<=K. Unused labels have zero mass on the reachable source.

Choose a word w_0,...,w_(a^2) over {0,...,a-1}, starting and ending at 0, whose a^2 adjacent ordered pairs are all distinct. An explicit finite rule is the lexicographically first Euler circuit, starting at 0, in the directed complete graph on a symbols, loops included. Existence needs no external theorem: each vertex has equal in/out degree; follow unused outgoing edges until returning to the start (balance prevents getting stuck elsewhere), and splice in unused closed walks at visited vertices until all edges are used. Strong connectivity ensures an unused edge remains reachable from the visited walk until all edges are covered. At most a^2 edges are consumed. Lexicographic ordering among the finite circuits makes the rule unique. This is a finite mathematical clock specification, not a compiler for F.

Let w^A=w and w^B=w+a coordinatewise; both have length a^2+1. Fix integer m>=2, L=a^2+5, M=(m+1)L-2 and epsilon=1/m. Initialize mu=delta_(p0,q0). Define the following transition rows theta_(x,y), each describing the next emitted symbol.

For stage s=0 use (p_s,q_s,w^s)=(p0,q0,w^A), and for s=1 use (p1,q1,w^B):

    (p_s,q_s) -> w^s_0;
    (q_s,w^s_0) -> w^s_1;
    (w^s_i,w^s_(i+1)) -> w^s_(i+2), 0<=i<=a^2-2.

The final internal A pair instead exits as

    (w^A_(a^2-1),w^A_(a^2)) -> eta;
    (w^A_(a^2),eta) -> zeta;
    (eta,zeta) -> p0 with probability 1-epsilon,
                   p1 with probability epsilon;
    (zeta,p0) -> q0; (zeta,p1) -> q1.

The final internal B pair instead exits as

    (w^B_(a^2-1),w^B_(a^2)) -> a uniform element c of C;
    (w^B_(a^2),c) -> a uniform element d of D, for each c in C;
    (c,d) -> p1 for every (c,d) in C x D;
    (d,p1) -> q1 for every d in D.

All displayed arrows not bearing probabilities are deterministic. Every unspecified pair row is delta_0. Distinct types of rows use disjoint marker/alphabet positions. Within either internal clock every ordered pair appears once, including the last pair whose exit rule replaces, rather than duplicates, an internal successor. Hence no row has conflicting instructions, every row is a probability vector, and all transitions obey the overlap shift (x,y)->(y,z). The table is fixed within the experiment. The parameter m is a public-horizon source choice, not a time-dependent transition rule.

At the boundary pair (p0,q0), one A block emits

    w^A_0,...,w^A_(a^2), eta,zeta,p0,q0       (stay)
or  w^A_0,...,w^A_(a^2), eta,zeta,p1,q1       (activate).

At (p1,q1), each B block emits

    w^B_0,...,w^B_(a^2), c,d,p1,q1,

with independently uniform c,d. Each block has exactly L emitted symbols/transitions. Activation is irreversible. The common phase L-2 is the gate pair (eta,zeta) in A and the query pair (c,d) in B. Thus the clock lengths and bridge length agree exactly, not only in order.

At time M=mL+(L-2), if activation occurred in one of the first m complete A blocks, the actual pair is a fresh (c,d) in C x D. Its true next-symbol law is delta_(p1). The query's own departure is at time M and is not included among the M observed departures.

Let j in {0,...,m-1} be the number of complete B blocks before the terminal partial B block. Activation in A block index m-j-1 gives this j with probability

    p_j=(1/m)(1-1/m)^(m-j-1)>=1/(4m).                  (4.1)

Indeed ln(1-1/m)>=-1/(m-1), so the power is at least e^-1>1/4. Conditional on this event, the j previous query pairs and the current terminal pair are iid uniform on C x D. This follows directly from the finite Markov path probabilities: each block's two choices contribute exactly a^-2, independently of all previous choices; each specified sequence of the j previous query choices and the current query yields a unique full history, whose exact unconditional probability is p_j a^(-2(j+1)). It is not an iid assertion conditioned on a random visit count.

For a realized terminal pair (c_r,d_s), let R_r count its first-coordinate matches among those j previous pairs, C_s its second-coordinate matches, and J their intersections. Then, conditional on j and this terminal pair,

    R_r~Bin(j,1/a), C_s~Bin(j,1/a), J~Bin(j,1/a^2).       (4.2)

These three counts can be dependent. Every previous visit to the actual query row emitted p1, so the true count vector has C_(p1)=J and all other coordinates zero. No A pair or B clock/connector pair belongs to C x D. This proves that J is exactly the original same-trajectory departure count.

Here min(1,z/4096)>=min(1,z)/4096 pays the embedding constant. This proves (OCC) from a complete legal source, without reversing UC. ## 6. Joint four-head identities and a positive phase set

Use the original q computation in actual mode, with terminal query (c_r,d_s).     D=(M+1, M+1+R_r, M+1+C_s, M+1+R_r+C_s+J).            (6.1)

We now prove a phase fact uniform in arbitrary real lambda; let alpha={lambda}. For a real w write

    r(w)={lambda-a w}, z(w)={lambda-(2a+1)w},
    H(w)=z(w)-2r(w).

    {((2a+1)/a)r + t/a -(1+1/a)lambda},

where, for each fixed r, t ranges over a consecutive integers. The starting integer may change with r or with a noninteger lambda, but the residues modulo a are still complete; no fixed branch numbering across r is required. For any real x,

    (1/a)sum_(t=0)^(a-1){x+t/a}
       =(a-1)/(2a)+{a x}/a >=(a-1)/(2a).

To verify this identity, write ax=k+delta, 0<=delta<1; the residues of k+t modulo a form a permutation of 0,...,a-1. Changing variables dw=dr/a on each branch consequently gives

    integral_(0<=r(w)<=1/4) H(w) dw
      >=(a-1)/(8a)-1/16

All integrals here are only over one specified unit interval. Since H<=1, the subset with H>=1/16 has length at least 1/60: if that length is t, the integral is at most t+(1/4-t)/16=1/64+15t/16.

Retain only points whose r and z phases have distance at least rho=1/1000 from integers. Each fractional-part function traverses an integer number of periods in a unit w interval, so its deleted set has length 2rho; deleting both loses at most 4rho. The final good set E has length
