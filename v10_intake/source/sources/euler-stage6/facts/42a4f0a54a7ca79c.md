# RATE-TV：一般二阶源的同轨迹 actual 风险能否去掉对数损失

这是已完成 G/U 条件统计根之后的独立研究问题，不增加旧根或 SRC 的前提，不重开它们。既有实际可靠性增量已经收束；count-snap 与 V 接口的直接译码推论仅作为既有科学来源保留。

对每个固定有限 K>=2、M>=1、N=M+2，令 theta 为任意齐次二阶转移表（允许零边），mu 为任意初始对分布。令 Y_i=(X_(i+1),X_(i+2))，0<=i<=M，已观察 departures 是 i=0,...,M-1。对 s=(a,b) 及 c 属于 {0,...,K-1}，

    C_s,c=sum_(i=0)^(M-1) 1{Y_i=s, X_(i+3)=c},
    n_s=sum_c C_s,c, p_s,c^+=(C_s,c+1)/(n_s+K),
    R_K^+(M)=sup_(theta,mu) E_(theta,mu) TV(p^+_(Y_M),theta_(Y_M)).

sup 的源可以随 M 改变；每一条实验轨迹内必须保持齐次。研究实际最后行的同轨迹均值风险，而非独立测试行、时间平均、固定行最大值或条件风险。

主问题是判定以下命题，不能预设其为真：

    对每个固定 K，存在有限常数 C_K，使所有 M>=1 有
    R_K^+(M)<=min{1,C_K/sqrt(M+1)}.                    (RATE)

若成立，给出可独立核查的证明、一个明确的 C_K 上界及其 K 依赖；准确说明现有 h_N 下同一 Pi 的转移仅另付已接纳全路径 e_N。若不成立，给出固定有限 K0 和齐次源/初始律序列及 M_j→∞，使 sqrt(M_j+1) R^+_(K0)(M_j) 无界的严格见证；再区分所证损失是否真为 sqrt(log M)，不把任何发散因子都称为匹配原粗界。

若只能取得介于现有粗率与 RATE 之间的实质进展，先给精确有限界和未闭合的一步，再按该真实范围登记后继义务；不以探索报告宣称本问题已解决。K 的最优依赖是同一前沿的后续问题，任何非 sharp 的 C_K 必须标明；K 随 M 增长的见证不能反驳固定 K 的 RATE。

必须处理 J=0、暂态/可约/周期、任意 mu 和随 M 变化的源。不准条件于 J 或 Y_M=s 后将该行样本重置为 iid。任何 row-stack、martingale、renewal 或反向链论证都需保留终端选择与样本计数的相关性。其他估计器上的上界不自动回答 RATE；一般有限状态链 lower 必须说明可嵌入本二阶 pair-chain 的合法转移结构。文献结论必须逐项核对损失、初始化、风险目标与量词。

## 7. 对同一个已接纳 Pi 的任意合法精度转移

先给全精度有限式。对实际 query s=Y_M，把 SRC 的逐路径 I
与 TV 三角不等式取期望，得到

    sup_(theta,mu) R_act(Pi_(K,N,h))
      <=min{1, R_K^+(M)+[78KM H(c0)+K-1]/Q}.           (7.1)

所有随机 count/终态相关性都已保留在 E[1/(J+K)] 内，
只用已接纳的无条件逆访问矩；I 对全历史成立，不需要数据律正性。

对于原 h_N，Q_N>=128(K+1)(N+1)^3，且 h_N 合法。
I 在 n_s>=0 时还给全路径、全 query 统一误差

    TV(Pi_(K,N,h_N),p_s^+)
       <=(78M+K-1)/Q_N
       <=1/(N+1)²=e_N.                               (7.2)

第二步可直接核算：
M=N-2<=N+1，K-1<=(K-1)(N+1)，
所以 78M+K-1<=(K+77)(N+1)<=128(K+1)(N+1)。
这正是前驱的全路径 e_N，不增加新的实现假设。
由 RATE+ 及 (7.2) 得 PI-high。
实际用的是同一个原 Pi，增加的项只有 e_N；
没有改成另一估计器或把数学 counts 赠送给程序。

最低合法精度及任意更高合法精度满足 Q>=2M。
从 (7.1) 与 RATE+ 得

    sup R_act(Pi_(K,N,h))
      <=min{1,11K^4/sqrt(M+1)
                  +39K H(c0)+(K-1)/(2M)}.             (7.3)

用 H(c0)<=2sqrt(c0)=2K²/sqrt(M+1)，实现项第一项至多

    39K H(c0)<=78K³/sqrt(M+1).

又对 M>=1 有 sqrt(M+1)<=M+1<=2M，所以

    (K-1)/(2M)<=(K-1)/sqrt(M+1).

(7.3) 中未截断的总和因而不超过

    [11K^4+78K³+K-1]/sqrt(M+1).
                                                               (7.4)

对 K>=2，78K³<=39K^4、K-1<=K^4，故 (7.4) 至多
51K^4/sqrt(M+1)，特别不超过100K^4/sqrt(M+1)。
再与1取小，即得 PI-legal。这个计算含全部 M>=1，不省略小 M 或 h_0=4 的段。

低精度结论只断言同轨迹 actual 期望风险率；
不声称 h_0 与 h_N 输出逐字相同，也不自动移植有限访问外部行的
精确极限分类。资源成本仍是 SRC 对相应 K,N,h 的既有完整计费，
不能由统计率推导新的硬件、深度或宽度优势。

## 8. 适用域与相关性检查

本证明没有对链类结构作分解，也没有使用谱隙、混合时间或唯一平稳律。
这是因为生成律核对、确定栈长度矩和 UC/逆访问矩都对以下情形有效：
暂态行、多个闭类、可约链、周期链、任意 mu、含零边的 theta。
零坐标的中心样本恒为零，四阶矩推导仍成立。

全行最大量 B_v 只是对随机所选行提供逐路径包络。
最终乘上的 P(E_v) 来自实际末行 J 的 UC，并不是每个 fixed query
访问数的 UC。由此不能推出全部 query 的同样速率。
同理，本文未除以 P(Y_M=s)，也没有对该条件事件使用行栈 iid，
所以不声称任意 conditional-terminal 风险的统一上界；
零概率条件事件仍未定义。

风险目标从始至终是同一已观察轨迹末端 Y_M 的期望 TV，
并非独立测试行或时间平均。分析栈生成时即与该终端绑定；
式 (4.2) 在联合空间上处理依赖，未以独立测试简化问题。
原有 fixed/all/conditional 的反例不与本结果冲突，
K 随 M 增长也不是本固定 K 收敛结论的无条件延伸。

## 9. 已接纳 iid 下界与固定 K 的率指数

U2 的实际目标下界准确地说是：
每个 K>=2、N=M+2>=3 和每个共同随机全历史预测器 A，
都存在一个合法 iid 源，使其 actual 均值风险至少1/(16sqrt(M+2))。
可取所有行都为同一二元分布，参数
1/2±1/(8sqrt(M+2))，初始对按该分布 iid；
K>2 时其余符号零质量。这个源确实是本二阶表域的特例。
每个 M 可选择不同见证；不宣称一固定源同时实现所有 M 的下界。

因此，设

    mathcal R_K(M)=inf_(common randomized full-history A)
                    sup_(theta,mu) R_act(A),

则已接纳下界与本 add-one 上界给

    1/(16sqrt(M+2)) <= mathcal R_K(M)
      <= R_K^+(M) <= min{1,16K^4/sqrt(M+1)}.            (9.1)

add-one 是一个共同全历史规则，所以可用于该 infimum 的上界；
本证明的主问题仍是它本身的 R_K^+，而非用另一估计器替代它。
同一个下界也适用于每个公开精度下的原 Pi：
它是共同有限程序，因而属于任意共同全历史预测器的范围。
结合 PI-high 或 PI-legal，固定 K 的这些风险均有 M^(-1/2) 的率指数。

这是真正去掉了原粗上界的 sqrt(log M)，不是仅给一个更小的发散因子。
但 (9.1) 不匹配 K 的依赖；16K^4、11K^4、51K^4、100K^4 均是保守常数，
不能称为 sharp K 结论。任意算法的统计下界也不能推出 Pi 的内部字长、
宽度、层数、整网主导费用或同预算资源最优性。

例如，非负 TV 损失的 Markov 不等式可由本上界推出固定 K 的统一依概率
一致性；本结果本身不新增统一 a.s. 结论。低精度输出格式与固定源有限访问
分类仍须按其原有范围理解。
