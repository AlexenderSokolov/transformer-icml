## 2. 浓缩分支的全部初相位与完整源

本节只在 M>=mathcal B 时使用。此时
    M/lambda>=2^80 a t>=2^104 a,                        (2.1)
    M>=2^80 a^5 t^3>=4L,
故 m=floor(M/L)>=4，特别 m>=2。令 d=M-mL，0<=d<L，
    k=(L-2-d) mod L, epsilon=1/m.
这不是在小 m 边界偷加条件：M>=mathcal B 已经推出 m>=4。M<mathcal B 的所有小 m 情形由 §9 处理。特别，若floor(M/L)为0、1、2或3，则必在补集，完全不需要在该处定义epsilon=1/m或本clock源。

完整字母表分为
    A={0,...,a-1}, B={a,...,2a-1},
    C={2a,...,3a-1}, D={3a,...,4a-1},
    (p0,q0,p1,q1,eta,zeta)=(4a,4a+1,4a+2,4a+3,4a+4,4a+5).
未用标签仍在 K 字母表中。令 P=a^2。取从0出发并回到0、每条有向边含 loop 恰用一次的字典序首个 Euler 回路 w_0,...,w_P。有限存在性可直接由平衡入出度构造：沿未用边行走，除起点外不可能因无剩余出边而终止；闭合后在已有游走的有剩余出边的顶点继续闭游走并拼入。完整有向图保证若还存在未用边则有这样的顶点。每轮消耗至少一边，至多 P 条边后覆盖全部边。有限回路集合有字典序首元。令 w^0=w，w^1=w+a。

齐次行表完全如下，每个未注概率的箭头表示 delta：
    (p_s,q_s)->w^s_0, (q_s,w^s_0)->w^s_1, s=0,1;
    (w^s_i,w^s_(i+1))->w^s_(i+2), 0<=i<=P-2, s=0,1;
    (w^0_(P-1),w^0_P)->eta, (w^0_P,eta)->zeta;
    (eta,zeta)->(1-epsilon)delta_p0+epsilon delta_p1;
    (zeta,p_s)->q_s, s=0,1;
    (w^1_(P-1),w^1_P)->Unif(C);
    (w^1_P,c)->Unif(D), c in C;
    (c,e)->p1, (e,p1)->q1, c in C,e in D.
其它未指定行都是 delta_0。用 e 表示 D 标签，避免与余数 d 混淆。两组 clock 内部 pair 各不重复；末内部 pair 的出口替代其内部规则。组/marker 的位置分离使不同类型行不冲突，每行都是合法概率，shift 始终 (x,y)->(y,z)。实验内没有时变行。

定义 A 的“stay 圈”只为选初始 pair：
    y_0=(p0,q0), y_1=(q0,w^0_0),
    y_r=(w^0_(r-2),w^0_(r-1)), 2<=r<=P+1,
    y_(P+2)=(w^0_P,eta),
    y_(P+3)=(eta,zeta), y_(P+4)=(zeta,p0).
其长度 P+5=L，y_L=y_0。取 mu=delta_(y_k)。这个定义不把随机门在观测中固定成 stay。

A 每个完整圈从 (p0,q0) 输出
    w^0_0,...,w^0_P,eta,zeta,p_s,q_s
恰 L 个符号，其中 s=0 表示 stay，s=1 表示首次激活。B 每圈从 (p1,q1) 输出
    w^1_0,...,w^1_P,c,e,p1,q1
也恰 L 个符号。激活不可返回 A；B 的 query pair (c,e) 与 A 门 pair 同处相位 L-2。

由 k+d≡L-2 (mod L) 且 0<=d<L，从 y_k 到首个门恰 d 步；此前没有门。未激活时观察中的门 departure 恰为
    d,d+L,...,d+(m-1)L,                                (2.2)
终端门时刻 d+mL=M 不包含 departure。若某个门激活，此后的 query 时刻与这串格点对齐，首个 query 在激活门的 L 步以后。故 M 时刻一定是未激活的 A 门或 B 的 fresh query。

特别 d=L-1 时 k=L-1，初始 pair=(zeta,p0)。其第一步按行表确定输出 q0，然后按 A clock 到门，门距离仍是 L-1。任意初始化允许这个 pair；我们没有给未观察的更早门附加 stay 概率，也没有对更早历史条件化。d=0 时初始就是随机门，其在 departure0 的真实 epsilon 试验必须计入；d=L-2 时 k=0 恢复旧对齐初始化。

## 3. 所有余数的精确路径律与未删前缀

设在 gate index m-j-1 首次激活，0<=j<=m-1。这表示其后终端前已有 j 个 B query departures，另有终端 fresh query。此前 m-j-1 个门 stay，因而激活事件质量
    p_j=(1/m)(1-1/m)^(m-j-1)>=1/(4m).                  (3.1)
该下界可有限证明：令 r=m-1>=1，二项式给
(1+1/r)^r<=sum_(i=0)^r 1/i!<3（i>=2 时 i!>=2^(i-1)）。
故 (1-1/m)^(m-1)>1/3>1/4，更小非负指数只增大此值。

激活门时刻为 d+(m-j-1)L。从它之后两步到 (p1,q1)，距终端剩 (j+1)L-2 步，故恰包含 j 个完整 B 圈和一个到 query 相位的部分圈。每圈先均匀选 C 标签，再在该行均匀选 D 标签。完整观察历史由激活 index、这 j 个旧 pair 和终端 pair 唯一决定；逆向可从 marker 与组别读出这些选择。对每个指定的完整选择序列，
    P(该完整历史)=p_j a^(-2(j+1)).                     (3.2)
式(3.2)从原行表的每一步概率相乘而来，所有 clock 和初始残段都包含在内。因此条件于激活 j，j 个旧 query 和实际末 query 是 iid Unif(C x D)。这只是这个特殊齐次源的精确分解，不是一般源的条件 iid 假设，也不是附加独立测试。

每条这样的历史长度恰 M+2；terminal pair 的 departure 恰 M，未计入 M 个已见后继。其真实目标为 delta_p1。未激活历史也是程序的实际输入，但可因损失非负而不用于下界。

为计入初始残段，定义
    h_A(k)=从 y_k 到首次门前 d 个 departure 所发 A 标签数.
此前没有门，故它是确定的 0<=h_A(k)<=d，且所有这些 departure 都保留在历史中。两次相邻 A 门之间恰有 P+1 个 A 标签，激活门本身输出 p1 不在 A。于是精确地
    H_A=h_A(k)+(m-j-1)(a^2+1).                         (3.3)
旧对齐公式只在 d=L-2、k=0、h_A(k)=a^2+1 时恢复。我们不在其它余数上沿用它。

## 4. 任意余数下四头的共同有限多项式

条件于激活 j 及实际末 pair (c_r,e_s)。在 j 个旧 query 中，令 R_r 是第一标签等于 c_r 的个数，C_s 是第二标签等于 e_s 的个数，J 是两者同时匹配的个数。由(3.2)，其边缘律分别为 Bin(j,1/a)、Bin(j,1/a)、Bin(j,1/a^2)；三者可以相关。真实计数只有 C_(p1)=J。

## 9. 互补分支：同风险统计比较，而非 clock 浓缩
