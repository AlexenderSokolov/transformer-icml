# 公开记录与后续更新规则

1. **保留科学版本。** 定理、反例、审查问题、真正失败与已留存的修订应保持原身份。候选标题不因后来的接纳而改写；接纳以另立的日期和哈希记录说明。
2. **区分不同实验。** 固定表示与可重新编码、源符号扰动与内部端口噪声、受保护与可编辑终点、已知与未知参数，分别陈述。后续单元不回填进已有科学冻结快照。
3. **公开科学，不公开私人运行材料。** 用户原始指令、私人工作流、聊天路由、LLM 执行遥测、凭据和无关文件不进入版本库。混合文本只删除非数学部分，并保留原文件哈希、公开哈希和精确行级对应；不公开被删除值。
4. **不弱化来源校验。** 历史绑定仍指历史字节。公开导出对应关系另列，不能全局替换期望哈希，不能把缺失的旧版本重新生成后称为原件。
5. **每次更新明确证据范围。** 新跑的检查与继承的历史检查分开记录；计算诊断、文稿重建、独立 LLM 审查与一般数学证明不相互替代。
6. **保持可浏览。** 证明、审查、诊断、英文和中文文稿及研究日志是主要入口。嵌套压缩包与生成缓存不替代科学来源导航。

本仓库的轻量 CI 仅核对公开字节清单和校验器的拒绝条件，不重证定理。它仅有 `contents: read` 权限，无密钥、部署、付费外部服务或周期性计划。
