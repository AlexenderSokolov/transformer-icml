# Precision assumptions in two Transformer expressivity results

This note records which contracts the cited results analyze. It is a literature comparison, not a statement of new project results.

| Reference | Result and model | Arithmetic contract | What the result does not imply |
|---|---|---|---|
| [Merrill & Sabharwal, TACL 2023](https://aclanthology.org/2023.tacl-1.31/), Definition 6, Theorem 2, Corollary 2.1, Appendix A | Uniform threshold-circuit simulation of a log-precision Transformer. The simulation depth is linear in Transformer depth; the constant-depth corollary uses fixed Transformer depth. The uniformity argument uses space-bounded evaluation of fixed-arity primitives. | A represented floating-point scalar has signed mantissa and exponent fields. The iterated sum in Appendix A aligns values on a common integer lattice, sums exactly, then truncates; aligned temporary integers can be much wider than a represented scalar. | This is a simulation, not a uniform accuracy bound on predicted probabilities. It does not analyze serial hardware rounding or give a prediction-risk lower bound from circuit containment alone. |
| [Brösamle & Eckstein, ICML 2026](https://proceedings.mlr.press/v306/brosamle26a.html), [proof text, arXiv v2](https://arxiv.org/html/2605.18079v2), Theorem 4.2, Definition D.4, Remark D.5, Theorem D.17 | A hardmax-to-softmax conversion for specified reference constructions, with a ternary-state restoration step, separated nontrivial attention scores, and twice the reference depth. The formal outputs are discrete tokens. | The analysis rounds selected activations and normalized attention weights in separate floating-point formats. The proof requires representable scaling and an adequate normal range for largest weights. It does not include errors inside the score dot product, primitive softmax, or higher-precision accumulation. | The theorem does not establish calibrated risk for an unknown Markov source, a fixed-score positive-epsilon PreLN result, or a guarantee for arbitrary rounding implementations. |

When comparing precision bounds, separate the representation of stored values, the maximum width of accumulators, the sites at which rounding occurs, and the quantity guaranteed at the output. An arbitrary additive perturbation at a residual boundary is a different model from deterministic rounding at internal arithmetic nodes.
