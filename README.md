# Transformer 预测：统计、资源、精度与源轨迹扰动

本仓库用于持续整理一项理论研究：对于未知二阶随机过程，正确概率预测需要哪些历史、计算、内部精度与可靠性条件，以及输入扰动如何改变可达风险。

## 当前发布状态

仓库正在初始化。完整科学资料、中文导航、研究日志、原始字节与公开导出字节的对应表，将在隐私及来源完整性复核后以可浏览文件提交；这里不以压缩包替代证明和审查记录。

计划保留：
- 前期统计、网络资源、精度与深度研究，以及历版论文。
- 第八阶段的六个冻结单元：SC001、SC002、SC003、BT001、BT002、EP001。
- 冻结之后的 JP001、RE001、AB001、AB002，明确标注为后续更新，不混入第八阶段。
- 完整证明、真实失败与修订记录、独立审查、诊断和可复现来源映射。

## 科学边界

BT001 的强输运前提仍未证明；BT002 通过不同的熵输运路线闭合二元下界。EP001 改变终点编辑权限，但仍预测隐藏的真实目标分布。AB001 排除的是同一个估计器同时不知道扰动预算和混合参数的统一适应；已知混合参数、未知扰动预算的问题仍开放。

独立 LLM 审查不是形式验证、外部同行评审或新颖性认证。有限诊断不替代一般证明。本次初始化提交尚未宣称完成资料发布、重新运行全部科学脚本或重新构建文稿。
