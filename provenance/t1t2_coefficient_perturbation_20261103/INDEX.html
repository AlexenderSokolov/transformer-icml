T1/T2：单系数扰动、末端风险与安全窗口

本阶段保留十三份解析研究、量词澄清、定向先例审计与绑定原件的 LLM 审查。没有新增实验、随机数据、训练、枚举或运行历史研究程序。解析审查不是形式验证、外部人类同行评审或新颖性认证。

这是一个指定网络、指定系数方向的精确实数分析。不是任意 Transformer、任意扰动、所有源、固定字长浮点或 SGD 的下界。下列固定 q、随 N 改变的 qN、逐长度安全窗口是不同量词，必须区分。

1. 固定系数误差可以产生非零端到端风险

先读固定源漂移反例及独立解析审查。所用是既有四块、无 LN、全因果、二类词表 softmax 的固定参数图，支付输入 (1,i,i²,ln i,x)、两枚值为1/2的 BOS 及 exact-real 运算。只将第一块 lag-one 头的一项分数改为

sη(i,j)=2i(i−1)j−(1+η)ij²，η=1/(2q)，q 为固定正整数。

这把对应 Q 投影权重 −4 改成 −4(1+η)，绝对权重变化为4η=2/q；其余权重、lag-two 头、mask、gates 和读出均不变。相对分数系数误差 η 与绝对权重变化2/q不是同一个数。

源固定为二元二阶链 θ00(1)=3/4、θ10(1)=1/4、θ01(1)=θ11(1)=1/2，从均匀平稳 pair 律开始。每个两步 pair 转移至少1/16，源全支持且几何快混合。每个 q 先固定，再令 N→∞，受扰完整模型相对于同一轨迹真实末状态条件分布的平均 TV 风险趋于3/16。q 可先选得任意大，使固定正扰动任意小，但证明只覆盖 η=1/(2q)，不覆盖所有实数 η 或另一符号。

证明跟踪实际 gates、非平稳索引计数、四个 anchors、真实末态查询及最终 softmax，不是把注意力选错直接等同于预测失败。漂移索引 f(k)=round[2q(k+1)/(2q+1)]−2；依赖计数用有限块混合与 bad-pair 协方差界，未假设 iid。未扰动图在同源的风险趋零依赖既有逐词近似与固定源经验转移行收敛；更强全源一致速率需要另带继承统计假设。

2. 有限 N、三角序列与非常保守的长度界

  • 显式有限 N 风险差界 · 对应审查。原稿保留 cutoff、均值/方差、早期非整值 gate、BOS、非匹配质量及最终 softmax 常数。N≥Kq,N 时适用非平凡分支，否则使用平凡界；固定 q 给 Oq(√(log N/N)) 的风险差上界，不是实测收敛速度。
  • 必须合读的三角量词澄清 · 澄清审查。
  • 闭式充分长度附录 · 条件于有限界的解析审查。
qN[ln(qN+1)+ln(N+2)]/N→0 使风险趋于3/16，但另须 qN→∞ 才能说权重扰动2/qN趋零。例如最终为正整数的 floor[N/ln²(N+2)] 满足两条件。此时每个 N 使用不同扰动权重，源和未扰动图固定；不能称一个固定受扰网络。固定 q 的结论则始终是固定非零误差。

N≥[10⁶(q+1)]⁴ 足以使该例的实际末态平均 TV 风险>3/32。它是刻意巨大、非最优的充分长度界，不是首次失效时间、必要长度、最优指数或实践预测，也不是一般扰动的统一保证。

3. 同一个系数的双符号充分安全窗口

双符号安全窗口与独立解析审查证明：N≥2、L=N+2，仍只改变上述系数，若 |η|≤1/(8L)，则对每个输入词，完整最终词表输出恰等于未扰动图。这对应绝对权重变化≤1/(2L)。原 ReLU snap 的1/4裕度和指定图的后续依赖隔离是关键，不能推给一般 residual 网络。

原始 attention 权重和未使用槽位可能变化，完整 residual state 不要求相等。N=2 的两网络输出相等，但该共同的有限分数输出不必恰为1/2。逐 N 的安全 ηN 仍不是一个固定非零系数跨所有长度。

现有证明对比的是 O(1/N) 的双符号充分窗口，以及 ηN∼ln²N/(2N) 的一个正向失败序列。没有证明尖锐阈值、随 |η| 单调变化、窗口外全部失败或其他坐标的鲁棒性。专用整数后端可精确保存这一系数，不被类比噪声反例否定。

4. 先例与读取范围

定向先例审计应与上述数学稿合读，但它不独立认证3/16证明。Liu 等 Proposition 4 已讨论特定 flip-flop 模型的位置 QK 精确约束和长序列失效；Chen 的 induction-head 工作已有复制/匹配到完整输出的误差桥接。因此“小位置系数误差导致长序列失败”不能声称一般新发现，未找到相同量词也不证明原创。
