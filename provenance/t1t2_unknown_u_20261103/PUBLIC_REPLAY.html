1. 从可信完整检出核验

需要 POSIX Python 3.10+。先在可信 Git 提交的仓库根目录运行原有库存检查，再由已核验库存取得阶段清单哈希；不能把待核验任意清单自己算出的哈希当成独立可信来源。

python -I -B tools/public_verify.py
STAGE_SHA=$(python -I -B -c 'import json; d=json.load(open("provenance/PUBLIC_INVENTORY.json")); print(next(r["sha256"] for r in d["files"] if r["path"]=="provenance/t1t2_unknown_u_20261103/STAGE_FILE_MANIFEST.json"))')
python -I -B provenance/t1t2_unknown_u_20261103/verify_public_archive.py "$PWD" --manifest-sha256 "$STAGE_SHA"
python -I -B -O provenance/t1t2_unknown_u_20261103/verify_public_archive.py "$PWD" --manifest-sha256 "$STAGE_SHA"

阶段清单不包含自身或全局库存；自身身份由库存与 Git 提交绑定。外层核验所有本阶段物理文件、来源映射和88份明确列出的既有依赖，然后仅执行固定哈希的新 trace 检查器。不会运行任何旧科学程序。

2. 79,712,544字节完整原件如何保存

逻辑来源 v10_research/route_a_bos_causal_compile_20261103_1411/full_trace_cases_v1.jsonl 按原始 UTF-8 字节和完整换行边界拆成20份，每份≤4 MiB。分片连续、无重排、无压缩、无重序列化、无删行或去重；顺序拼接恢复唯一原件 SHA-256 b2559d1d28cf43d54a42f12adff27b65d1fbdb113a2fc1ed13b347b9cc0f34cf。实际仓库只保存分片，不再上传同一份79.7 MB整文件副本。

分片清单逐项提供路径、序号、原字节偏移、长度、首末记录和哈希，并绑定四个历史原件的身份。来源表中的 full-trace 条目是可重建逻辑来源，storage 明确标为 lossless_chunks；其 public 身份仍是原字节，绝不冒充仓库已有一个物理整文件。

3. 可选：只向全新目录重建原路径

先完成上面的可信核验，再取得分片清单的已验证哈希。用一个尚不存在的目标根目录替换下例路径。这个显式命令会创建新目录和原相对路径，只重建保存数据，不执行模型；如果目标已存在或含不安全路径则拒绝，不覆盖已有原件或日志。

CHUNKS_SHA=$(python -I -B -c 'import json; d=json.load(open("provenance/PUBLIC_INVENTORY.json")); print(next(r["sha256"] for r in d["files"] if r["path"]=="provenance/t1t2_unknown_u_20261103/FULL_TRACE_CHUNKS.json"))')
python -I -B provenance/t1t2_unknown_u_20261103/validator/verify_full_trace.py "$PWD" --manifest-sha256 "$CHUNKS_SHA" --reconstruct-to ./new-trace-reconstruction

重建器验证每份分片和拼接原件，输出恢复的字节数与哈希。去掉 --reconstruct-to 则只读核验。重建的数据属于后来那次单独运行，不会把较早缺失的中间记录变成已恢复。

5. 为什么不直接执行旧 checker

所有五个 checker 和五个 launcher 版本、原始开始/结束/stdout/stderr日志、运行总结及先前版本说明都在档案里，包括空 stderr。它们是历史证据，不是默认运行入口。v2 checker 的总结命令仍写 v1，这是实际保留的候选历史，未静默修复。

完整 trace 和 v5 checker 绑定原始 one-hot v4 报告哈希 79e81b718fbb89990d4a679fbd6fd5f1aec30a65e29ac8ddb9fb43cca5afec3a；既有公开报告是已声明非数学规范化后的副本。旧程序会按原来的完整性 guard 拒绝这个公开副本。新 helper 通过固定哈希的既有映射核对原始与公开身份，而不是改写旧 guard、修改记录或声称原脚本在公开副本上直接重放通过。

如要再次执行那些算法，必须另建隔离运行、显式处理身份映射并保留全部必要新值。任何新输出都应单独标注，不能覆盖旧日志或称为原始运行恢复。本交付只提供完整保存数据的可检验重建，以及研究方法/代码历史。
