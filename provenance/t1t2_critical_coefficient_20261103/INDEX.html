T1/T2：指定系数的临界尺度与固定常数风险

本阶段归档十份解析研究、实际澄清、绑定原文的 LLM 数学审查，以及 LLM 研究价值与文献审计。没有新增实验、随机数据、训练、枚举或历史研究程序执行。审查不是形式验证、外部人类同行评审或创新性认证。

只讨论一个明确图、一个明确系数方向和一个固定源。位置输入、其余权重和算术均按指定 exact-real 构造；不存在一般 Transformer、任意扰动、普通量化或 IEEE 硬件结论。固定 c 后取 N 极限、随 N 改变 cN、固定非零误差三种问题不能混同。

1. 共同模型与损失

沿用四块固定参数、二类词表 softmax 构造：无 LN、全因果、两枚 BOS、输入 (1,i,i²,ln i,x)、原 snap 与 gates、四个 anchors 和最后 Gaussian/log-position 读出。L=N+2，只把 lag-one copy 头的分数改为

s(i,j)=2i(i−1)j−(1+η_N)ij²，η_N=c/L。

它将 Q 投影中原标量 −4 改成 −4(1+c/L)，绝对权重变化的大小为4c/L。每个长度的受扰权重不同；原图不变。所有其他参数、mask、BOS、lag-two 头和输入不变。

源也始终固定：均匀平稳 pair 初始化，θ00(1)=3/4、θ10(1)=1/4、θ01(1)=θ11(1)=1/2。每个两步 pair 转移至少1/16，是全支持、真正二阶且快混合的源。风险对同一条观测轨迹的真实末状态 next-token 条件分布取平均 TV，不是独立查询或源类 minimax 下界。

2. c=2 的临界尺度反例与必须合读的 L1 更正

  1. c=2 主稿。
  2. 移动随机目标的 L1 表述更正，必须与主稿合读。
  3. 绑定两份原件的联合解析审查。

ηN=2/(N+2) 时风险趋于583/3072。证明把历史复制分成相对长度1/4、1/2、1/4的确定性区间，排除 O(log N) 个可能接近切换点的行；未假定半整数 tie 自动正确。依赖同轨迹的有限窗口遍历平均、实际四 anchors、真实末端查询及最终 softmax 得到该常数，不外推较早 qN 的证明。

主稿 §2 的“same limit in L1”是被保留的历史措辞，准确结论是 E|PN−pXN−3,XN|→0。随机比较量随 N 改变，不声称它本身收敛。四个 anchor 分别趋于固定常数，平稳性固定移动末窗口的分布，反三角不等式才把该 L1 误差转成风险极限。

与既有|η|≤1/[8(N+2)] 的逐词充分安全窗口对照，可说此指定系数已有同为 Θ(1/N) 阶的安全侧与一个失败侧例子。它不意味着同常数、符号对称、风险单调或所有窗口外扰动失败。

3. 固定正 c 的开区间与两个分别证明的端点

固定 c 转变主稿和对应审查原本只决定两个开区间，后来端点附录须成组读取：

  • 0<c<1/2 固定：所有充分大的 N，对每个输入词，受扰和未扰动最终输出恰相同。风险因而在该固定源上趋零；不承诺该开区间证明的长度条件在小 N 成立。
  • c=1/2：独立端点附录与审查给更强结论：每个 N≥2、每个词均输出相同。N=2 只说明两模型相等，不说共同输出恰为1/2。
  • 1/2<c<3/2 固定：实际末态平均 TV 趋于 (11c−3)/[16(4c−1)]，例如 c=1 为1/6。真实查询使用有依赖的末窗口，未引入独立-query 假设。
  • c=3/2：单独端点附录与审查给极限27/160。历史尾部可被排除为异常行，但末端查询另算，不能漏掉它。XN−2 的该端点查询解释从 N≥3 使用，不给 N=2 虚构 X0。
两个开区间加 c=1/2 的独立结论，显示先固定 c、再取长度极限的风险函数在 c=1/2 的正侧跳变，右极限为5/32。固定有限 N 的 softmax/ReLU 图仍对参数连续，不存在所声称的有限长度不连续。这不是一般网络的临界常数。随 N 靠近端点的 cN 边界层未解决；一般 c>3/2 未由这组区间证明覆盖，但上节特定 c=2 已另有证明，不能说它也未知。

所有这些长度相关 ηN=c/L 的结果，都不同于先固定 η=1/(2q) 再取极限的3/16。不能把3/16、583/3072、27/160混成同一量词公式。

4. 价值、先例与真正的数值边界

研究价值与先例审计是本项目的 LLM 研究角色评估，不是外部审稿、证明验收或优先权认定。它承认图、源、方向均为分析而选择；价值在于明确跟踪完整预测风险和固定长度/跨长度均匀稳定性的差别，不是发现一切模型共同的机制。

原 Q 标量−4 可被常用二进制浮点格式精确表示。不能说一次普通舍入必然产生本稿选定的 c/L 扰动。真实量化涉及格点、共享尺度、多参数、激活及运算实现，本批没有量化或训练实验，也不证明 SGD 通常产生该方向。参数误差大小依赖固定坐标与 Q/K 重标度，不是跨架构不变量。

Liu Proposition 4 已有位置 QK 精确约束和长序列失败先例，Chen 已有复制/匹配误差到完整输出的桥接，其他文献各有输入、参数和数值范围。未找到完全相同量词不是原创性证据。审计只是定向阅读，第三方原文只链接、不转载；既有 Liu PDF 抓取大小限制与索引文本核对范围保留在上一阶段索引和原审查中。专用整数后端精确保留原系数，不与此非零反事实实值误差冲突，也不自动证明完整标准浮点实现无误。
