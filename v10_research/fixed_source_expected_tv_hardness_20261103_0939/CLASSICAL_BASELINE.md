# Matched source-specific classical prediction baseline

2026-11-03. This additive scope note concerns the fixed source and threat model of `RESEARCH_NOTE.md`; it does not change that note or add a numerical experiment.

The constructed source has the publicly specified transition probability p=1/M² for symbol 1 in every row. A source-specific classical predictor that is told this same p can ignore the entire possibly edited history and return Bernoulli(p). Its next-symbol TV is exactly zero on every history and under every legal corruption, irrespective of the initial pair law. In an exact dyadic implementation, M is a power of two, so storing p takes O(log M) bits in a standard fixed-point or numerator/exponent representation; initial source knowledge, output representation, and routine arithmetic must be counted. This comparator has different model behavior from the hard construction and demonstrates that the latter's attack-value hardness is not an information-theoretic difficulty of predicting this known iid source and does not show a Transformer advantage.

The hard model's output instead lies in [1/M,3/(2M)] and is always greater than p; its absolute error is O(1/M) but its relative error is at least M-1. The constructed source is public to specify the risk, while the reduction's attacker still does not need p as an input: it only maximizes the public model's q. This comparison is source-specific. It does not give a source-blind predictor that knows p for the original general class of unknown order-two processes, nor a general robust-prediction theorem.
