一 共同任务和模型合同

固定 0<c<1/2，来源为未知齐次二元二阶过程，各转移概率位于 [c,1−c]，目标为实际末端上下文的下一符号分布；风险是期望终端 TV。所有结论覆盖平稳主类，所用统计和轨道证明还允许任意初始二元分布。

输入仅为 N 个原始符号、公开位置与一个合成终端行。模型使用完整特征 PreLN，所有 LN 的 ε=1、增益=2、偏移=0，普通因果 softmax 注意力，最终为普通仿射词表 logits 加 softmax。完整状态、矩阵算子范数、完整偏置和逐步增益置于一次选定且足够大的有限包络内。没有声称适配任意预给的小数值范数上限。

主要正面构造宽度固定；反例另行购买 O(N) 宽度。全历史统一输出误差与来源平均预测风险分别记账。有限系数描述不是浮点执行保证。

二 双区域相位真正落到 PreLN

令 b 为二次幂、4≤b≤N/2，N 是四的倍数。取 m=⌊(N−b−2)/16⌋≥1，在初始对之后设置两个各含 8m 位的连续区域。每区相位按区域内计数重新定义，不能直接丢弃旧全局二次相位的跨区项。

第一次均匀注意力读取两个公开区域掩码后的前缀计数和原有后缀打包值，值维数为 3。第二次读取两个二次计数值，值维数为 2。对区域 (sⱼ,eⱼ]，第二读的掩码必须延长到 eⱼ+1；所得 Uⱼ 中每对位置 ℓ<k 的重数是 eⱼ−k+2，其奇偶恰好给出所需区域相位。

公开位置选择采用付费裁剪倍增，而不是一个斜率 N 的矩阵；平方、乘积、折叠与平台判别复用已有有界原语。所有准备、复制、范数填充和清零先固定，再选择小幅度 η。两读的误差递推均保留完整特征 LN 因子，不能将其看成分银行归一化。

结果：两个向量值注意力调用，值维数 (3,2)，不是两个标量读。对所有布尔历史，真实输出与双相位参考输出的 TV≤δ；宽度 O_c(1)，深度和每系数位宽 O_c(log N+b+log(1/δ))，未共享总描述为该量的平方。串行标量调度需五读。结论依赖已审后缀与规范化输出模块，不含完整数值矩阵展开或有限算术复现。

三 概率轨道重心的付费 softmax 实现

对公共振幅 ∑ρⱼ≤R，令 M(t)=2^(−r)∑_ν sigmoid(t+∑ρⱼνⱼ)，这里 ν 遍历所有 ±1 符号向量；实际后缀自变量是原有付费程序 d(z)。M 的一、二阶导数有与 r 无关的统一上界，且在有界 d 区间内远离 0 和 1。

直接在一维 d 区间上构造 M 的分段线性表，使用 O_(c,R)(ε^(−1/2)) 个节点。串行 ReLU 铰链求值保持固定宽度；对总斜率变差和系数舍入逐项控制，保证所有中间累加器有界。再付费近似 log M 与 log(1−M)，然后进行完整准备与 PreLN 恢复。不能把概率平均直接当成平均 logits。

结果：一个非零均匀标量读、固定宽度，D=O_(c,R)(log N+b+ε^(−1/2))，对每条历史 TV(Q_fold,M(d(z)))≤ε。足够小 ε 时原注意力头的消融差仍为正。未共享总参数描述 O_(c,R)(D²)。

这个线上网络界甚至可以不随 r 增长，但只是非一致的参数化表达界：朴素离线表生成仍需 O(2^r ε^(−1/2)) 次 sigmoid 求值，振幅输入描述也需支付。没有证明有限位参数生成器，也没有训练保证。另一种逐分支构造不预先形成 M 表，但线上深度会乘 2^r。群大小本身不能推出该一维特例的线上网络大小下界。

对上述双区域构造取 ρ₁=ρ、ρ₂=ρ/2，ρ 为指定的量级 b^(−1/2) 的正二进制振幅。此前已证局部类型保持对换在每区首个匹配八位块上翻转该区相位。令 γ=1−2c⁸，两个区域未匹配事件各自概率≤γ^m。

R_P(Q_fold)≤R_P(Q_two-phase)+δ+ε+(ρ₁+ρ₂)γ^m/4。

若 b≈log N，选择 δ、ε≈b^(−2)，两端都可保持固定宽度和 O_c(log N) 深度，风险增量为 O_c(b^(−2)) 加明确异常项。这里不再需要用旧单 sigmoid 基线替代重心所付的 (ρ₁²+ρ₂²)/8 项。

# Physical growing-width type-invariant approximation forbids suffix-only domination

6 November 2026 UTC. Private analytical candidate v1. No upload, experiment, parameter generation, numerical model execution, training, or finite-arithmetic certificate. This is a theorem composition and a scope clarification, not a new estimator or statistical rate. Independent review is required before treating this exact file as accepted.

## 1. Architectural and statistical scope

Fix c in (0,1/2). Let P_c be all homogeneous binary order-two kernels with every transition probability in [c,1-c], with arbitrary initial-pair law. The prediction target is the kernel at the actual final context (X_(N-1),X_N); risk is expected total variation of the reported binary distribution from that target.

Use EXACTLY the network family Q_N of the reviewed WIDE_PRELN_STATISTICAL_WITNESS.candidate.v2.md, not a purported compilation of the different clipped-MLE predictor in CONSISTENT_TYPE_ESTIMATOR_SUFFIX_OBSTRUCTION.candidate.v1.md. Q_N is source-independent and length-dependent. It receives N raw symbols, public positions and one synthetic terminal, not supplied counts, pairs, suffix statistics or source parameters.

The family obeys the same positive-epsilon ordered-causal PreLN/ordinary-output/full-norm conventions as the reviewed two-read ordered-suffix model: self-inclusive causal softmax attention; actual complete PreLN residual blocks; epsilon one, gain two, shift zero at every LN; bounded affine/ReLU FFNs; final actual LN, bounded affine vocabulary head and ordinary vocabulary softmax. It buys d=O_c(N) width, rather than remaining inside the ordered-suffix theorem's fixed-width subclass. A sufficiently large c-dependent envelope is fixed once for every N; it is not an unchecked prescribed numerical norm budget. Gain is bounded as an operator, not as the Euclidean norm of its d stored diagonal entries.

All statements below use exact-real execution semantics. Approximate invariance is an all-history output assertion, not exact invariance of physical row states or attention values.

## 2. The precise reference estimator already compiled

For each context v and j in {0,1}, let

 C_(v,j)(x) = sum_(i=3)^N 1{(x_(i-2),x_(i-1),x_i)=(v,j)}.

For v=(x_(N-1),x_N), set J=C_(v,0)+C_(v,1), and

 B_j(x)=(C_(v,j)+1)/(J+2).

Choose the fixed dyadic a used in the wide theorem, with 0<a<=min(c,1/4). Define the mathematical reference

 F_N(x)_j=max(B_j(x),a) / [max(B_0(x),a)+max(B_1(x),a)].

This is the actual wide theorem's ideal floored reference, not clipped MLE and not the intermediate rounded piecewise-linear-log output. Sections 3–5 of that theorem prove, uniformly over ALL binary histories,

 TV(Q_N(x),F_N(x)) <= epsilon_N := N^(-1/2)/64.          (1)

Indeed its log interpolation contributes at most N^(-1/2)/128 and its physical final-logit error contributes at most N^(-1/2)/128. The ordinary binary-softmax TV Lipschitz bound gives (1). No expectation, typical-history qualification, or physical exact decoding is inserted here.

The inherited full-history add-one theorem and binary flooring contraction give

 sup_(P,mu in P_c) R_(P,mu)(Q_N)
 <= U_N := min{1, 13 sqrt(32/(N-1)) + epsilon_N}
 = O_c(N^(-1/2)).                                      (2)

This risk controls the actual terminal context, including its dependence on the observed counts. The constant displayed in (2) is conservative and inherited. For N>=4, U_N<=K/sqrt(N), for example K=100 suffices. Constants in architecture and the fixed envelope still depend on c.

## 3. All-history approximate type invariance

Write x~y if their eight triple counts agree and their final ordered pair agrees. Then B(x)=B(y), hence F_N(x)=F_N(y) exactly. By (1),

 sup_(x~y) TV(Q_N(x),Q_N(y)) <= 2 epsilon_N
                                        = N^(-1/2)/32. (3)

Thus Q_N is an actual physical network with vanishing diameter on every such type class. This includes every orbit of the reviewed endpoint-preserving local type moves. The bound is for ANY two members of an orbit and does not accumulate with the number of moves, because each output is compared to the same exact F_N.

Triple counts alone without terminal-context preservation are insufficient for this inference. No claim is made that all universal source-preserving maps necessarily preserve that terminal context. Nor does this approximation create exact invariance of the physical network.

## 4. Fixed-source logarithmic-suffix obstruction

A suffix-b predictor means any source-independent measurable rule S_(N,b)(X_(N-b+1):N,U) reporting a probability vector, where U is independent private randomness. It may depend on public c,N,b, use unlimited computation, and use the final context when b>=2, but receives no earlier data, source parameter, or correlated advice. A program that looks at the full history and merely rewrites it into a short string is NOT covered by this information restriction.

Take the two fixed sources P_-=IID Bernoulli(c) and P_+=IID Bernoulli(1-c), including their IID initial laws. Both belong to P_c. Let Delta=1-2c. For the two suffix laws with masses f_-,f_+, the pointwise triangle inequality gives

 [R_-(S)+R_+(S)]/2
 >= (Delta/2) sum_z min(f_-(z),f_+(z))
 = Delta e_b,                                         (4)

where e_b is the equal-prior optimal binary testing error. Randomization does not help: apply the inequality for each U, then integrate. The all-zero and all-one suffixes together contribute 2c^b to the overlap, so e_b>=c^b. This avoids any tie-handling assumption in majority testing.

For every integer 1<=b<=log N/[4 log(1/c)],

 [R_-(S)+R_+(S)]/2 >= Delta N^(-1/4).                  (5)

Combining (2) and (5), some one of these same two sources satisfies

 R_sigma(S)-R_sigma(Q_N) >= Delta N^(-1/4)-U_N.         (6)

The right side is positive for all sufficiently large N. Therefore no suffix-b predictor sourcewise dominates Q_N, even on this fixed two-source subclass. The assertion quantifies over every suffix predictor, not merely another network with comparable resources. Arbitrary randomized output replacements are included.

If an additive domination slack tau_N is permitted, (6) still rules it out whenever tau_N<Delta N^(-1/4)-U_N. The lower is on task risk, not on reproducing Q_N's outputs.

## 5. Stronger classical source-varying corollary: every sublinear suffix

The restriction b=O(log N) above comes from insisting on the SAME separated pair c and 1-c. It is not a fundamental limit of suffix information. Here is a separate, elementary minimax calculation; it adds no new statistical-rate claim.

For 1<=b<=N put

 delta_b=min{(1/2-c)/2, 1/(8sqrt(b))},
 theta_-=1/2-delta_b, theta_+=1/2+delta_b.

These IID kernels lie in P_c and delta_b<=1/8. The Bernoulli KL upper bound KL(p||q)<=(p-q)^2/[q(1-q)] gives

 KL(Ber(theta_+) || Ber(theta_-)) <=32 delta_b^2.

Consequently the product suffix laws satisfy KL<=32b delta_b^2<=1/2. Pinsker gives TV<=1/2 and hence overlap >=1/2. The same integrated triangle inequality, now with target separation 2delta_b, yields

 [R_(theta_-)(S)+R_(theta_+)(S)]/2 >=delta_b/2
 >= k_c/sqrt(b),
 k_c := (1/2) min{(1/2-c)/2,1/8}>0.                   (7)

Thus, for every suffix rule, one admissible IID source satisfies

 R_theta(S)-R_theta(Q_N) >= k_c/sqrt(b)-U_N.            (8)

If b=b_N=o(N), then sqrt(b)U_N ->0, so eventually this is strictly positive, and in fact the excess is at least k_c/(2sqrt(b)). This applies to any integer sequence b_N>=1. For b=0 there is already a constant two-source lower with no observations. For b sufficiently large that delta_b=1/(8sqrt(b)), the explicit lower in (7) improves to 1/(16sqrt(b)).

Unlike Section 4, the two witness parameters here can depend on b. The source-selection quantifier is minimax: for each N,b and predictor there is an offending source. It does NOT exhibit a single fixed IID source that defeats every member of an arbitrary b_N-growing predictor sequence. It DOES rule out uniform sourcewise domination over P_c by any sublinear-suffix sequence.

This is a direct observation-information lower, not circular use of an old architecture depth-risk theorem. Combining a full-history risk with a suffix sample lower establishes the restriction on suffix replacements, but cannot establish an arbitrary-message communication lower or an optimal architectural resource frontier.

## 7. Failed shortcuts and unresolved gap

1. Compiling the clipped empirical MLE from the symbolic consistent-obstruction note by citing the wide add-one compiler would substitute a different estimator without proof. This file uses the exact add-one/floor reference already compiled. The two estimators need not agree.
2. Exact type invariance of the add-one reference does not imply exact physical invariance after nonlinear PreLN approximation. Only the uniform O(N^(-1/2)) orbit diameter (3) is proved.
3. The network is in the same broad architectural/norm contract, but NOT the same fixed-width resource class. Calling this a fixed-width counterexample would be false.
4. The fixed-width ordered-suffix network with b=N can provide a separately paid O(N)-depth route, but that is not the logarithmic-depth wide witness and is not used to hide the present width purchase.
5. A fixed-separated-source lower decays exponentially with b; it cannot alone prove all b=o(N). Section 5 explicitly changes to local alternatives and labels its minimax quantifiers.
6. No suffix-only lower forbids an arbitrary short message summarizing the whole history. Such a message can contain empirical counts or another useful statistic, and the acquisition/communication/precision costs require their own analysis.
7. A canonical orbit representative computed from all of x need not be suffix-computable. Thus (3) does not settle a general finite-group task-folding theorem; it rules out the additional conclusion that a risk-preserving replacement can discard all but a sublinear raw suffix.
8. The O(N^(-1/2)) rate and classical two-point inequalities are inherited standard ingredients. The useful closure here is an explicit physically normalized, all-history approximately invariant, resource-honest counterexample to an overbroad suffix-domination assertion.
9. No fixed-width, O(log N)-depth analogue is proved. No lower for arbitrary nonlinear evolving-memory networks or arbitrary interactive protocols is proved. These gaps remain open.
