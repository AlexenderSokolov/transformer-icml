## Independent derivation and source-bound checks

### 1. Scope and partition

Deleting all-zero output columns leaves two nonempty supports. Equality of rows, empty support intersection, unequal supports with nonempty intersection, and equal supports with unequal rows exhaust all possibilities and are pairwise disjoint. Equal singleton supports necessarily imply identical rows, so there is no missing singleton case. For unequal overlapping supports, lambda=sum min is strictly positive and less than one, since lambda=1-TV(W0,W1). The proof does not mistake nonidentical probabilities for distinct supports.

The experiment fixes physical binary input length before channel realization, permits full corrupted-word scanning, and exposes only baseline plus actual channel outputs. Common independent coins can be conditioned on; private encoder mixtures remain arbitrary. The same map applies to every budget, table, initial law, and legal kernel at a fixed horizon. Fresh post-attack memoryless noise is explicitly required. Neither the constructions nor the lower attacks use a channel seed, source oracle, variable length, or feedback.

### 2. Universal minorizer

For every deterministic codeword h, product law W^R(v|h) dominates product_i min_b W(v_i|b). Its mass is lambda^R. Integrating arbitrary encoder mixtures preserves domination; conditioning on shared baseline coins preserves the identical common submeasure. The artificial baseline decoder draws this normalized common distribution independently and then applies the original receiver. Since the actual loss is nonnegative, each instance's risk dominates lambda^R times that decoder's risk. Only then taking the instance supremum and rule infimum yields Gamma_W >= lambda^R Gamma_0. No minimax exchange or attained optimum is used. The common component need not be observable.

The separate full-history floor follows because the composite channel procedure is a randomized function of full data in the clean subfamily. This floor does not assert domination by the historical exact gate. Combining it with the minorizer gives a maximum, not an unproved sum. R=0 means the empty transcript of mass one; lambda=0 with R>0 simply gives zero overlap lower contribution. These endpoint conventions avoid 0^0 errors.

### 3. Identical and disjoint rows

With identical rows, the entire output law is independent of encoder input, path, and common seed, so it can be generated by baseline randomization. Ignoring the channel gives the reverse inequality. Therefore exact equality with Gamma_0 holds for every finite length, including horizon-dependent finite schedules.

With disjoint supports, one input communicates the accepted gate without error. A null-probability output can have any fixed fallback. R=0 remains baseline and cannot achieve a uniformly bounded target as M tends to infinity. The candidate correctly restricts minimum-one language to this asymptotic sense; for a particular small M, zero inputs might already meet a large target. It also does not claim one input can attain every target below the displayed gate bound.

### 4. Unequal-overlap construction

Choose a nonempty exclusive set in one direction, relabeling inputs if needed. Its probability p under the exclusive row is positive, and overlap forces p<1. This works for strict support inclusion; exclusivity in both directions is not required.

The words 01 and 10 have exactly one input from that exclusive row. Seeing the exclusive output identifies which slot it was and hence the bit, without error. Otherwise declare erasure. For each bit, success probability is exactly p, so the failure indicator is independent of the complete pre-channel state. Two exclusive detections have probability zero. This establishes an exact BEC only after explicit coarsening; no false full-output equivalence is claimed.

For n repeated two-input blocks, all-erased probability is (1-p)^n independent of path and gate. Thus one may switch between accepted gate and baseline procedures with instance-independent weights. This directly yields the stated upper bound with n=floor(R/2); any odd padding uses a fixed actual binary input and is ignored. For R=0 or R=1 the decoder simply uses baseline. Two is a cost of this construction, not a universal lower bound on every possible finite code. All displayed costs count physical inputs, with no free extra alphabet.

The minorizer lower forces R >= ln(c0 ell_M/B)/ln(1/lambda) for any attained bounded factor, and the same lower applies directly to the minimax value. The construction achieves Cg+1 using twice a rounded logarithm of C0 ell_M. Consequently the optimal feasible constant-factor length order is Theta_W(log log M). The exponents lambda^R and (1-p)^floor(R/2) need not match; the candidate explicitly makes no sharp fixed-length risk-curve assertion.

### 5. Equal-support lower

Finite common support makes the maximum reciprocal row ratio finite. Distinct rows ensure kappa>1. Product distributions have pointwise ratio bounded by kappa^R on common product support, and both vanish outside it. Arbitrary mixtures preserve this two-sided comparison, including after conditioning on common coins.

The reviewed likelihood source uses the channel only through this comparison: at common-baseline words, TV triangle inequality leaves the target separation intact and multiplies only clean nonnegative loss by the likelihood factor. Its legal, predeclared mixture attack is independent of code, coins, and channel outputs. Actual nonnegative null loss is transported before the signed inequality is substituted. Thus replacing its BSC factor by kappa^R is valid without changing any combinatorial lemma or attack.

The inherited finite implication is exactly: M+1>=2^160 and kappa^R<=(M+1)^(1/8) imply Gamma_W>=2^(-32)ln(M+1). For any fixed bounded target, sufficiently large horizons therefore require R>ln(M+1)/(8ln kappa). This applies before taking an infimum and does not require minimax attainment. Infinite ratios in partial-support channels preclude this substitution there; the candidate respects this boundary.

### 6. Equal-support upper

The Bhattacharyya coefficient h is strictly between zero and one: positivity uses overlapping common support; strictness in Cauchy-Schwarz uses distinct probability rows. For likelihood decoding, under bit zero its error region satisfies P1>P0, hence P0<=sqrt(P0 P1); under bit one its error region satisfies P0>=P1, hence P1<=sqrt(P0 P1). Summing gives each conditional error <=h^R, including the assigned tie. An average-error bound has not been silently promoted to a worst-case bound.

Conditioned on any corrupted word, gate error is bounded by h^R. Coupling accepted exact-gate and decoded-gate receivers, their loss difference is at most the error indicator because unsquared TV loss lies in [0,1]. Dividing by g_M(k)>=M^(-1/2) yields the stated Cg+sqrt(M)h^R upper, uniformly over all budgets. R at least the ceiling of ln(sqrt(M))/(-ln h) achieves Cg+1. This proves the matching O_W(log M) order without adaptive encoding or additional side information.
