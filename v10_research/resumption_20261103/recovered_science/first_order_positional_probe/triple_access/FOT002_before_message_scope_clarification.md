# FOT002: matched first-order result in the original richer observation

Root-authored interface candidate, pending independent check. The accepted FOT001 lower and FOU001 upper use different horizon conventions; this note matches them without dropping constants.

## Exact common model

Let M>=64, N=M+1. Observe X_0,...,X_(M+1), i.e. N+1 raw symbols. The source transition table is known to be first-order binary, but its table and arbitrary initial PAIR law are hidden. The initial edge need not obey the table; all subsequent transitions do. There are M triple departures (eight exact counts H_abc at indices0,...,M−1) and N ordinary pair edges. Supply actual first/last r raw symbols, integer2<=r<=M+2. Protect X_M and X_(M+1); strict offline source-independent kernels change at most integerk∈{0,...,M} of the first M coordinates. Prediction is at the actual terminal pair; for first-order tables this is exactly prediction at its last symbol. Loss is unconditional unsquared TV.

For one k-blind map, take its supremum risk/g_M(k), g_M=max(M^-1/2,k/M), then infimize over maps. Denote the resulting stationary/all-start factors by Lambda_stat(M,r), Lambda_all(M,r). The source class may be either (i) all first-order tables, or (ii) those satisfying the original all-state pair certificate beta=1/M. Lower witnesses obey(ii), upper covers(i).

## Candidate matched theorem

For ell=1+ln((M+2)/r), under either source-class convention,

2^-33 ell <= Lambda_stat(M,r) <= Lambda_all(M,r) <=2^17 ell.

Known-budget same-information risks obey

g_M(k)/96 <= Rstat(M,k) <= Rall(M,k) <=2^16 g_M(k).

Thus the logarithmic cost already occurs for first-order dynamics even after supplying all eight triple counts and protecting both final symbols. The certificate is not needed for the first-order upper; the lower respects it when it is imposed. This does not change the class for the existing second-order upper theorem, which still uses its certificate assumption.

## Proof of the upper and oracle upper with arbitrary initial pairs

Discard the first raw symbol and use the suffix X_1,...,X_(M+1), with exactly M ordinary transitions. The original observation recovers the four pair counts of that suffix exactly:

N_ab(suffix) = sum_c H_abc + 1{(Z_M,Z_(M+1))=(a,b)} - 1{(Z_0,Z_1)=(a,b)},

where Z is the corrupted word. The first and last pairs are observed because r>=2. This is an exact pathwise count identity, even when Z0 was edited; it adds the omitted final edge and removes the initial edge. The last r'=min(r,M+1) symbols of the suffix are also available.

Conditional on each clean X0=b, the suffix follows the homogeneous first-order table from an arbitrary conditional initial law of X1. Define an induced suffix kernel by prepending fixed b, applying the original full-word kernel, and retaining its suffix output. This is a fixed legal map on all suffix words for each b, changing at most k suffix symbols and protecting the terminal symbol (in fact two). It may use the prepended fixed b but no true law. The SAME suffix predictor is used regardless of b. FOU001 is uniform in initial law and kernel, so applying it conditional on each b and averaging covers arbitrary original initial PAIR laws. The proof does not assume the initial edge was generated by the first-order table.

Apply FOU001 with N'=M, budget0<=k<=M, and windowr'. Its suffix-only map is measurable in the reconstructed counts and available raw suffix; no unavailable raw prefix of the truncated word is needed. Its bound is2^17ell' g_M with ell'=1+ln((M+1)/r'). If r<=M+1, ell'<=ell; if r=M+2, both ell' andell equal1. Thus the asserted upper follows. The known-k FOU predictor needs only the reconstructed counts and actual terminal symbol, giving2^16g_M directly.

This covers arbitrary initial pairs and all reducible/periodic first-order tables. It uses ordinary-state suffix departures r'-1, not the older pair-state r-2 formula. Conditional clean X0 is only an analysis device; it is not an input to either predictor.

## Proof of the lower and oracle floor

For each fixed map, accepted FOT001 gives sup R/g_N >=2^-32ell over legal budgets0..N−1 and stationary first-order sources satisfying beta=1/(N−1). These are exactly the original budget and certificate values after M=N−1. Pointwise,

g_N<=g_M<=[N/(N−1)]g_N,

so R/g_M >=[(N−1)/N]R/g_N. Taking the supremum and then infimum preserves the universal lower, giving at least[M/(M+1)]2^-32ell >=2^-33ell. No optimizer or worst-case attainment is required. The lower for the larger all-table class follows by inclusion.

For the known-budget floor use the actual elementary IID proof in the accepted original manuscript (lem:oracle-floor), not an arbitrarysecondorder lower. It uses only stationary IID binary sources and one source-independent kernel on the first M editable symbols, preserving the last TWO symbols and counting all four protected labels. Hence that proof is already within the first-order subclass and yields g_M/96 even with full history. IID pair kernels have P²=Pi on every row, so the certificate-restricted convention also admits them. Information restriction and arbitrary-start inclusion give the stated oracle floor.

## Direct consequences and limits

Prescribed raw widths have a uniform finite factor iff their normalized liminf is positive. Counts plus initial/final pairs (r=2) cost orderlogM. A full-word encoder may instead send FOU001's exact half-visit bit for the truncated suffix X1,...,X_(M+1) after corruption; the reconstructed suffix pair counts and last symbol suffice to decode it, with risk<=1024/sqrt(M)+2^20k/M. A one-symbol alphabet leaves at most the r=2 baseline and cannot achieve a uniform constant. Thus the minimum fixed supplemental alphabet is two in this richer-count model too; scanning and exact counters are not charged as message bits, and the message is fault-free.

These are same-map adaptation factors, not a logarithmic risk penalty at each individual budget. Exact-oracle normalization changes constants according to the displayed sandwich. No neural, causal-attack, noisy-message, source-order-learning, leading-constant or novelty claim is made. No accepted manuscript has been edited by this interface candidate.
