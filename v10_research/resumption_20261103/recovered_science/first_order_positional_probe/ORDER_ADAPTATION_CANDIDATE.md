# FOC001: Markov order and full-history joint adaptation

Root-authored interface corollary, pending independent review. This does not replace either accepted proof or manuscript.

## A common experiment and comparison profile

Use the original word length M+2, M>=64, final pair protected, strict budget k on the first M coordinates, 0<=k<=M. The predictor receives the FULL corrupted word and neither k nor beta. The target is unconditional unsquared TV at the actual protected final pair. For first-order tables the next-symbol distribution after the initial pair depends only on the last symbol. The initial PAIR may have any hidden law, as in the original experiment: its first edge need not have been generated by the table. The next-symbol and pair-state targets still agree exactly.

For sources possessing a stationary pair law Pi and all-state certificate P²(u,v)>=beta Pi(v), beta in[0,1], retain the established profile

H2(M,k,beta)=min(1,max(M^-1/2,F2)),
F2=0 at k=0,
F2=(k/M)[1+ln(1+1/(k max(sqrt(beta),1/M)))] at k>=1.

This is the same comparison family used by the accepted joint-blindness theorem. It is not a new claim that H2 is an exact source-specific minimax risk. A uniform guarantee quantifies over every qualifying source and supplied-certificate value, while the predictor is not given that value.

## Candidate order comparison

1. If the source is known to be binary FIRST-order, a single predictor ignorant of k and beta has all-start risk <=2^21 H2 simultaneously for all M,k,beta and all such qualifying tables. It may use the full word, or the four pair counts of the suffix after dropping the first symbol, actual last symbol and one exact half-visit gate bit computed on that suffix.
2. For binary SECOND-order sources, no such jointly blind family exists with any finite universal constant, even with full corrupted history, unlimited computation and stationary initialization.

Thus Markov order affects this joint-adaptation question independently of the boundary-window restriction. This is not an unknown-order learning claim or a result for a predictor supplied beta.

## Positive derivation with the arbitrary initial pair handled

Discard X_0 and apply the accepted FOU001 exact half-gate predictor to the suffix X_1,...,X_(M+1), which has N=M ordinary transitions. Conditional on any clean X_0=b of positive probability, this suffix is a homogeneous first-order chain from the arbitrary conditional initial law of X_1. Every transition after the initial pair follows the first-order table. The original first edge X_0->X_1 need not follow it and is not used.

For each fixed b in{0,1}, define an induced stochastic kernel on suffix words w: apply the original kernel to the full input (b,w), and retain only its output suffix. This is a fixed map on every suffix word for the fixed constant b, not an oracle using a hidden table or initial law. It changes at most k suffix coordinates on every outcome and protects the final symbol (indeed the final pair), so belongs to the FOU001 attack class. Any edits to or information use of the omitted coordinate are already integrated into this induced map. Predictor randomness remains independent. The actual predictor is the SAME suffix map for both b and is not given b. The uniform FOU bound applies conditional on each b and every conditional initial law, and averaging proves it for the original arbitrary initial pair.

For g_M(k)=max(M^(-1/2),k/M), FOU001 gives

R<=min(1,1024/sqrt(M)+2^20 k/M) <=2^21 g_M(k).

The full corrupted word permits computing the four pair counts and half count of that suffix. No inaccessible clean coordinate is used by the predictor. Conditioning on clean X_0 occurs only in the proof to establish uniform legality and the Markov suffix law.

For k>=1, F2>=k/M; for k=0 it is defined as zero. Because g_M<=1 on the exact budget domain, the cap in H2 preserves g_M<=H2 for every beta. Thus R<=2^21H2. The ordinary first-order flip orientation is merely another representation of the next-symbol distribution; binary TV at the last symbol equals TV at the actual pair for a first-order table.

No all-state certificate is used to construct the predictor. Reducible/periodic tables and arbitrary initial pairs are covered through the suffix argument, including those with only beta=0. At positive beta, restrict the source class as usual without changing the map.

### Corrected initial-pair pitfall

The initial draft incorrectly applied FOU001 with N=M+1 to the full word while intending arbitrary initial PAIR laws. For the identity transition table and deterministic initial pair01, the word0111... has an impossible first edge under that table. The full-word homogeneous-first-order premise therefore did not follow. Discarding X0 and the conditional induced-kernel argument above repairs that actual interface gap. The original before-file and exact diff are retained; no accepted underlying theorem was changed.

## Negative derivation and exact non-transfer boundary

Use accepted AB001, binary_budget_adaptation/AB001_joint_blindness_obstruction.md and its root receipt intake/AB001_acceptance.json. Root has reread the full proof and its complete independent review. It explicitly gives a stationary second-order clean family Q_a in the beta=0 class and a first-order null with beta=1/M, under one common strict source-independent protected-pair kernel. Its full-history constrained-risk inequality contradicts a constant H2 guarantee for the SAME k,beta-blind map by selecting k=floor(M^(3/4)). Its estimator may randomize and use the entire corrupted word.

The clean alternatives are not generally first order: they have theta00(1)=theta10(1)=a, but theta01(1)=r(1-a)/a differs from theta11(1)=1-r. This matters. Their use does not contradict the first-order positive theorem. Nor does AB001 refute beta-informed estimators: its clean and attacked cases use different certificate values and need not share a positive certificate.

## Scientific use and limitations

This corollary distinguishes two sources of difficulty:

- At fixed critical supplied certificate, restricted local counts may lose unknown-budget adaptation even for first-order dynamics; positional gates address that observation limitation.
- With full history but both k and beta hidden, the first-order class still permits universal adaptation, while the larger second-order class does not.

It does not establish a phase diagram for every beta, arbitrary alphabet, source-order estimation, a noisy-bit implementation, a neural advantage, or novelty. The negative proof is an already accepted theorem; the only new work here is the common-experiment/horizon/normalization interface check. Independent review of that interface remains required before acceptance.
