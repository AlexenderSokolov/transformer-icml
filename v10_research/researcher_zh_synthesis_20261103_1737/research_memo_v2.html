一、目标与当前判断

母问题是：对转移规律未知的齐次二阶随机过程，Transformer 在什么条件下能随历史增长而提高下一符号概率预测精度；为达到误差需要多少历史、计算和数值精度；归一化与扰动怎样改变这些条件。原计划已限定每个源为有限字母表，并优先联合研究 T1 的前向机制和 T2 的历史—计算资源；训练可达性另行研究。

本 v2 合并了 v1 的两项单独更正；v1 及更正均保留在内部，待发布。
目前最稳妥的判断是：在明确付费位置与算术的无 LayerNorm 模型中，已有一套固定参数、普通词表 softmax 的一致性构造；统计难度对初态和混合要求非常敏感。另一方向已证明特定纯 pre-LN 类在一个固定快混合源上有非零风险下限。两者是结构对照，并非相同计算和数值预算下的最优分离。此前若干看似新颖的单头温度、上下文恢复或普通 n-gram 观察，已被先例或额外通道反例削弱。

二、共同实验与结论量词

给定长度 N 的同一条历史 X₁:ₙ，末状态 Sₙ=(Xₙ₋₁,Xₙ)，目标是真实下一符号条件分布 θSₙ。主风险为 E TV(Qₙ,θSₙ)，TV 为半 L1；期望包含真实末状态，而不是另抽独立查询。Js 是同一历史中情境 s 的先前出现次数，Cs,a 是其后符号 a 的次数；参考估计是 (Cs,a+1)/(Js+A)。

以下必须区分：固定单源与按 N 变化的最坏源；平稳与任意初态；末状态条件风险与按真实末状态平均风险；源内证据、网络可计算性、学习能否找到参数和数值实现。A 表示字母表大小，M=N−2 为可用三元组数。A 固定与 A 随 N 增长也是不同结论。

三、正面构造：固定参数、普通词表 softmax

二元

已推导，限定无 LayerNorm、exact-real 图。 使用四个 full-causal attention/ReLU 块、宽 128、每块配置 8 头、两枚 BOS；固定权重不依赖源或 N。输入显式付费 (1,i,i²,ln i)，不预先提供情境×位置、参数 θ 或未来符号。前两块复制最近符号并建立情境特征；第三块用四个锚头和 BOS 构造 add-one 近似，并用零 logits 的均匀头产生长度标记；第四块以 ln i 作为值，给出两个有限 logits，最后接普通二类词表 softmax。

对每条历史：|Pₙ−Bₙ| ≤ (N/2)e^(−N) + min{1,168/√(N+2)}。

其中 Bₙ 是同历史 add-one。结合 R011 的任意初态统计上界，固定二元字母表的最坏平均 TV 为 O(N−1/2)。上式的 168 是保守常数。ln i 是位置预处理而非免费 ln θ 或 ln P；首个 BOS 的 ln 1=0。N=2 用边界单独处理，不能说数值输出恰为 1/2。

一般固定有限字母 A

已推导，限定结构与账本。 采用 A 个 one-hot BOS、A² 个情境锚头、A 个输出头，以及同一类已付费位置；四块配置每块 A²+1 头，残差宽 O(A³)，最大 FFN 隐层为 A³。对于每个固定 A，参数可依 A 选择，但不依赖源或 N。以 L=N+A 记总位置数，逐历史输出误差满足

TV(Pₙ,Bₙ) ≤ N e^(−N)/A + min{1,84A/√L}。

结合 R011，固定 A 下对任意齐次转移表和任意初态的最坏平均 TV 为 OA(N−1/2)。若 A 随 N 增长，该已证资源与风险账本给出 A⁵/N→0 的充分条件；网络宽度、头数和参数同时随 A 改变，并未声称它是单一固定网络或最佳增长阈值。

四、精度、资源和原型边界

二元图的未平移复制 score 项最大为 O(N³)，匹配 gap 随 N 增长；位置幅值和动态范围不是免费资源。另有专用任意精度整数后端，以 s=⌈log₂(N+2)⌉、b=32s 构造二进制网格，使用确定性级数计算位置 ln i，并支付指数截断、归一化、除法及舍入。分析得到逐字误差 O(N−1/2)，位运算 O(N²log³N)，流式空间 O(Nlog N+log²N)，其中常数未优化。固定 A 的扩展也给出 A 和 N 的显式账本。

这些是专用任意精度整数算法的解析保证，不是标准 IEEE 浮点、固定字长、GPU、数值溢出稳定性、运行效率或训练成功的证明。此前没有通过未保存记录的实验来证明这些结论。扰动分析另显示，原位置复制 score 的固定系数发生某些非零误差时，足够长序列会改变最近位置排序；这只是所分析路径的反例，不是整个网络输出风险下界。

五、统计历史难度：A³ 与 A⁵ 为何都出现

源类与实际末态风险当前结论与边界
平稳、正反混合受统一控制同历史 add-one 上界适用于逆链混合总和受统一常数控制的平稳源类；对包含所构造硬源族的相应类，上下界匹配到 Θ(min{1,√(A³/N)})，常数依混合预算。下界不适用于任意收窄的快混合子类。所用硬源全支持、平稳且有统一两步混合；其他平稳源另有含对数因子的上界。该 A³ 不自动覆盖任意初态。
任意初态、无统一混合约束本地继承的 MM5/R011 证明链给共同 minimax 和原始 add-one 的 Θ(min{1,√(A⁵/N)})，常数不优化。其周期时钟以约 A² 步换来一个未知行样本，完整历史与有效样本及真实末态的对应需同时保留。可把表平滑成全正、不可约、非周期而保留逐 N 下界，但平滑及混合常数可随 A、N 变化。
稀有情境、整体快混合在指定二元族和真实末状态 00 条件下，未知稀有参数 u 的 add-one 条件风险阶为 O((1+Nu)−1/2)，与该族相应统计下界同阶。它不是对所有稀有源的无条件定理；条件风险不能直接替代总体平均风险。

平稳占用调和界不能直接推广到任意初态：周期时钟可令真实末情境先前未出现的概率至少 1/2，而错误套用的平稳右侧随 A 增大趋零。A⁵ 是对允许初态随问题规模选择的逐 N 最坏源结论，不声称某个固定源对所有长度始终达到下界。

六、归一化：限定 pre-LN 反例与正面构造

对一个精确定义的纯 pre-LN 类，所有 Q/K/V 和 FFN 只读取固定 ε>0 的 LayerNorm，深宽和参数固定，full-causal softmax，无 token×position 预处理、局部窗口或无界 score 偏置；任何可选的有界 score 偏置也必须是确定性的，且与源及整段 token 序列无关。残差可携带与源和 token 无关的无界位置向量。对末尾前一个符号的改变，实际末位输出变化 O(1/N)。在一个所有转移概率位于 [1/4,3/4] 的固定平稳快混合二阶源上，由两种同前缀末尾续接得到

liminfₙ E TV(Qₙ,θ_(Sₙ)) ≥ 1/32， 对每个固定网络成立。

已展开的保守有限 N 资源式为 risk ≥ max{0,1/32−Cmodel/(16N)}。Cmodel 显式支付层数、头数、||γ||/√ε、权重和读出范数、embedding 差及 score 上界。因此要使风险 r<1/32，必要有 Cmodel≥N(1/2−16r)；这是必要非充分条件，不声称最优。参数可随 N 改变时必须逐 N 重算；固定网络的 liminf 不能交换成不受预算约束的有限 N 网络下确界。

无 LayerNorm 的构造可直接使用增长的位置 score。Post-LN 的首个 attention 也可能先读到未归一化位置；在原稿特定 residual 布局下，后置 LN 会使局部复制信号缩小，但这不是所有 post-LN 网络的风险下界。局部窗口、额外 score 偏置、不同位置渠道、ε=0 或增长参数均需另案分析。

七、文献重合与主张边界

  • D’Angelo 等，Corollary 4.1 已在理想诱导头及相关极限下得到对称 add-α；它不是本文有限精度和普通输出接口的完整证明，但不能把 add-one 本身说成新发现。
  • Ekbote 等，两层 conditional k-gram、Rajaraman 等及 He 等的二次位置构造 已直接覆盖相关层数、匹配或位置机制；各自有相应极限、相对位置或读出假设，不能据此直接宣称本报告的全部接口已经相同，也不能把相同机制包装为新发明。
  • Han、Jana 与 Wu，Theorems 5、22 已给平稳高阶同轨迹预测的 KL minimax 率，在适用范围内包含二阶的 A³ 尺度；KL 下界不能反向用 Pinsker 自动变成 TV 下界。Han、Jiao 与 Weissman，Theorem 2 已给有限分布 iid 的 L1 minimax 先例。
  • Hahn 2020，Lemma 5 已有有界 soft attention 的单符号影响先例；Barbero 等分析 causal residual 的位置信息传播；Chiang 与 Cholak 展示 ε=0 归一化及长度缩放的逃逸机制。有限 N 资源账本和固定源风险桥接不能被称为全新的普遍注意力下界。
  • Makkuva 等，Attention with Markov v2 已撤回旧版高阶失败断言；不能把该旧说法当成支持本结果的定理。

阶段评估：现有正面构造和 pre-LN 风险界适合作为精确基线与后续证明接口；在完成更广泛先例核验、同资源对照和更有区分力的权衡之前，不宜仅凭它们宣称达到原计划的独立论文创新门槛。

九、下一步决策

  1. 最值得先做：将现有 pre-LN 必要容量界与一套允许相同 score、头数、位数、掩码和历史的正面模型作逐项对照，检查界是否能收紧到非平凡的匹配区间；若不能，应明确保留为机制性必要界。
  2. 对 post-LN、相对位置偏置、局部窗口和重新注入位置各自建立明确接口，判断哪些能恢复最近邻信息；不能由一个 LN 局部反例外推整个架构。
  3. 将输入生成、LN 的 ε/γ、温度、残差、舍入和浮点动态范围放入同一算术模型，并独立核对端到端实现；专用整数后端与通用硬件结果分开。
  4. 优先开展外部专家审稿与公开文献追索；训练可达性、慢混合细分、归一化下的全网络鲁棒性和更广的字母增长机制仍为开放问题。公开发布前须对文件可访问性、隐私、版本与缺失记录完成整包核查。
