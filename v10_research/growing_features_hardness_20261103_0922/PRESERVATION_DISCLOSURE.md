# Preservation disclosure for the original author diagnostics

2026-11-03. This is an additive disclosure. It does not alter the original author scripts, logs, note, or their checksums, and it does not replace or recreate any missing original per-case record. No new diagnostic, random operation, training, or source-data generation was performed to write it.

The original deterministic `check_reduction.py` and its retained `check_reduction.log` recorded only aggregate pass counts for 18,876 normalized formulas and 148,588 assignments, plus three named full-mask formula examples with M, k and mask counts, and one normalization pass line. The original script contains the finite enumeration scheme and fixed normalization examples, but the author run did **not** retain the individual generated formulas/assignments, each mask, each computed position/token embedding, pre-attention ReLU vector, feature bank, literal count, violation indicator, rational probability, target or intermediate assertion result. The three printed full-mask summaries do not list the individual masks or their computed values. Likewise, the original `check_gap.py` and retained `check_gap.log` recorded only the aggregate count of 2,232 rational checks and a pass line; they did **not** retain the individual M, m, P, V, probabilities, derivative fractions, lower bounds or per-case assertion results. Consequently, the retained author-run logs alone do not establish the exact per-case output values or preserve every intermediate computation. The deterministic source code makes a new replay possible, but such later results would be later-generated evidence, not the original missing records.

The independent review directory `review_independent_20261103_0924/` contains separately produced code, logs and `full_records.jsonl.gz`. Its script records selected per-case inputs and outcomes including masks, words, banks, literal counts, violation indicators and rational probability/target values for its own chosen set of cases, plus its own normalization and derivative-grid records. Those records are independent later computations, not the original author's per-case records and not a recovery of missing originals. The independent script's selected formula/assignment set is not identical to all 18,876 author-generated ordered formulas. Its per-case records likewise should be interpreted according to exactly what that script emits, rather than as a claim that every temporary intermediate in its process was saved.

The author's separately retained note, scripts and aggregate outputs support only the finite results and mathematical scopes described there. This preservation limitation does not by itself invalidate the proof, but the proof, original aggregate diagnostics and independent later checks have different evidentiary identities.
