Route B: terminal-port identifiability, precision and rare-family risk

3 November 2026. Research candidate in provisional model R, not a novelty claim, a formal proof certificate, a full-network lower bound, or a matched-FLOP separation. The scope is the common binary order-two model and the actual terminal state S_N. This artifact is distinct from earlier immutable reports. No RNG, enumeration, numerical test or external write was used in preparing it; the exact collision pair below is an existing checked example, not a new test result.

Research status. Results 1–3 are derivations for explicitly declared information ports. The rare-family bound uses a known public u, exact occupancy and total-count ports, and a certified head-output error; its sample scaling is an upper bound, not an optimality result. All causal binding, feature, precision and comparison costs must be paid. Independent mathematical review is pending.

1. Model and exact port

Let X_i∈{0,1}, S_t=(X_{t−1},X_t), N≥3, M=N−2, and let J_ab and C_ab be the numbers of historical triples t=2,…,N−1 with state (a,b), respectively the number whose successor is 1. Let query s=S_N and C=Σ_ab C_ab. Given exactly to the readout are s, N, all J_ab, C (equivalently r=C/M), and two scalar attention outputs q_1,q_2. For coordinate i, the terminal head scores β_i if the candidate coordinate equals the query bit, −β_i if it differs, and its value is the historical successor bit. Finite fixed β_i≠0 are public. The terminal query, counts and values all come from the same trajectory; history-side values do not read the later query. The readout has no access to any additional residual, token, position, head or intermediate stream.

For a binary bit fixed as the matching coordinate, let J^= and C^= count history matches, with D=e^βJ^=+e^(−β)(M−J^=). Then q=[e^β C^=+e^(−β)(C−C^=)]/D, so

C^= = [Dq − e^(−β) C] / [2 sinh β].

If the query bit is 1, subtract this from C to obtain the coordinate-0 successor margin. Thus the exact declared port determines A=C_00+C_01 and B=C_00+C_10. Conversely J,C,A,B and the query determine both heads. No four-query tomography is used here. If β_i=0, that head equals r and the corresponding margin need not be identifiable by this formula. No assertion is made that it could not be inferred from other path constraints in a particular case.

2. Exact finite-path criterion and reconstruction radius

For fixed J,C,A,B write x=C_00. All successor vectors compatible with the two recovered margins have the affine form

(C_00,C_01,C_10,C_11)=(x, A−x, B−x, C−A−B+x).

Let F be the set of integers x satisfying 0≤C_ab(x)≤J_ab for all states and the following causal feasibility condition. Construct the directed de Bruijn multigraph on 00,01,10,11 with edge multiplicities E_{ab,b1}=C_ab(x), E_{ab,b0}=J_ab−C_ab(x). There must exist an Euler trail of all M edges ending at the observed s. If the initial state S_2 is also explicitly given to the readout, the trail must start there; otherwise take the union over all four possible starts. The standard degree-balance and connected-support Euler conditions provide an exact finite check. The set is nonempty for every genuinely observed path. This formulation retains overlap between successive binary contexts rather than treating four state samples as iid.

For any α>0, define same-history comparator B_s=(C_s+α)/(J_s+2α). The coefficient of x in every C_s(x) is +1 or −1. Consequently the declared port determines B_s exactly if and only if F is a singleton. More generally, for a fixed port and an adversarial choice among all binary paths consistent with it, the exact minimax absolute error for reconstructing B_s is

diam(F) / [2(J_s+2α)],  where diam(F)=max F−min F.

A midpoint of the feasible comparator extremes achieves this, and the triangle inequality on paths at the two extremes proves necessity. Even if F is disconnected, only its extrema are needed for this absolute-loss radius. When J_s=0 the box constraint forces C_s=0 and the comparator is 1/2; it is not legitimate to claim missing matching observations always imply failure to recover this smoothed comparator. For an actual stationary trajectory, choosing the midpoint pathwise yields

Eθ|p_port−θ_(S_N)| ≤ Eθ|B_(S_N)−θ_(S_N)|
                         + Eθ[diam(F)/(2(J_(S_N)+2α))].

This follows on every path and then by expectation. It does not assume S_N is independent of the history and it does not bound the second term without further family-specific analysis. The same formula holds conditionally on S_N=s whenever that event has positive probability. The reconstruction radius is a lower/upper result for recovering a same-history statistic from the specified port, not automatically a minimax lower bound for estimating an unknown kernel.

For reference, box constraints alone imply

max(0,A−J_01,B−J_10,A+B−C) ≤ x
 ≤ min(J_00,A,B,J_11+A+B−C).

Euler feasibility may tighten this interval or remove values. The earlier words 00011011 and 00100111 have the same declared port but C_11=0 and 1, respectively, and are both legal; thus at that port F has at least two elements. This is a mechanism witness, not evidence about the numerical prevalence of ambiguous ports.

3. Certified precision for the two marginal counts

Assume J,C and β_i, D_i are exact and the computed head values satisfy |q̃_i−q_i|≤ε_i. Define ρ(β)=e^|β|/(2|sinh β|)=1/[1−e^(−2|β|)]. The affine inversion obeys

|C̃^=_i−C^=_i| ≤ D_i ε_i/[2|sinh β_i|] ≤ M ρ(β_i) ε_i.

Hence if Mρ(β_i)ε_i<1/2, rounding each reconstructed margin to its nearest integer recovers both margins, after which the criterion in §2 applies without additional ambiguity from these two rounded heads. For uniform b-bit fixed-point rounding with ε_i≤2^(−b−1), the strict sufficient condition is 2^(−b) Mρ(β_i)<1 for both heads. At equality no tie rule guarantees correct decoding. This is sufficient, not necessary: legal-path constraints can sometimes recover a margin even with coarser values. J and C require their own exact-count or bounded-error channel and O(log M) bits per count. Certified accuracy of β, exponentials, the logits, masking, accumulators and FFN outputs is not supplied by this scalar bound. As β→0, ρ diverges; as M grows, exact integer resolution requires correspondingly more precision under this decoding strategy.

4. Rare family: one terminal head can contain population signal

Let u∈(0,1/4) be public and fixed, w=(1−u)/3, θ=(t,1/2,1−ut/w,1/2) in state order 00,01,10,11, and t∈[1/4,3/4] unknown. Start in π=(u,w,w,w). For the older-coordinate successor count A=C_00+C_01, stationarity gives

E_t[A/M]=ut+w/2.   Thus t=(E[A/M]−w/2)/u.

The recent-coordinate margin C_00+C_10 instead has expectation Mw, independent of t. The old-coordinate head’s population mean contains t-dependent signal, provided β_1≠0 and the matching/normalization ports are known. This does not say its finite-prefix output is unbiased after conditioning on S_N=00.

On S_N=00, invert the older-coordinate head to obtain Ã, and output t̃=clip_[0,1]((Ã/M−w/2)/u). If |q̃_1−q_1|≤ε_q on every path, while J and C are exact, then

E_t[|t̃−t| | S_N=00] ≤ min{1, [sqrt(65M)+16]/(Mu) + ρ(β_1) ε_q/u}.   (∗)

Proof. In the stationary reversed pair chain, conditioned on S_N=00, P*² has common atom 11 of mass at least 1/8. Let ρ₀=7/8. Each summand of A is a bounded function of two successive reversed states. The discrepancy of its conditional mean from the stationary mean is at most ρ₀^⌊j/2⌋ at reverse time j; the sum over j≥0 is at most 16. Two such edge observables at lag h have absolute covariance at most 2ρ₀^⌊(h−1)/2⌋; summing h≥1 gives variance at most M+4M·16=65M. Hence E[|A−M(ut+w/2)| | S_N=00]≤sqrt(65M)+16. Divide by Mu and add the inversion error Mρ(β_1)ε_q/(Mu); projection onto [0,1] cannot increase distance to t. The event S_N=00 has probability u>0. This proof does not condition a forward martingale as if it remained a martingale and does not assume an independent query. ∎

For a desired conditional error τ∈(0,1], a deliberately conservative sufficient choice is M≥max{1040/(u²τ²),64/(uτ)} and ε_q≤uτ/[2ρ(β_1)]. With nearest b-bit fixed-point output, 2^(−b)≤uτ/ρ(β_1) suffices for that component. These conditions are sufficient, not a lower bound, not a complete network precision budget, and not proof that a single-coordinate port is statistically optimal. The model knows the special family and u, but not t; a generic unknown-transition problem cannot hard-code this inversion. The direct 00 joint-count comparator has a different sufficient conditional bound in the Route A work; comparing upper bounds alone cannot establish a strict sample-complexity separation.

5. Contrast with the pure-interaction family

Use signs a,b∈{−1,+1}, stationary uniform state distribution, and P(X_{t+1}=+1|a,b)=1/2+δab, |δ|<1/2. Marginalizing the successor over either state coordinate gives 1/2; population q_1 and q_2 are both 1/2, independent of δ, for any finite one-coordinate scores. A joint-state value or direct joint-match head can retain δ. This is a population symmetry statement; finite correlated path fluctuations, endpoints and additional accessible streams can still carry information about δ. The rare family above is not this uniform pure-interaction family: its old-coordinate mean contains signal of order u. Do not transfer a population no-signal assertion between these source distributions.

One can pad either construction to equal dimensions, but equal declared dimensions alone do not establish equal FLOPs or a strict difference in total prediction risk. In fact the four occupancy values already require representing joint state features in history-side values. If the same budget allows arbitrary successor-dependent value features, modifying that vector can directly expose C_ab and bypass the scalar-port obstruction. The earlier two paths even differ in a copied predecessor visible to some residuals. Thus there is no network-wide inference from §2 and no claim that depth or extra computation is necessary for all transformers.

7. Prior art, assumptions and checks

D’Angelo et al., Proposition 3.1 already cover exponential aligned partial matches; βac=2β·1{a=c}−β maps their equality coefficient to twice the sign-product parameter. Their copy and early-mask implementation has ideal limiting steps and Appendix E studies broader cross-lag symmetry-constrained comparisons. Basic Walsh product attenuation and soft interpolation are not claimed new here. The terminal-port condition above is an elementary restricted-interface consequence with Euler feasibility and integer precision; it requires a complete literature and internal-prior-art audit before any novelty assertion. Rajaraman et al. and Chen et al. are important full-network joint-context antecedents. Existing v10 positional/counter and rare-family work also cannot be disregarded.

The actual feasibility sets and risk rates remain to be independently reviewed. No complete proof-validation process, formal certification, or complete novelty gate is claimed.
