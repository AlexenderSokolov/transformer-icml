# 未知编辑预算下，少量位置信息如何恢复稳健预测

## 核心进展

本阶段解决的不是“已知污染量时怎样估计”，而是：**同一个预测器不知道实际编辑预算，能否同时达到干净数据与所有污染预算各自的最优阶？**

模型保持不变：二元齐次二阶源；对所有成对状态成立的证书 `K² >= beta Pi`；对前 `M` 个符号实施严格逐次成立的至多 `k` 次 Hamming 修改；最后两个符号受保护。目标是该实际末端状态真实下一符号分布的无条件 TV 风险。源参数、干净内部历史、攻击掩码和随机种子均不提供给预测器。结论覆盖任意初始分布，包括平稳支撑之外的初始状态。

最关键的发现是：**全局三元组直方图会丢失预算自适应所需的信息，但无需保留完整顺序；再加四个“前半段各行出现次数”就足够。**

## 一个简单的平衡门控规则

在受保护的末端行，记污染后全段行计数为 `J'`、前半段行计数为 `J1'`、指定后继符号计数为 `C'`。指定符号取该行第一位的补位。规则为：

    J' > 0 且 512 J1' >= J' 时，输出 C'/J'；
    否则，指定符号概率输出 0。

同一个规则不使用 `k` 或 `beta`，并满足

    R_all <= min{1, 2^16 / sqrt(M)
                    + 2^16 / (M sqrt(beta)) + 2^23 k/M}。

因此，在任意固定 `c > 0` 的区域 `beta >= c/M`，它同时达到所有预算下的已知预算最优阶

    min{1, max{M^(-1/2), k/M}}。

尤其在临界曲线 `beta = 1/M`，问题得到肯定解决。常数较大，结论是阶意义上的理论保证，不是实用性能评价。[全初始状态证明](../critical_beta_adaptation/CB005_all_start_critical_adaptation.md)

证明的关键不是假定全局混合速度达到 `sqrt(beta)`，也不是把“条件于末端行”的样本当成独立同分布。门控把攻击引起的错误决策限制到小行计数事件；对真正不平衡的干净路径，则用保留目标平稳质量因子的**末端状态—占用次数联合尾界**控制其风险。平稳初始化与任意初始化有各自严格的论证；单点平稳支撑下的暂态起点另行处理。

## 为什么这确实是信息上的分离

在同一临界曲线上，仅观察八个三元组计数和初末状态对，不可能完成全预算自适应；即使再保留真实的首尾各 `r` 个符号，只要 `r = o(M^(1/3))`，仍然不可能。这不涵盖所有内部长度 `r` 模式计数或任意局部编码器，也没有宣称 `M^(1/3)` 是精确阈值。[直方图障碍](../binary_beta_known_adaptation/BK001_histogram_adaptation_obstruction.md)、[边界窗口障碍](../binary_certificate_adaptation_phase/KH004_constant_crossing_window_obstruction.md)

所以，能描述干净齐次路径似然的统计量，不一定足以适应未知污染。四个半段计数提供的是分布在时间上的信息，而不是更强的计算能力。这里证明了“四个计数足够”，没有证明其数量最小。

## 已给定证书时的完整区域分类

设 `E` 是任意公开的 `(M,beta)` 集合。要求一个有限常数在该集合及全部预算上统一有效，并允许算法使用实际给定的 `beta`。对 `beta > 0`：

| 观察信息 | 可以全预算自适应，当且仅当 |
| --- | --- |
| 三元组直方图及初末状态对 | `sup_E min{M² beta, 1/(sqrt(M) beta)} < infinity` |
| 完整污染历史 | `sup_E min{M² beta, 1/(M beta)} < infinity` |

在 `beta = 0` 时，表中指标定义为零。分类同时覆盖平稳初始化与任意初始化，并允许稀疏或振荡的证书区域。[直方图分类](../binary_certificate_adaptation_phase/KH002_histogram_domain_classification.md)、[完整历史分类](../binary_full_history_domain/AF001_full_history_domain_classification.md)

完整历史的正向算法在 `beta <= B/M²` 时采用普通 add-one，在其余允许区域采用平衡门控。这个**选择器使用公开证书**；不能因为两个分支各自不使用证书，就把选择器说成证书盲。若 `beta = M^(-gamma)`，完整历史允许 `gamma <= 1` 或 `gamma >= 2`，而直方图只允许 `gamma <= 1/2` 或 `gamma >= 2`。弱证书区域的正面结论是相对于更大的证书相关最优风险，不代表绝对估计难度反而降低。

## 有限精度、带噪切口的可实现延伸

一个固定的十二坐标编码器导出八个全局三元组频率和四个前半段行子频率，全部除以 `M`。半段位置指示、局部表、掩码和端点获取均计入成本，不免费提供额外历史。源编辑之后，允许一次向量 `l_infinity` 扰动 `delta`，再裁剪并向 `Q = 2^h` 网格下取整。切口只保留十二个标签、受保护的末端状态对及公开格式信息。

在 `beta >= c/M`，同一个不使用 `k、delta、beta` 的有理数解码器达到该**固定编码器**的最优阶

    min{1, max{M^(-1/2), k/M, delta, 1/Q}}。

新增的四个端口需要针对完整十二端口消息重新证明精度下界，不能直接沿用八端口下界。[有限切口证明及成本账本](../balanced_joint_finite_cut/BCJ001_theorem.md)

实现采用明确计费的有限顺序算术：公开表生成、所有候选边及掩码测试、宽整数乘积与累加、商余数、扫描回卷、输出序列化和切口交接都计算在内；小数位数 `h` 或 `P` 不等于总工作字宽。它证明保守的可实现性，不证明固定神经深度、训练效果、最优算力，亦不是对重新设计编码器的下界。临界带以下只保留已证明的上下界，未声称它们匹配。

## 保留失败路线与结论边界

此前的精确长游程、近常量前缀否决规则仍是有效的局部风险增量结果；一个具体攻击可以绕过固定前缀包装，说明该包装不足，却不构成所有完整历史算法的不可能性。新的平衡门控不是将同一阈值继续调大，而是使用不同的路径统计性质。[真实失败构造](../critical_beta_adaptation/CB003_fixed_veto_bypass.md)

尚未解决的包括边界窗口的精确阈值、最少需要多少位置信息，以及较弱证书下有限切口的匹配风险。已建立的通用首次命中点概率尺度有 Norris–Peres–Zhai 的先行结果；本阶段不声称该尺度的新颖性，也不作全面新颖性认证。独立 LLM 审查与有限精确诊断不等于形式验证或外部同行评审。详见[英文综合稿](positional_counts_adaptation.md)和[精确来源映射](SOURCE_MAP.json)；完整证明独立保存，本摘要不替代它们。
