A deterministic fixed-point backend for the fixed-parameter decoder

3 November 2026. Constructive numerical specification and proof; independent AI-agent analysis, not formal peer review. No random or numerical experiments were used. This version is a new file and does not alter the exact-real construction.

Scope and result. For each binary input of length N≥2, the deterministic integer algorithm below evaluates the three-block fixed-parameter construction, using exact integer positions and scores, a rigorously specified truncated exponential table, integer summation, integer division, and exact ReLU gates on fixed-point values. With L=N+2, its output Q̃ is a probability and obeys, for every word,

|Q̃−B_N| ≤ (N/2)e^(−N) + 3L^(−7),   B_N=(C_{S_N}+1)/(J_{S_N}+2).

The learned weights remain fixed; the numerical precision and the supplied positional integers grow with input length. This is a specialized arbitrary-precision integer backend, not a claim about IEEE floats, a black-box library softmax, fixed machine words, learned training, or an ordinary final vocabulary softmax.

1. Inputs and exact integer logits

Input N≥2 and the two BOS values 1/2 followed by N bits, with positions i=1,…,L and exact positional integers 1,i,i². Use precisely the source's 64 residual coordinates, four 16-dimensional heads per block, six active heads, fixed Q/K/V maps, causal mask j≤i, and FFN gates. The factor 1/4 in scaled dot product is incorporated algebraically in computing the following exact integer logits, not approximated by a square root:

Block 1, h=1,2:  s_h(i,j)=2i(i−h)j−ij².
Block 3, h∈{00,01,10,11}:  s_h(i,j)=(i−2)(g_{j,h}+b_j).

The second formula is integer-valued because the first block plus gate proof below gives g and b exactly in {0,1}. No product of position and state is supplied as an input: the backend evaluates the specified attention dot product. For every row, find the exact integer maximum among allowed j, and set m_j=max(s)−s_j≥0. Masked keys are never included. This avoids subtracting approximate large logits.

2. Executable fixed-point primitives

Let s=⌈log₂L⌉, b=16s, H=2ᵇ and F=H². Fixed-point value z means the real z/H. The following construction, which uses integer arithmetic and floor only, computes a global lookup table once per length. Multiplication, summation, subtraction, comparison, floor division and bit shifts here are exact integer operations.

z ← F − H                         # (1 − 1/H) represented at scale F
repeat b times: z ← floor(z*z/F)   # b squarings at scale F
r ← floor(H*z/F)                  # base approximating H/e
T[0] ← H
for k = 1,...,b: T[k] ← floor(T[k−1]*r/H)
weight(m): return T[m] if 0 ≤ m ≤ b, else 0.

softmax-value(logits s_j, values x_j∈{0,1/2,1}):
    a ← max_j s_j                 # over exactly the causal keys
    z_j ← weight(a − s_j)
    W ← Σ_j z_j
    V ← Σ_j z_j*(2*x_j)          # all factors integers
    y ← floor(H*V/(2*W))         # output y/H
    return y/H

At least one m_j is zero and T[0]=H, so W≥H and division cannot fail. As 0≤2x_j≤2 and all weights are nonnegative, 0≤y/H≤1. Half-BOS values are represented by the exact factor 2x_j; there is no half-bit rounding. All earlier first-head outputs are on the same H-grid. Every ReLU, integer affine gate and threshold 1/4 or 3/4 is then evaluated exactly on that grid; H is divisible by 4. All residual slots are disjoint as specified in the source. Zero heads may be skipped after their zero contributions are established.

3. Exponential-table proof

Put a=1−1/H. Since b squarings form aᴴ and each floor at scale F incurs less than 1/F, the error recurrence δ_{t+1}≤2δ_t+1/F gives |z/F−aᴴ|<H/F=1/H. For H≥2, −x/(1−x)≤log(1−x)≤−x gives e^(−1−1/(H−1))≤aᴴ≤e⁻¹. Consequently |aᴴ−e⁻¹|≤1/(H−1)≤2/H. The final base floor costs less than 1/H, so |r/H−e⁻¹|<4/H.

Let t_k=T[k]/H. Both t_k and r/H are in [0,1]. Induction from t_0=1 gives |t_k−e⁻ᵏ|≤5k/H for k≤b: each recurrence adds at most 4/H from the base and 1/H from flooring. For integer k>b, output is 0 and e⁻ᵏ<e⁻ᵇ<2⁻ᵇ=1/H. Therefore every allowed key has absolute unnormalized-weight error bounded by ε_w=(5b+1)/H, including the truncated tail. In particular max-shifted weight 1 is exactly retained.

4. Row-wise error and preserved gates

Let p be exact softmax on one allowed row and p̃ the normalized table weights before the final floor. The exact denominator and the approximate denominator are both at least 1. For any values x_j∈[0,1], direct numerator/denominator comparison yields

|Σp_j x_j − Σp̃_j x_j| ≤ 2Σ_j |e^(−m_j) − weight(m_j)/H| ≤ 2L ε_w.

The output floor adds <1/H. For s≥2, b=16s and 5b+1=80s+1≤2^(8s). Thus L ε_w≤2^s·2^(8s)·2^(−16s)=2^(−7s)≤L⁻⁷, and H⁻¹≤L⁻⁷. Every active softmax output consequently differs from its exact-real output on the same supplied values and logits by at most 3L⁻⁷.

For block 1, every source value is exact, and for target lag h with i≥4 (h=1) or i≥5 (h=2), the source bounds wrong attention mass by 2e⁻ⁱ/(1−e⁻ⁱ)≤2/(e⁴−1)<2/15. Since L≥4, the numerical perturbation is at most 3/4⁷<1/15. Total deviation is <1/5<1/4, so T(a)=2ReLU(a−1/4)−2ReLU(a−3/4) returns the exact predecessor bit. This includes the terminal lag-one bit at L=4 and both bits at candidate positions i≥5. At all other positions, the rounded head values still lie in [0,1] and T(a) lies in [0,1].

Consequently b=1 exactly at the two BOS positions, v=1 exactly at i≥5, and at invalid positions g_h=ReLU(−d_h)=0 because d_h≥0. At valid positions both predecessor bits are exact, hence each g_h is the correct binary context indicator. At the terminal position q_h is an exact one-hot encoding of (X_{N−1},X_N), including N=2. The approximate execution therefore produces exactly the same block-3 logits and terminal selector as the source's exact-real construction. The block-3 values are exactly 0, 1/2 or 1; its numerical error does not accumulate from a perturbed score.

5. Final output and N=2

At the final row each computed head lies in [0,1]. The exact one-hot q_h makes the source's final ReLU sum select exactly the corresponding computed head; the final pair (Q̃,1−Q̃) is evaluated exactly on the fixed-point grid. The row error is at most 3L⁻⁷. Combining it with the original pathwise (N/2)e⁻ᴺ soft-matching bound proves the displayed claim. For N=2 there are no valid observed triples; B₂=1/2, L=4, both BOS keys remain present and W≥H. The bound and gate proof apply directly. For a statistical risk corollary, use the trivial TV≤1 at N=2; the inherited R011 statement is applied only for N≥3, as in the boundary addendum.

Assuming the source's separately reviewed R011 risk bound, for N≥3 the uniform same-history actual-terminal risk is at most min{1, 2¹³√[32/(N−1)] +(N/2)e⁻ᴺ +3(N+2)⁻⁷}, uniformly over the source class stated there; this document does not independently reprove R011. Exact-real and finite-integer constructions both use direct output probabilities, without a further vocabulary softmax.

6. Resource accounting

  • Word sizes. Exact positions and block-1 logits have magnitude at most 3L³; shifted differences at most 6L³. Block-3 logits have magnitude at most L. Integer positions, scores, shifts and loop counters take O(log L) bits. H-grid values take b+1 bits; table construction at scale F uses at most 2b+1-bit operands and ≤4b+2-bit products. Row sums and scaled division numerators use O(b+log L) bits. There is no fixed upper bound on these widths over all lengths.
  • Work. Grade-school multiplication/division gives O((log L)²) bit operations per score, table multiplication or row division. The table uses b repeated squarings and b recurrence updates, O((log L)³) bit operations. Six active full-causal heads require Θ(L²) score/weight visits; with the row normalizations, exact gates and paid position generation, a straightforward bound is O(L²(log L)²+(log L)³) bit operations. Bit complexity, not a constant-cost real-arithmetic claim, is being charged.
  • Storage. Streaming each attention row twice, once for its maximum and once for accumulation, requires O(L log L) bits for token/position and constant-width residual arrays plus O((log L)²) bits for the length-b table. Dense Θ(L²) score storage is unnecessary. A precomputed position table, if used, is included in this bound; alternatively generate i and i² with paid integer arithmetic.
  • Mask and truncation. Causal support is exact. Exponentials for all gaps greater than b are deliberately set to zero, and their total contribution is in the error proof. There is no reliance on underflow, finite exponent range, library rounding mode or stochastic behavior.
