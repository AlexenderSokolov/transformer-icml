Four fixed-temperature heads recover the complete count bank

3 November 2026. This is a deliberately richer, explicitly specified access model. It refutes an overgeneralization of a single-output necessity result, not that result itself. No random or numerical experiments were used; no novelty or generic finite-word Transformer claim is made.

Result. With four parallel anchor-query softmax heads at fixed β=ln 2, a BOS-indicator value channel and a nonlinear ratio/inversion/readout, all binary order-two transition counts are exactly recoverable in the ideal model, including zero counts. Thus the earlier β≥(1/2)ln M−O(1) requirement for one scalar equal-temperature interpolator cannot be extended to this richer model. The richer model pays for extra heads, value channels, context formation, normalization recovery, count precision, readout, position handling and arithmetic.

1. Input and charged interface

Let X₁,…,X_N be any binary sequence, N≥2, with M=N−2 candidate triples indexed by i=3,…,N and actual terminal query s=(X_{N−1},X_N). Let J_r count triples whose predecessor pair is r∈{00,01,10,11}, and C_r count those followed by 1. Thus 0≤C_r≤J_r and Σ_r J_r=M.

For the attention stage, explicitly grant a candidate key carrying its predecessor pair r and a value carrying the observed successor bit X_i, along with one BOS key. This can be produced by a preceding causal context-copying/feature mechanism or supplied as an augmented representation; either option is an extra cost and assumption. We do not claim that ordinary finite-score attention creates exact lagged copies for free. The support comprises exactly those M candidates plus BOS, including candidate i=N and excluding unobserved X_{N+1}. The terminal pair s is separately available to the final readout and is not supplied as a different historical sample. M=0 means BOS alone.

2. Four normalized measurements and exact inversion

For each fixed anchor h∈{00,01,10,11}, a separate head assigns a candidate of context r the score β·matches(h,r), where β=ln2, and gives BOS score 0. Data values have two coordinates (X_i,0); BOS has value (0,1). The anchor queries are fixed by head, not all equal to the actual query s. Let a_h and b_h be the two resulting output coordinates. With

K_hr=2^matches(h,r),     Z_h=1+Σ_r K_hr J_r,
a_h=(Σ_r K_hr C_r)/Z_h,     b_h=1/Z_h,

the exact real-valued readout first performs the four reciprocal/ratio operations

T_h=a_h/b_h=(KC)_h,          U_h=1/b_h−1=(KJ)_h.

In order 00,01,10,11,

K = [[4,2,2,1],[2,4,1,2],[2,1,4,2],[1,2,2,4]]
  = [[2,1],[1,2]] ⊗ [[2,1],[1,2]],
K⁻¹=(1/9)[[4,−2,−2,1],[−2,4,1,−2],[−2,1,4,−2],[1,−2,−2,4]].

Its singular values are 9,3,3,1, so κ₂(K)=9 and ||K⁻¹||∞=1, independent of M. The readout computes C=K⁻¹T and J=K⁻¹U, selects the row for the actual terminal s, and returns (C_s+1)/(J_s+2). This is exactly the ordinary same-history binary add-one estimator for every input path and M, including an unseen query row. The +1,+2 are introduced by this readout; the single BOS key is used as a normalization reference, not secretly counted as two observed data points.

More generally for constant β>0, K=[[e^β,1],[1,e^β]]⊗² and κ₂(K)=((e^β+1)/(e^β−1))². The condition number blows up as β→0; β=0 makes these four score patterns identical, so the displayed inversion is unavailable. Constant nonzero β does not mean the rest of the computation is free.

3. Explicit precision cost and scope of the counterexample

Set L=1+4M. Every Z_h≤L, so b_h≥1/L. Suppose all eight real attention outputs a_h,b_h are available to the readout with absolute error at most η, and η≤1/(2L). The measured BOS coordinate satisfies b̃_h≥b_h/2. Since 0≤(KC)_h≤4M=L−1,

|1/b̃_h−1/b_h| ≤ 2ηL²,
|ã_h/b̃_h−a_h/b_h| ≤ 2ηL².

Applying ||K⁻¹||∞=1 gives each recovered count coordinate error at most 2ηL². In particular η<1/(8L²) makes each count error <1/4, so nearest-integer rounding reconstructs all eight exact counts; the add-one ratio can then be evaluated to any separately paid output precision. The BOS reference therefore becomes small as M grows: K is well-conditioned, but the nonlinear normalization recovery costs O(log M) fractional bits under this sufficient worst-case guarantee. It is not evidence that constant precision suffices, nor a proof that this precision cost is necessary for every alternative representation.

As a comparator at β=0, if a head is instead granted eight value coordinates containing the one-hot predecessor context and its product with the successor bit, uniform attention exposes all eight counts divided by its known support size. Routing, multiplication by the size, BOS or boundary conventions, and the final ratio must still be paid. This direct count-bank bypass demonstrates why a lower bound on a single scalar port cannot rule out richer value channels. The companion finite-bank construction in this research program already uses paid context features and uniform attention; the direct bank and the ordinary one-pass counter should not be portrayed as newly discovered.

Even in the four-head construction, attaining η requires explicit control of softmax evaluation, score and value rounding, masks, context-copy precision, and arithmetic in the ratios. Exact hard-copy or structural masks are separate assumptions. An O(log M)-bit real-to-integer reconstruction description is a finite arithmetic algorithm, not automatically a proof that a fixed-depth, standard ReLU Transformer with a conventional floating-point backend realizes exact division and rounding for all lengths. Dense attention reads O(M) positions per anchor and O(M) active query-key edges for the final query; a full dense causal execution can cost O(N²) per head. The key/query/value dimensions, embeddings, positional parameters and preprocessing must be specified and charged in any direct comparison.

4. What is and is not contradicted

The previous temperature necessity concerned one scalar output equal to a positive-weighted soft-match/BOS estimator, with its final readout fixed to that interpolated prediction. The present head outputs include an additional BOS normalization coordinate and four different fixed anchor queries, followed by signed inverse mixing and nonlinear ratios. It lies outside that theorem’s assumptions, so the earlier theorem remains valid. The conclusion it rules out is the proposed leap from that theorem to all multi-head networks or all values/readouts.

For the source classes where a separately established same-history add-one statistical guarantee applies, this ideal reconstruction inherits that guarantee because its result is pathwise the same estimator. That inheritance does not prove the guarantee for arbitrary nonmixing sources, model training, unspecified finite precision or a standard full Transformer.
