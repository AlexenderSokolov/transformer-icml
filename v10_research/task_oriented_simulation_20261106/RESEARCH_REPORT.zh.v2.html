一 固定过程、模型与风险

固定 c∈(0,1/2)。共同主来源类为平稳、齐次二阶二元过程，所有转移概率位于 [c,1−c]。类型投影和去扰动论证另外对任意初始符号对分布成立，均不向预测器提供未知转移核。输入仍为原始符号、公开归一化位置和合成终端；真实模型使用完整特征的 ε=1、增益 2、平移 0 的 PreLN，以及普通最终词表 softmax。

风险是同一历史上，预测概率与真实下一符号条件分布之间的期望 TV；随机性在损失内取期望。来源、输入分割、风险与计费规则不因换用“任务替代”措辞而改变。物理模型的状态、矩阵、完整偏置和单步增益先共同固定在足够大的 c 相关包络内，深度和精度按原规则计费。

上一轮硬网络的参考输出为 σ(d(s)+ρ(2F−1))，其中 s 是最后 b 位，d 只依赖该后缀，ρ≈b−1/2，F 为全历史二次奇偶位。真实输出与参考输出的统一误差为 ζh。它的最坏风险 Θc(ρ) 趋零，但小风险比例精度的完整输出模拟需要 Ω(N) 通信。

二 通用的风险改进投影，不等于免费计算

把历史按初始符号对、八个三元组计数及末端符号对分类。齐次二阶来源的每条历史概率为初始对概率乘各转移概率的计数次幂，因此同一类别中的条件分布对所有未知来源都是同一个均匀分布。零概率类别按组合意义定义即可，不在零概率事件上强行条件化。

对任意预测器 Q，在每个类别中平均它的概率向量，得到 ΠQ。目标下一符号条件分布在该类别中固定，TV 的凸性给出：

对每个转移核 p 和初始分布 μ，Rp,μ(ΠQ) ≤ Rp,μ(Q)。

这是经典充分统计量与 Rao–Blackwell 思路的直接应用，不依赖待证的风险资源下界。但不能把它免费装入固定神经网络：一般类别平均可能需要指数级计算，也未证明保留原宽度、深度或精度。

统计量虽然只有 O(log N) 位描述，分布式获取并不自动便宜。在 AA/BB 划分下，用四位块 (ai,ai,bi,0) 编码，111 的计数正好是 Σaibi。精确获取整个类型因此需要 Ω(N) 最坏历史交互通信。这里只是最坏历史结论，没有把这些编码输入冒充真实来源的平均分布。

三 有限词证书：对特定扰动建立非循环比较

八位词给出保来源概率的改写

词 00110000 与 00011000 都以 00 开始和结束，内部三元组计数相同，却翻转 F 的相位。在初始对之后、后缀之前划分不重叠的八位块；找到首个匹配这两个词之一的块，并互换它们。

这一操作是可逆的对换，保留整个历史的二阶类型、初始对、后缀及终端目标；因此对每个未知齐次来源都保留概率。按这两个输出的轨道求平均，风险精确不增。但这个轨道平均本身还不被宣称可廉价执行。

每个块匹配两词的条件概率至少为 2c⁸，无需块间独立。因此完全没有可交换块的概率至多 (1−2c⁸)⌊(N−b−2)/8⌋。有匹配块时，轨道平均恰好只依赖末端后缀。

五位词给出更强的相位收缩

另一个证明保留“最后两位＋累计位数奇偶”这八个状态，追踪带符号概率。词 11000 与 01100 达到相同状态，符号贡献相反，每条路径概率至少 c⁵。由此得到：

B5=(1−2c⁵)⌊(N−b−2)/5⌋，Es|E[(-1)F | s]| ≤ B5。

五位块会改变时间奇偶，证明对两种起始相位分别成立。这里控制的是平均绝对条件偏差，不是每个后缀上的逐点偏差。五位词不必具有相同的边界条件似然，不能未经证明就把它们当成前述精确保概率的类型改写。

四 b/2 位通信的任务替代

令

qsym(s)=[σ(d(s)+ρ)+σ(d(s)−ρ)]/2。

这个确定性的概率平均不需要未知来源。AA/BB 划分下，N 为 4 的倍数、b 为至少 4 的二次幂时，只需 Alice 发送她的 b/2 个后缀位；Bob 重建后缀并计算两个公开概率分支。目标只取决于末端符号对，所以 TV 凸性与相位证书给出逐来源比较：

RP(qsym) ≤ RP(Qphys) + ζh + (ρ/4)B，

其中 B 可取五位证书、八位证书所得上界的较小值。逻辑比较中的相位项指数小，但物理比较仍有 ζh，不能把整个物理风险增量说成指数小。

这没有推翻原输出模拟下界：qsym 是两个分支的中点，在每个历史上距原参考输出至少 κcρ，距真实输出至少 κcρ−ζh。它故意不满足旧的精细输出模拟要求，却在任务风险上几乎不差。

这里返回的是两个概率的确定性平均。随机选一个分支，或直接平均 logits，都不是同一个结果。通信协议允许通常的数学本地计算；O(b) 计数／读出加两次 sigmoid 的实数运算量不等于已证明的位复杂度。

五 同一真实模型中的单读替代与排除约束

令旧基线 q0(s)=σ(d(s))。由于 |σ″|≤1/4，两个分支的一阶项抵消：

|qsym−q0| ≤ ρ²/8。

把原有单读后缀算法与同一对数读出重新正确编译成 Qbase，使统一误差为 ζb，可得：

RP(Qbase) ≤ RP(Qphys) + ζh+ζb+(ρ/4)B+ρ²/8。

这是固定宽度、一次有用标量读取、Oc(log N+b) 深度、全部 LN 增益为 2、普通 softmax 的真实网络。不能直接删除旧物理网络的寄存器，因为完整特征 LN 会耦合它们；证明重新处理共同状态范围、准备向量、清零与振幅选择。

取 b≈log N、ζh,ζb=Oc(b−2)，额外风险为 Oc(b−1)=o(ρ)。由于原硬网络最坏风险为 Θc(ρ)，单读替代不差于其 (1+o(1)) 倍。这里不是每个来源上的乘法比值，也不是廉价版本的精确零误差风险支配。

可核验而非空的排除条件

要求输出在上述前缀局部对换下的最大变化不超过 δN=o(ρ)。物理单读基线的变化至多 2ζb，所以可满足该约束；硬扰动网络在匹配历史上的变化至少为 2κcρ−2ζh，所以被排除。无匹配块时把变化模量定义为 0，非平凡排除用于至少存在一个完整块的情形。

这是固定 N 的有限输出属性，可由显式结构证明或穷举验证，但没有提供高效的通用神经网络验证器。其他无益或难计算函数可能仍满足这一个改写约束；不能据此自动推导一般廉价模拟、最弱约束或统计最优性。

六 改成任务风险仍须避免等价命题中的循环

对同一个平稳内点来源类、AA/BB 单向协议、公开资源尺度 1≤S≤N，以下两类存在性命题仍等价，常数可以改变：

  • 每个架构成员都满足 R(Q)≥ac/√S。
  • 对每个有效的正公开风险上界 r>0 且 r≥R(Q)，存在一个不知来源的协议，通信至多 KS，任务风险至多 λr。

这里任意固定 λ≥1 都成立，包括 λ=1。通用后缀预测器只给出 O(r−2) 通信；把它写成 O(S) 已经使用了待证的风险下界。若所需后缀比 N 更长，必须发送全部输入并计算原 Q，不能简单截断一个未必满足 r 的估计器。

直接测试下界使用 δ=λr，并保留 δ≤min{1/128,(1−2c)/8}，确保所有测试来源仍在同一内点类。它是单向结果，不能未经证明推广到二阶二元过程的交互任务协议。

本轮的正面比较没有假设所有网络具备廉价替代。它明确使用了后缀双分支形式、有限相位状态和具体路径证书，因此不是把一般等价命题当作免费定理。范围更大的模型类，尤其包含增长宽度见证时，必须重新核对 S 的含义。

# Source-independent task simulation by cancelling the quadratic nuisance

6 November 2026 UTC. Private analytical candidate v1, frozen for independent exact-file review. This is a structure-specific task-risk theorem, not a general simulator for repeated-attention networks and not a new estimator or statistical rate. No scientific executable, numerical diagnostic, model execution, training, upload, or public mutation was performed. The finite word certificates below are derived symbolically. File inspection, writing, and hashes are administrative only. No literature-priority claim is made.

## 1. Result and the distinction it establishes

The reviewed quadratic-nuisance construction has a source-independent reference output whose first probability is

    Q_ref(1 | x) = sigmoid(d(s) + rho(2F(x)-1)),
    s = x_(N-b+1:N),
    F(x) = sum_(odd k <= N) x_k sum_(j<k) x_j  (mod 2).       (1)

Here N is divisible by four, b is a power of two with 4<=b<=N/2, rho>0 is public, and the public function d depends only on the final b raw symbols. The source kernel is not an input to d. The actual physical network satisfies

    sup_x TV(Q_phys(x),Q_ref(x)) <= zeta_h.                  (2)

Define one deterministic source-independent task predictor by averaging the two branch probability vectors, not their logits:

    q_sym(1 | s) = [sigmoid(d(s)+rho)+sigmoid(d(s)-rho)]/2,
    q_sym(0 | s) = 1-q_sym(1 | s).                         (3)

For every homogeneous binary second-order source whose two next-bit probabilities at every context are at least c>0, and for every initial-pair law separately,

    R_P(q_sym) <= R_P(Q_ref) + (rho/4) B_(N,b,c),
    R_P(q_sym) <= R_P(Q_phys) + zeta_h + (rho/4) B_(N,b,c), (4)

where R_P is expected next-symbol total-variation loss on the same history, and either of the following explicit bounds is valid:

    B8 = (1-2c^8)^floor((N-b-2)/8),
    B5 = (1-2c^5)^floor((N-b-2)/5),
    B_(N,b,c) = min(B8,B5).                                (5)

The eight-symbol certificate is the proposed route. A shorter five-symbol certificate strengthens it and works in either starting time parity. Both proofs appear below. The constants are deliberately conservative; no optimal contraction rate is asserted.

Under the original AA/BB ownership, Bob obtains the full suffix when Alice sends her suffix bits. This costs exactly b/2 bits for the displayed N,b domain, and at most b bits without using the alignment. He then evaluates (3) locally. This is a task simulator: it nearly preserves the original predictor's statistical risk, but need not approximate its output. In fact, for the reviewed nuisance amplitude and logit interval, its distance from that output is of order rho on every history.

There is also a replacement inside the same neural model, rather than merely a communication protocol. Let q_0(1 | s)=sigmoid(d(s)). The existing one-read suffix reference, with the same bounded-log circuit and a separately correct PreLN compilation, gives a one-useful-scalar-head physical predictor Q_base with uniform error zeta_b from q_0 and

    R_P(Q_base) <= R_P(Q_phys)
                   + zeta_h + zeta_b
                   + (rho/4) B_(N,b,c) + rho^2/8.         (6)

For b=Theta(log N), rho=Theta(b^(-1/2)), and zeta_h,zeta_b=O_c(b^(-2)), the excess in (6) is O_c(b^(-1))=o(rho). The old hard predictor has worst-source risk Theta_c(rho), so this old one-head baseline is no worse than (1+o(1)) times that worst-source risk. No source-wise multiplicative comparison is asserted: the lower risk bound used for this ratio holds for the worst-source risk, via fair IID, rather than for every source individually.

Thus the known output-simulation obstruction survives while a cheap, architecture-contained task replacement is certified. The certification uses the explicit nuisance structure and source positivity, not an assumed risk/depth lower bound.

## 2. Source, input, target, and risk contract

Fix c in (0,1/2). Let M_c be the family of all laws with arbitrary initial-pair distribution mu on {0,1}^2 and a homogeneous order-two kernel p satisfying

    c <= p(y | a,b) <= 1-c

for every a,b,y in {0,1}. The stationary interior class P_c from the prior nuisance theorem is a subclass. Here initial-pair probabilities may be zero, and no mixing or stationary initial law is assumed.

The raw input is the actual length-N sample X. No communication-specific encoding is inserted. The next-symbol target on history x is

    tau_p(x) = p(. | x_(N-1),x_N).

Because b>=2, this target is a function of the retained suffix s for each fixed p. Its value is unknown to the task predictor, and neither p nor mu is supplied to the simulator or network.

For a possibly randomized prediction rule A, define

    R_(p,mu)(A) = E_X E_U TV(A(X,U), tau_p(X)),             (7)

where U is independent predictor randomness and TV is inside both expectations. The construction (3) is deterministic. Sampling one of its two branches would be a different prediction rule under (7), and would not obtain the Jensen improvement claimed here.

The phase and cancellation proofs only need N-b>=2 and b>=2. The more restrictive N=4n and power-of-two b are retained when importing the reviewed network and its AA/BB communication lower. Nothing in the cancellation step uses stationarity. The old suffix statistical guarantee itself holds for arbitrary initial-pair laws, so its standard O(b^(-1/2)) upper can also be used on M_c; the all-history physical approximation is independent of the sample law.

## 3. Signed state recursion

All parities in this section are in F_2. For t>=2 let

    S_t = sum_(j<=t) X_j (mod 2),
    F_t = sum_(odd k <= t) X_k sum_(j<k) X_j (mod 2),
    A_t = (X_(t-1),X_t,S_t) in {0,1}^3.

The eight-state signed row vector

    v_t(a) = E[(-1)^F_t 1{A_t=a}]                         (8)

has l1 norm at most one. At t=2, F_2=0 and S_2 is determined by the initial pair, so in fact ||v_2||_1=1 for every mu.

When a new bit y is appended after time t, the state and phase updates are

    (a,b,s) -> (b,y,s+y),
    F_(t+1)-F_t = 1{t+1 is odd} y s.                     (9)

The probability of this transition is p(y | a,b). Thus the one-step signed kernel K_t has entries

    K_t((a,b,s),(b,y,s+y))
        = p(y | a,b) (-1)^[1{t+1 odd} y s],              (10)

and zero elsewhere. If destinations ever coincide their contributions are summed; for the one-step binary update the two destinations are distinct. Equation (9), the order-two Markov property, and conditioning on the present state give

    v_(t+1) = v_t K_t.

Every row has absolute sum one, so ||v K_t||_1<=||v||_1 for any signed row vector v. The same holds for any product of one-step kernels. The prefix parity S_t is essential: conditioning on the last pair alone would not determine the future contribution to F.

For a fixed length-l future word w=(w_1,...,w_l), its phase increment from a start with prefix parity s is

    Delta_(t,s)(w)
      = sum_(j: t+j odd) w_j [s+sum_(i<j) w_i] (mod 2). (11)

Its endpoint state is determined by the old state and w. Because every transition probability is at least c, its conditional probability from every starting state is at least c^l. This remains true for starting states not reachable under a particular mu; those states can harmlessly be retained in the matrix norm bound.

## 4. The eight-symbol cancellation certificate

At an even starting time t, take the two future words

    w  = 00110000,
    w' = 00011000.                                      (12)

Both end in the last pair 00, both contain two ones, and therefore both end in state (0,0,s), independently of the starting pair. In w the ones occupy local positions 3 and 4. Its only odd-position one is at position 3, with no preceding one, so

    Delta_(t,s)(w) = s.

In w' the ones occupy local positions 4 and 5. Its only odd-position one is at position 5, with exactly one preceding one, so

    Delta_(t,s)(w') = s+1.                              (13)

Their contributions to the same signed-kernel entry have opposite signs. Each path has probability at least c^8.

For completeness, at an odd starting time the selected local positions are even. Then w contributes s+1 and w' contributes s. Thus the cancellation actually works in either starting phase, although the eight-step blocks starting at 2+8j are all even and need only (13).

Let K be the signed eight-step kernel from any one block. Fix a starting state a. All 2^8 path masses sum to one before signs. If the two paths in (12) have probabilities alpha,beta, replace their signed contributions at their common destination by their sum, whose absolute value is |alpha-beta|. Apply the triangle inequality to every remaining contribution. Therefore

    sum_z |K(a,z)|
        <= 1-alpha-beta+|alpha-beta|
         = 1-2 min(alpha,beta)
        <= 1-2c^8 = gamma8.                            (14)

Additional cancellations can only decrease this bound. For every signed row vector,

    ||v K||_1 <= gamma8 ||v||_1.                         (15)

Put t_*=N-b and k8=floor((t_*-2)/8). Starting at time 2, apply k8 complete eight-step blocks and then the fewer than eight remaining one-step kernels. The latter are nonexpansive. Consequently

    ||v_(t_*)||_1 <= gamma8^k8 = B8.                    (16)

This is a signed-phase cancellation estimate, not merely an ordinary Markov-context mixing estimate.

## 5. A five-symbol improvement

A shorter certificate uses

    u  = 11000,
    u' = 01100.                                        (17)

Again both words have two ones, both end in pair 00, and both end in the same full state (0,0,s). If t is even, the selected local positions are 1,3,5. Word u contributes s at its first position; word u' contributes s+1 at its third position. If t is odd, the selected positions are 2,4. Word u contributes s+1 at its second position, whereas u' contributes s there. In both cases the increments differ by one, independently of the starting pair and s.

Each path probability is at least c^5. The argument in (14) now gives row absolute sum at most

    gamma5 = 1-2c^5.                                    (18)

A five-step block flips the time parity, so its signed kernel need not be the same as the preceding block's kernel. This causes no problem: each of the two phase-specific kernels obeys the same induced-l1 contraction bound. A product of k5=floor((N-b-2)/5) such kernels, followed by fewer than five nonexpansive steps, gives

    ||v_(N-b)||_1 <= gamma5^k5 = B5.                    (19)

The proof does not incorrectly identify these alternating matrices as a single time-homogeneous signed kernel. Taking the smaller of the two independently established bounds yields (5).

## 6. Retaining the full suffix without losing the estimate

A bound on the unconditional phase mean alone would not be enough, because the baseline and target depend on the suffix. The needed quantity is the average absolute conditional phase bias.

For each suffix word z in {0,1}^b, let H_z be the signed kernel that appends exactly z after time t_*=N-b, including its full contribution to F. From each starting state there is one deterministic state path for that fixed word. Its nonzero signed entry has absolute value equal to that word's conditional probability. Hence for every starting state a,

    sum_z sum_e |H_z(a,e)| = 1.                         (20)

Let

    B(z) = E[(-1)^F_N 1{X_(N-b+1:N)=z}].

Tracking the signed mass through the specified suffix gives

    B(z) = v_(t_*) H_z 1.

Using (20) and the triangle inequality,

    sum_z |B(z)|
      <= sum_z ||v_(t_*) H_z||_1
      <= ||v_(t_*)||_1
      <= B_(N,b,c).                                    (21)

For every positive-probability suffix define beta(z)=E[(-1)^F | suffix=z]. Set beta arbitrarily on null suffixes, which contribute nothing. Equation (21) is exactly

    E_suffix |beta(suffix)| <= B_(N,b,c).              (22)

This is an average over suffixes. It does not assert the same bound for every individual suffix, and no division by a possibly tiny suffix probability is used. In the present positive-transition class every suffix has positive probability once enough transitions precede it, but that observation is unnecessary for the proof or the null-event convention.

The argument accounts for every term of F, including terms involving one prefix bit and one suffix bit. Those terms are handled by the retained S_t state and the signs in H_z. Simply dropping the suffix's phase contribution would be invalid.

## 7. Convex loss comparison, with all constants

For a fixed suffix z, write

    a_+(z)=sigmoid(d(z)+rho),
    a_-(z)=sigmoid(d(z)-rho),
    m(z)=(a_+(z)+a_-(z))/2,
    p_z=p(1 | final pair of z),
    L_+(z)=|a_+(z)-p_z|,
    L_-(z)=|a_-(z)-p_z|.

Since (-1)^F is +1 on F=0 and -1 on F=1,

    Pr(F=1 | z)=(1-beta(z))/2,
    Pr(F=0 | z)=(1+beta(z))/2.

The reference conditional risk is therefore

    E[|Q_ref(1)-p_z| | z]
      = (L_+(z)+L_-(z))/2
        + beta(z)(L_-(z)-L_+(z))/2.                    (23)

Convexity of absolute value gives

    |m(z)-p_z| <= (L_+(z)+L_-(z))/2.

The reverse triangle inequality and sigmoid derivative bound give

    |L_+(z)-L_-(z)| <= a_+(z)-a_-(z) <= rho/2.          (24)

Combining these inequalities,

    |m(z)-p_z|
      <= E[|Q_ref(1)-p_z| | z] + (rho/4)|beta(z)|.

Averaging and applying (22) proves the first inequality in (4). In fact the proof establishes the slightly sharper source-specific bound

    R_P(q_sym)-R_P(Q_ref)
       <= (1/2) sum_z |B(z)| [a_+(z)-a_-(z)].           (25)

Since TV between binary distributions equals the absolute difference of their first probabilities, the notation in (7) agrees exactly with these calculations. Finally (2) and the triangle inequality yield

    R_P(Q_ref) <= R_P(Q_phys)+zeta_h,

which proves the second inequality in (4). All these statements hold for each p,mu separately with the same function q_sym; taking a supremum over any chosen source subclass preserves them.

### General two-branch form

The decision-theoretic step does not depend on logits. Suppose a target tau_P is measurable with respect to a retained statistic Z, and Q(x) selects either of two source-independent probability vectors A_+(Z), A_-(Z) according to a sign variable. If

    E_P |E_P[sign | Z]| <= delta_P,

then the deterministic midpoint M(Z)=(A_+(Z)+A_-(Z))/2 satisfies

    R_P(M) <= R_P(Q)
               + (1/2) E_P[|E_P[sign | Z]|
                              TV(A_+(Z),A_-(Z))].     (26)

To prove it, apply convexity of TV and the reverse triangle inequality for a metric exactly as in (23)-(24). A uniform branch gap G gives excess at most G delta_P/2. This is a source-wise comparison for a source-independent map. A certifiable source-uniform bias bound, not knowledge of the actual source, is what makes it useful here.

A finite paired-path certificate is a sufficient way to obtain such a bias bound: augment the source context by the finite state needed to update the sign; exhibit, from every starting state and relevant time phase, two fixed-length positive-probability paths with the same augmented endpoint and opposite sign increment. If each path has probability at least a>0, every block contracts signed l1 mass by at most 1-2a. The explicit words above provide that certificate for this particular quadratic phase. This is not a claim that arbitrary nuisances have such a certificate.

# A local type-preserving involution and a nonvacuous nuisance-exclusion certificate

6 November 2026 UTC. Candidate v2; v1 is preserved. This revision states the prefix-domain and empty-event conventions explicitly. Symbolic proof only, with no executable, experiment, training or upload. This complements the signed-kernel proof in SYMMETRIC_QUADRATIC_NUISANCE_REMOVAL v1. It does not overwrite that frozen source or claim a general statistical frontier.

## 1. Same process, retained suffix, and explicit rewrite

Use the reviewed nuisance reference Q_ref with first probability sigmoid(d(s)+rho(2F-1)), where s is the final b-bit suffix, b>=2, and F=sum_(odd k<=N) x_k sum_(j<k)x_j mod2. The target is the unknown homogeneous binary second-order next law at the actual terminal pair. For the imported physical family keep N divisible by four, b a power of two, 4<=b<=N/2. The physical comparison is sup_x TV(Q_hard(x),Q_ref(x))<=zeta_h.

Assume N-b>=2. Partition the first 8k raw symbols AFTER the initial pair into k disjoint blocks of length eight, where

 k=floor((N-b-2)/8).

Every such block lies entirely before the retained suffix. Let w=00110000 and w'=00011000. Their internal triple-count vectors agree: 001,011,110,100 occur once each, 000 occurs twice, and the other triples occur zero times. Both start with 00, end with 00, and contain two ones.

Let G be the event that at least one of these disjoint blocks is either w or w'. Define a deterministic map iota on all N-bit words: on G, interchange w and w' in the FIRST such block; on G complement, leave the word unchanged.

This is an involution. The selected block's membership in {w,w'} is unchanged, so the same block is selected on the second application. Earlier and later blocks are untouched. The initial pair and the complete final b-bit suffix are preserved.

## 2. Exact preservation of every homogeneous Markov law

Changing the selected block preserves all internal triple counts. The first two and last two block symbols are identical in w,w', so every triple crossing either boundary is also unchanged. Therefore the whole word's initial pair, eight triple counts and final pair are unchanged by iota.

For any homogeneous binary order-two kernel p and any initial law mu, including zero probabilities,

 P_(p,mu)(x)=mu(x_1,x_2) product_(a,b,c) p(c|a,b)^(C_abc(x))
           =P_(p,mu)(iota x).

Thus iota preserves EVERY source measure in this model, not merely a selected IID law. This equality uses homogeneity; it is not inferred merely from positivity. The signed-kernel proof separately gives a cancellation estimate without relying on equal word probabilities.

The selected block starts after an even time 2+8j. If the incoming prefix parity is S, w contributes S to F while w' contributes S+1. The two ones leave the outgoing prefix parity unchanged. Consequently later contributions to F are unchanged, and

 F(iota x)=F(x)+1 mod2 on G.

This is a full-history phase identity, not just a comparison of the block's isolated polynomial. The retained suffix, and hence d(s) and the true terminal context, remain unchanged.

## 3. Exact risk domination on rewrite orbits

Define the public source-independent predictor

 Q_orbit(x)=[Q_ref(x)+Q_ref(iota x)]/2.

For any fixed source, the target law is identical at x and iota x because their terminal pairs agree. Convexity of TV and source-measure preservation therefore give

 R_(p,mu)(Q_orbit) <= R_(p,mu)(Q_ref)

for every kernel and initial law separately. No risk envelope, unknown parameter, statistical rate lower, or source-specific conditional expectation is needed. This is a small explicit orbit projection, not averaging over an exponentially large full Markov type class.

On G, the two branches have opposite F and the same d, so Q_orbit equals the suffix-only midpoint q_sym. On G complement, iota is the identity and Q_orbit equals Q_ref. Thus

 TV(q_sym(x),Q_orbit(x)) <= (rho/4) 1_(G complement).

The factor follows from sigmoid's derivative bound: the gap of the two branches is at most rho/2, and the midpoint is half that gap from either branch.

If all transitions have both probabilities at least c>0, conditional on any past each next eight-bit block has probability at least c^8 of being w and at least c^8 of being w'. These are disjoint words. Repeated conditioning, without assuming independent blocks, gives

 P_(p,mu)(G complement) <= (1-2c^8)^k.

Therefore

 R_P(q_sym) <= R_P(Q_ref)+(rho/4)(1-2c^8)^k
             <= R_P(Q_hard)+zeta_h+(rho/4)(1-2c^8)^k.

This independently proves the eight-word part of the signed-state result. It also explains why task averaging can help while complete-output approximation stays hard: typical rewrite orbits contain both separated output branches, and their midpoint has no worse averaged loss even though it remains far from either original output.

Q_orbit itself is not claimed to be a cheap neural or communication implementation. It still evaluates the original reference on unmatched histories. The cheap task predictor is q_sym, which needs only the suffix and tolerates the explicitly bounded exceptional set. This distinction prevents moving an unproved expensive computation into the simulator.

## 4. A checkable restriction that excludes the specific nuisance

Consider the output-rewrite modulus

 J_N(Q)=sup_(x in G) TV(Q(x),Q(iota x)),

with the explicit convention J_N(Q)=0 when G is empty.

For fixed N this is a finite, precisely specified property of the complete input-output function. An explicit invariance proof or exhaustive finite evaluation can verify it; no efficient generic neural verifier is provided. Defining J_N is not a resource bound and computing it is not free.

Every LOGICAL suffix-only predictor has J_N=0, because iota fixes the suffix. In particular q_0=sigmoid(d(s)) is exactly invariant. A correctly compiled physical one-head baseline Q_base with uniform error zeta_b from q_0 obeys

 J_N(Q_hard)>=2kappa_c rho-2zeta_h

whenever G is nonempty, as it is for k>=1. Indeed the same lower holds for each matched pair. This is a simultaneous risk-domination theorem, not a statement that the new predictor approximates the old predictor's output. It needs no advertised risk bound, no known source parameter, and no inference of the desired depth-risk rate. It therefore does not repeat the risk-scale simulation equivalence in the prior work.

The projection has three important limitations:

1. The sufficient statistic has an O(log N)-bit description, but computing it from the original distributed AA/BB raw-input ownership requires Omega(N) worst-case communication, even with arbitrary interaction and bounded error. A low-dimensional statistic is not thereby a cheap distributed statistic.
2. Computing the projected predictor from the statistic can require an exponential type-class average. No efficient evaluation algorithm is supplied for an arbitrary predictor.
3. The projection is not proved to preserve a frozen neural architecture, width, paid depth, parameter precision, or normalization contract. It does not show that a fixed-depth architecture contains its own risk-improved projections.

An exact type-invariance requirement excludes the specific raw-history quadratic parity nuisance from the reviewed construction. It does not by itself imply cheap communication, remove all possible nuisance, or prove a statistical depth lower.

## 2. Model and statistic

Fix N >= 3 and alphabet {0,1}. Let p(c | a,b) be any homogeneous second-order transition kernel and let mu(a,b) be any initial-pair law. No stationarity, mixing, positivity, or relation between p and mu is needed for the theorem. A stationary interior class P_c is a permitted subclass.

For a word x=(x_1,...,x_N), define its eight triple counts

    C_abc(x) = sum_(i=3)^N 1{(x_(i-2),x_(i-1),x_i)=(a,b,c)},

its initial pair I(x)=(x_1,x_2), and its final pair E(x)=(x_(N-1),x_N). Keep both endpoint pairs explicitly and set

    T(x) = (I(x), (C_abc(x))_(a,b,c in {0,1}), E(x)).       (1)

Let H_t={x in {0,1}^N : T(x)=t}. Only nonempty H_t are used. The statistic has at most 16(N-1)^8 possible encodings, and can be represented by

    4 + 8 ceil(log2(N-1))

bits using fixed-width integer counters. This is a deliberately loose encoding bound. The eight counts have sum N-2 and obey additional flow constraints.

The next-symbol target distribution is

    tau_p(x) = p(. | E(x)),

and is constant on each H_t for every fixed p. The pair remains unknown only in the usual sense that it must be obtained from the sample; the source kernel is never given to the predictor or its projection.

### Endpoint redundancy, without a degenerate exception

Regard each triple abc as a directed edge ab -> bc on the four pair states. For every valid word and every pair v,

    out_C(v) - in_C(v) = 1{I=v} - 1{E=v}.                (2)

Consequently the vector 1{E=v} is recovered exactly as

    1{E=v} = 1{I=v} - out_C(v) + in_C(v).

Thus the initial pair and all eight counts already determine the final pair for every valid word. In the balanced case the final pair equals the initial pair; there is no exceptional valid-word degeneracy. Keeping the final pair in (1) makes target measurability explicit and does not change the type partition. Arbitrary integer tuples not arising from a word are outside the definition.

## 3. Uniform conditional law within each type

The probability of a history is

    P_(p,mu)(X=x)
      = mu(I(x)) product_(a,b,c) p(c | a,b)^(C_abc(x)).  (3)

Use the usual convention that a factor with exponent zero is one, including when its base is zero. For fixed t, the right side has a common value lambda_(p,mu)(t) for every x in H_t. Therefore

    P_(p,mu)(T=t) = |H_t| lambda_(p,mu)(t).

Whenever this probability is positive,

    P_(p,mu)(X=x | T=t) = 1/|H_t|,  x in H_t.           (4)

The conditional kernel in (4) is the **same** for all p and mu. If a source assigns probability zero to H_t, the conditional law there need not be defined probabilistically; the uniform law on that nonempty combinatorial fiber still defines the projection below. Such fibers contribute zero to that source's risk. This handles zero transition probabilities and zero initial-pair probabilities without conditioning on null events.

In a strictly positive transition class, an initial-pair law can still have zero entries. The same null-fiber treatment applies. If the class also requires a stationary full-support initial law, every nonempty type has positive probability, but this stronger property is unnecessary.

Equation (4) is a sufficiency statement for the family of complete sample laws, including the unknown initial-pair law. It remains true when mu is constrained to depend on p, such as under stationarity: within a type, that factor remains constant.

## 4. Source-independent projection and simultaneous risk domination

Let Q:{0,1}^N -> Delta({0,1}) be any fixed source-independent predictor. Define

    (Pi Q)(x) = qbar(T(x)),
    qbar(t) = (1/|H_t|) sum_(y in H_t) Q(y).             (5)

This is a normalized binary distribution and is source independent. Its definition uses only Q and the combinatorial type classes, not p, mu, their likelihood values, or an advertised risk envelope.

For each source, each positive-probability type t, and its final pair e(t), convexity of total variation in its first argument gives

    TV(qbar(t), p(. | e(t)))
       <= (1/|H_t|) sum_(y in H_t)
                      TV(Q(y), p(. | e(t))).           (6)

Using (4), this is exactly the conditional risk inequality. Averaging over T yields

    E_(p,mu) TV((Pi Q)(X), p(. | E(X)))
       <= E_(p,mu) TV(Q(X), p(. | E(X))).               (7)

The same Pi Q obeys (7) simultaneously for all kernels and initial laws. In particular, for any chosen family P,

    sup_(P in P) R_P(Pi Q) <= sup_(P in P) R_P(Q).      (8)

For a randomized predictor Q(X,U) whose private/public randomness U is independent of the source and sample, first average its output over U in (5). Jensen over both U and the uniform type fiber proves (7), with the original risk including expectation over U. The result concerns the average probability vector, not a random draw from the mixture with TV measured after that draw.

The argument extends to any prediction loss convex in the predicted distribution, provided the true target is constant within the type for each parameter. No strict improvement is guaranteed, because TV is not strictly convex.

### Projection identity and statistical completeness

Pi is idempotent: Pi(Pi Q)=Pi Q. Its fixed points are exactly the type-invariant maps

    T(x)=T(y) implies Q(x)=Q(y).                         (9)

Hence, with no architectural or computational constraint, restricting predictors to type-invariant ones does not change the minimax risk over any source subfamily: this follows from (8) and from inclusion of the restricted class in the full class. This statement is not asserted for a fixed neural architecture, which may fail to contain Pi Q.

A formal implementation of (5), given T and public access to Q, enumerates binary words in the fiber and averages their outputs. Enumerating all 2^N words and testing their types suffices. This is an existence construction with potentially exponential local computation, not an efficient compiler.

## 5. This need not approximate Q at all

There is no conclusion of the form

    TV(Pi Q(x),Q(x)) is small,

pointwise or on average at a prescribed fraction of Q's risk. Projection can discard information on which Q deliberately depends. A type-invariant output is identical for every member of a fiber even when Q has separated outputs on that fiber.

Thus (7) is a task-oriented domination relation. It is distinct from the earlier requirement to simulate the complete predictor at error kappa times its risk. Neither direction in RISK_SCALE_SIMULATION_EQUIVALENCE.candidate.v1.md is invoked here, and (7) contains no hidden assumption that the desired risk/depth lower already holds.

To use the projection to prove a depth lower, one would still need an independent architecture-controlled communication procedure for a risk-dominating output, or a different suitable statistical argument. The theorem supplies the domination, not the communication procedure.

    C_001=C_011=C_110=C_100=1,
    C_000=N-6,

### What a type-invariance restriction does and does not certify

The condition (9) is finite and mathematically checkable for a fixed N by comparing outputs on all fibers. ## 7. An O(log N)-bit statistic with Omega(N) distributed communication

Retain the original raw AA/BB ownership: for N=4n, Alice owns positions 4i-3 and 4i-2, and Bob owns 4i-1 and 4i. Consider a protocol that, on every binary history, outputs the exact full statistic T at Bob with probability at least 2/3, using at most C bits in the worst case over inputs and coin tapes. Arbitrary interaction and local computation are allowed; communication is a standard binary protocol tree, with no free timing/silence channel.

Given independent communication inputs a,b in {0,1}^n, form the raw history blockwise as

    (x_(4i-3),x_(4i-2),x_(4i-1),x_(4i))
       = (a_i,a_i,b_i,0).                              (15)

Each party can generate exactly its own owned raw positions using only its local input. Every triple ending or crossing through a zero at position 4i fails to be 111. The sole possible 111 triple associated with block i starts at 4i-3 and equals (a_i,a_i,b_i). Hence

    C_111(x) = sum_(i=1)^n a_i b_i,                    (16)

including the first and last blocks, with no boundary correction. Computing T therefore computes binary inner product

    IP_n(a,b) = C_111(x) mod 2.

This reduction does not change the raw input alphabet or the ownership split. It merely selects a set of worst-case raw histories.

### Elementary interactive lower bound

Let H_(a,b)=(-1)^(a dot b) for a,b in {0,1}^n. Orthogonality of binary characters gives

    H H^T = 2^n I,    ||H||_op = 2^(n/2).

For a rectangle R=A times B, under uniform independent a,b,

    |E[1_R (-1)^IP_n]|
      = 2^(-2n) |1_A^T H 1_B|
      <= 2^(-3n/2) sqrt(|A||B|)
      <= 2^(-n/2).                                    (17)

A deterministic C-bit interactive protocol has at most 2^C transcript rectangles. If Bob's last answer depends on his own input within a transcript rectangle, split that rectangle according to his output bit, producing at most 2^(C+1) constant-answer rectangles. Its correlation with the correct sign is therefore at most

    2^(C+1-n/2).

If its distributional error under uniform independent a,b is at most 1/3, this correlation is at least 1/3. Thus

    C >= n/2 - 1 - log2(3) = N/8 - 1 - log2(3).        (18)

A randomized protocol with worst-case success at least 2/3 has average error at most 1/3 under that input law. Fixing all public/private coins yields a deterministic protocol with no larger average error and the same worst-case bit cap. Therefore (18) applies to the randomized protocol too.

The standard exact-computation upper is for Alice to send all her N/2 raw bits, after which Bob reconstructs the history and computes T. Thus the worst-case communication complexity of this task is Theta(N), despite the O(log N)-bit size of its output. The same lower applies to a protocol estimating C_111 to absolute error strictly below 1/2 with the displayed success guarantee, because rounding recovers it.

### Scope of this lower

Equation (18) is **not** a source-average lower under the unknown Markov model, nor under fair IID raw histories. The distribution generated by independent a,b in (15) imposes duplicate Alice bits and fixed zeros. It need not be the law of a homogeneous binary second-order source, and it is not the fair-IID raw law. Positivity/full support of an admissible Markov source would make each encoded word possible but does not give the encoded set enough mass to transfer this lower to average loss.

The lower also does not say that every function phi(T), or a risk-dominating output depending on T, requires linear communication. Computing the full statistic can be harder than producing a useful estimate. It rules out the shortcut “T has logarithmic description length, so both parties can obtain it with logarithmic communication.”

# Task-risk replacement and the inverse-square-root resource lower are equivalent

6 November 2026 UTC. Author candidate v1, awaiting a separate exact-file independent review. Analytical theorem composition under a common fixed source class. ## 1. Main conclusion and why it differs from output simulation

Fix a stationary interior binary second-order source class and the AA/BB one-way raw-input ownership described below. For any source-independent architecture class and any public resource scale S in [1,N], the following are equivalent, up to constants uniform over the class:

- Every predictor has minimax terminal prediction risk at least a_c/sqrt(S).
- At EVERY valid positive advertised risk envelope r, each predictor can be replaced by a source-independent one-way distributed predictor with communication at most K S and minimax prediction risk at most lambda r.

Here lambda is any fixed number at least one, INCLUDING lambda=1. A replacement need not approximate the original predictor's output, hidden states, attention answers, or source-by-source risk. Its only fidelity requirement is the displayed minimax task risk.

This is an equivalence of existence statements. It does not establish either statement for an unrestricted architecture class. In particular, proving the proposed O(S) task-replacement property would already prove the desired architecture-dependent risk lower. Generic statistical estimation alone provides O(r^(-2)) communication, not O(S) without the lower-rate information.

## 2. One common experiment and frozen quantifiers

Fix c in (0,1/2). Let P_c consist of homogeneous binary second-order Markov sources with symbols {-1,+1}, every next-symbol probability in [c,1-c], and the source's stationary initial-pair law. The four-state pair chain has a unique stationary law under this positivity condition. The SAME class P_c is used for network risk, replacement risk, generic upper, and testing lower. No source-dependent architecture or source-dependent choice of protocol is permitted.

For N>=3 and a deterministic source-independent normalized binary predictor Q, define

    R_Q(P) = E_P TV(Q(X_1:N), P(.|X_(N-1),X_N)),
    R(Q)   = sup_(P in P_c) R_Q(P).

Architecture constants and syntax are frozen before N varies. For the intended application, Q is the synthetic-terminal probability output of a raw-token network in the frozen model: all data-carrying operations and probability-readout work remain charged to that network. This note grants no additional network readout, terminal-symbol port, hidden aggregate, source-specific weights, causal broadcast, or uncounted decoder. It uses only that Q is a public, fixed, normalized, source-independent map. The communication-side decoder, in contrast, has the usual unrestricted mathematical local computation. Exact evaluation of a public Q after full raw-input reconstruction is legitimate in THAT protocol model and is not a new neural implementation theorem.

For each public index (for example N,D and fixed architecture parameters), let C_index be any class of such Q. Assign a public, nonrandom, source-independent scale

    1 <= S = S(index,Q) <= N.

The usual target is S=min(D+1,N). More general publicly specified resource scales are allowed. S cannot depend on the observed sample or unknown source. To use this as an architecture theorem, its relationship to paid architecture resources must be justified independently; naming a risk-dependent quantity a resource is not such a justification.

Alice owns raw positions 1,2 modulo four; Bob owns positions 3,0 modulo four. The split, N, Q, S, architecture constants, and advertised r are public. Alice sends one finite binary message to Bob. Communication C is the maximum number of bits over all raw histories and random tapes, in the standard binary protocol-tree model; padding is allowed and timing or message boundaries convey no uncharged information. Public coins are independent of the sample and source. Independent private coins are permitted. Bob outputs a normalized probability vector.

For a fixed finite lambda>=1, define:

(L_S) There is a constant a_c>0 such that, for every public index and every Q in its class,

    R(Q) >= a_c/sqrt(S).

(T_S(lambda)) There is a constant K<infinity such that, for every public index, every Q in its class, and EVERY real r>0 satisfying r>=R(Q), there exists ONE source-independent one-way protocol Pi_(Q,r) satisfying

    C(Pi_(Q,r)) <= K S,
    sup_(P in P_c) E_(P,coins)
       TV(Pi_(Q,r)(X), P(.|X_(N-1),X_N)) <= lambda r.

The same Pi_(Q,r) must work for every P in P_c. The existence quantifier is AFTER Q and r but BEFORE P. The protocol can depend on the numerical advertised envelope r; no algorithm for computing R(Q) or checking r>=R(Q) is claimed. Constants a_c and K may depend on c, lambda and the class's frozen budgets, but not on N,D,Q,S,r or P. Empty classes cause no problem: both statements are then vacuous at those indices.

 J_N(Q)=sup_(x in G) TV(Q(x),Q(iota x)).

For fixed N this is a finite, precisely specified property of the complete input-output function. An explicit invariance proof or exhaustive finite evaluation can verify it; no efficient generic neural verifier is provided. Defining J_N is not a resource bound and computing it is not free.

Every LOGICAL suffix-only predictor has J_N=0, because iota fixes the suffix. In particular q_0=sigmoid(d(s)) is exactly invariant. A correctly compiled physical one-head baseline Q_base with uniform error zeta_b from q_0 obeys

 J_N(Q_base)<=2zeta_b.

This is approximate physical invariance, not an assertion that full-feature PreLN has exact suffix support.

For the hard reference, the bounded-logit derivative constant kappa_c gives on every x in G

 TV(Q_ref(x),Q_ref(iota x)) >=2kappa_c rho.

Hence the actual physical nuisance predictor satisfies

 J_N(Q_hard)>=2kappa_c rho-2zeta_h

whenever G is nonempty, as it is for k>=1. Indeed the same lower holds for each matched pair. For zeta_h,zeta_b=O_c(b^-2) and rho=Theta(b^-1/2), a declared tolerance delta_N=o(rho) satisfying delta_N>=2zeta_b includes the old physical one-head baseline but excludes this nuisance family for all sufficiently large N.

The constraint is therefore nonvacuous relative to the shared model: it retains an already-proved consistent predictor and rules out the specific phase perturbation. It is NOT a necessity theorem for statistically good predictors. Other nuisance functions can be invariant under this one rewrite, and invariance alone has not been proved to yield cheap communication, a source-average resource inequality, or a sharp statistical rate. It must not be advertised as the weakest possible useful constraint.
