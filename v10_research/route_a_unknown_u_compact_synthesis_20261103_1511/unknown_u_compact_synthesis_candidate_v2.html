Unknown-u matched conditional rate: compact causal corollary

3 November 2026. This is a candidate synthesis of independently reviewed source results; independent review of this exact corollary is pending. It is not a novelty certification, formal verification, training theorem, architecture lower bound, or generic floating-point claim. No random sampling, numerical test, source overwrite or external write was used.

1. Experiment and statement

For integer N≥2, let M=N−2. For 0<u<1/4, w=(1−u)/3, t∈[1/4,3/4], take a stationary binary homogeneous order-two chain with pair distribution (u,w,w,w) in 00,01,10,11 order and next-one probabilities (t,1/2,1−ut/w,1/2). Observe X₁,…,X_N and condition on the actual terminal pair S_N=(X_{N−1},X_N)=00; this event has probability u. The unknown target law is Bernoulli(t). For a common predictor H based on the same entire observed path, define

R_{u,t}(H)=E_{u,t}[TV(H(X₁:N), Bernoulli(t)) | S_N=00].

There is a single length-indexed predictor H_N whose parameters use public N but neither u nor t, realized for N≥3 by the standard-causal two-block model and specialized finite-bit backend in §4, and by the constant output 1/2 for N=2, for which simultaneously for all allowed u,t,

R_{u,t}(H_N) ≤ min{1, 157/√[1+(N−2)u] + 1/(4N)}
                 ≤ min{1, (157+1/4)/√[1+(N−2)u]}.                    (1)

For the corresponding mathematical decoder with exact real softmax of dyadic logits and an exact probability-valued output, the second term 1/(4N) can be replaced by 9/(64N). That exact-real statement is not an implementation guarantee for exponentiation or output quantization.

Conversely, for each fixed public u, every single common full-history prediction rule H, even one allowed to know u, satisfies for t±=1/2±1/[32√(1+(N−2)u)]

max_{t∈{t₋,t₊}} R_{u,t}(H) ≥ (1−1/√6)/[32√(1+(N−2)u)].             (2)

The lower is an information-theoretic statistical lower for one common rule across the two unknown t values. A randomized rule must be a common source-independent stochastic kernel given the supplied path and u, with any random seed independent of source and path; source-dependent training data or parameters correlated with t are not part of the experiment. It permits arbitrary access to X₁:N and u. It therefore applies to the stated neural predictor as a special case, but it does not establish a depth, width, head, score, precision or computational lower bound. Equations (1)–(2) give matching order for each fixed u in this conditional full-history experiment; the same H_N achieves the upper bound for every u without being given u. They do not assert a distinct minimax result for arbitrary mixtures of u or unconditional terminal-state risk.

2. Same path, same statistic

For each s∈{00,01,10,11}, put

J_s=∑_{j=3}^N 1{(X_{j−2},X_{j−1})=s},
C_s=∑_{j=3}^N 1{(X_{j−2},X_{j−1})=s}X_j,
B_s=(C_s+1)/(J_s+2).

Both the statistical source and compact-decoder source use exactly these indices and the same terminal s=S_N; neither sees X_{N+1}. In particular, the j=N history term uses X_N as the successor of (X_{N−2},X_{N−1}), then the output is read at the actual terminal pair (X_{N−1},X_N). The comparator exists at J_s=0 and then equals 1/2. The statistical source establishes for this same B

E_{u,t}[|B_00−t| | S_N=00] ≤ min{1,157/√(1+Mu)}.                    (3)

Its proof reverses the already terminal-conditioned stationary chain, uses the two-step common atom and a reverse martingale, and explicitly handles the endpoint flow. It does not assume an independent query. The fixed-u lower (2) is imported from the rare-family conditional-history two-point analysis, not recomputed from unconditional KL. The four-step π-minorization in that source must not be replaced by an unproved two-step π-minorization.

3. Pathwise transfer and public accuracy choice

For N=2 the public length branch outputs 1/2 exactly, which equals B_{S_N} because the history count is empty. For N≥3 the compact-decoder source proves a pathwise, all-word comparison to B_{S_N}. Choose its public accuracy parameter η=1/N. For the specified specialized rational backend, the unrounded output p_N obeys

|p_N−B_{S_N}| ≤ η/8 = 1/(8N)                                  (4)

for every binary input of length N, including J_{S_N}=0. Round p_N to nearest point on the grid {k2⁻ʳ: 0≤k≤2ʳ}, r=⌈log₂(8N)⌉, with both endpoints included and an explicitly sufficient endpoint/integer representation. The rounding error is at most 2⁻ʳ⁻¹≤1/(16N); using the looser 1/(8N), and emitting the exact complement, the resulting Bernoulli output H_N obeys

TV(H_N, Bernoulli(B_{S_N})) ≤ 1/(4N)                             (5)

pathwise. For the exact-real dyadic-logit model the corresponding unrounded bound is |p_N−B_{S_N}|≤9/(64N). Triangle inequality and (3), conditioned on exactly the same actual event, yield the first line of (1). No conditional independence or interchange of a ratio and expectation is used. As 1+(N−2)u≤N for N≥2 and u<1/4, one has 1/N≤1/√[1+(N−2)u], proving the second line of (1). The same parameters work for all u,t; N is public.

4. Declared architecture and fully scoped arithmetic

For N≥3 there are N input tokens, no added BOS, two causal residual blocks, two head slots per block, three active head instances, model dimension 32, head dimension 16 (score scaling 1/4), and a first-block one-hidden-layer ReLU FFN of width at most 72; the second block FFN is zero. No LayerNorm is present and the output is a Bernoulli probability pair, not a further vocabulary-logit softmax. Public positional features (1,i,i²) are stored in O(N log N) bits or generated by a paid exact counter/square routine. A designated first position supplies the pseudo-count while its original bit remains available to the copying heads and residual stream. Both heads attend over all positions j≤i; no singleton or query-dependent attention mask is supplied.

In the compact source notation, set

c=⌈log₂(64N)⌉, b=⌈log₂(4N²)⌉, T=b+1,
A=max{c(N+1)²,b+1}, p=⌈log₂(128AN)⌉,
P=10[T+p+b+c+⌈log₂(N+2)⌉+100].

The stored dyadic s approximates ln2 within 2⁻ᵖ. Copy-head logits are cs[2(i−ℓ)j−j²] for lag ℓ=1,2; scores become −cs[j−(i−ℓ)]² after a row-constant shift. Raw score magnitude is O(cN²+b), parameter coefficients O(b+c), and positional coordinates reach N². A single-layer direct ReLU gate handles early positions without a supplied validity mask. For the finite-bit implementation, subtract exact integer row maxima; keep symbolic relative powers 2⁻ᵏ for k≤T and drop the rest. In block 2 all three possible relative exponents 0,1,b+1 are retained. This is a specialized approximate softmax backend for this discrete logit family, not an assertion that exp(ks)=2ᵏ, not a generic exponential routine, and not a standard framework fixed-word guarantee.

The source proof uses an explicit aligned denominator for attention sums, a common product denominator for each pair of copied inputs, and exact canonicalization of FFN gate outputs to 0/1 and pseudo-values to 0, 1/2 or 1 before the second head. With this specified representation, P=O(log N) bits bound exact intermediate integers. Straightforward dense causal evaluation has O(N²P²+(P+r)²) schoolbook bit operations and O(NP+r) working/output bits, plus O(p⁵+T) bit operations and O(p²+T) bits for deterministic ln2-parameter and powers-of-two preprocessing. Position-table space is charged separately; no asymptotic claim is made for an arbitrary floating-point implementation. The final grid has r fractional bits plus sufficient endpoint/integer encoding, not r total bits.

5. Scope and comparison

The same-history classical baseline keeps counts of 00,01,10,11 transitions and successor ones in one pass, reads the actual terminal row after seeing X_N, and outputs B_{S_N}. It uses O(N) count updates, O(log N) bits per fixed-number counter and a paid final division; it already has the same statistical guarantee (3). This decoder is not claimed computationally superior.

R011's K=2, M=N−2 estimator is exactly the same pathwise add-one rule but its stated risk averages over terminal states; a conditional 00 bound does not follow unchanged. D’Angelo et al. §§3–4 already supply finite-score n-gram matching and an add-α BOS limit; Rajaraman et al. Theorems 4.4–4.5 and Remark 4.2 give two-layer constant-dimensional k-gram constructions and assert logarithmic-precision approximation for an empirical estimate defined at positive count. Izzo et al. Appendix B.3 provide a finite-score positive-match error calculation in a heuristic construction. Their exact objectives, smoothing, terminal conditioning and numerical models should not be conflated with this synthesis. Conversely, differences in formulation alone do not establish publication novelty or a resource separation. No training result, general source result, unique architecture claim, or N-versus-depth necessity is asserted.
