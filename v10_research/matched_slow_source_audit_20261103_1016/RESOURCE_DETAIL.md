# Classical comparator cost detail

For M historical departures, read the M+2 input symbols once and maintain the most recent two input bits, the index, and four rows each of J, successor-one C and first-half D. With the endpoint fixed after the scan, use its row's counters to evaluate G, F, B, B_G and the requested q. All counts and the index need O(log M) bits each, so the fixed number of counters uses O(log M) auxiliary bits, in addition to the streaming input and output. A counter update is one O(log M)-bit operation, giving O(M log M) bit operations under a simple worst-case bit-cost model.

For output error at most 1/M, choose p=ceil(log2(16M)) fractional bits. Fixed-point add/divide and a direct binary search for s=M^-1/2 using schoolbook arithmetic have a conservative O(p^3) final bit-operation bound and O(p) extra working bits. The overall conservative bit cost is O(M log M+(log M)^3); O(M) counter operations in the original note refers to word operations and excludes this final arithmetic. These are existence-level accounting bounds, not timing claims or exact instruction counts. The oracle identification itself still requires independent source episodes; the test reads their full words and has the stated episode count.
