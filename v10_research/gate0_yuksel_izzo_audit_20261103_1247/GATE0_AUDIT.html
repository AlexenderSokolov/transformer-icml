Gate 0：Markov 样本复杂度与长度泛化审计

2026-11-03。对象：Yüksel & Flammarion（AISTATS 2025）和 Izzo、Nichani & Lee（ICLR 2026）。对照 v10 基准问题与已声明的科学比较口径。本文是两篇论文的定理级别定位，不是完整文献调查、正式证明核验或新颖性认证；没有运行数值测试或随机实验。

决策摘要。 第一篇已给出高阶 Markov 轨迹上经验风险最小化的非渐近 KL 泛化上界，包括单条训练轨迹的经验平均误差，不能将一般 Markov 预测收敛或非渐近统计上界本身当作新发现。第二篇已建立受限一层及两层 Transformer 的定量长度泛化，并明确讨论 in-context k-gram 经验估计，不能将这类宽泛机制或二层表示本身视作空白。两篇各自的对象和量词均不能直接替换为 v10 同一随机历史、实际末尾查询的预言机 TV 风险；这不是新颖性证明。

0. 共同比较对象与记号

v10 参考实验：未知齐次二阶转移表，完整单条历史，目标是实际末对之后的概率分布；允许任意初始对律和零转移，主要损失为同一历史上的无条件期望 TV。比较口径包括同一风险定义下的统计误差、实际因果计算与精度成本，并区分固定情境条件风险和随机末情境风险。以下沿用各论文原记号；特别是 Yüksel 的 N 是训练轨迹数、T 是每条长度，Izzo 的 N 是短输入长度阈值、T 是测试输入长度，Izzo 的 L 是参数范数常数而非网络深度。

1. Yüksel & Flammarion：次 token 预测的样本复杂度

PMLR 258:694–702 原始条目；会议原文全文及证明。读取 §§3–4，§5 证明思路，附录 B、C、D 的相关定理及证明结构。原文是预测器类的 ERM 泛化分析，而非构造从任意未知任务执行同历史预测的 Transformer。

定义与假设

  • 有限字典 d；阶数/窗口 k；N 条独立训练轨迹，各长 T，每条由同一固定未知转移核 pθ* 生成。一个固定参数 θ 的模型只接受当前 k 个 token 的上下文，输出 softmax 概率；θ 经整份训练集的最大似然/交叉熵 ERM 获得。N=1 是允许的特例，但学习完成的 θ 可以依赖全段训练数据，不等于在同一前缀上运行的因果 ICL 更新算法。
  • Assumption 3.1：logits 的无穷范数 ≤B；Assumption 3.2：关于参数的统一 L-Lipschitz；Assumption 3.3：真核在假设类中，即 p*=pθ*；Assumption 3.5：参数覆盖熵 Cε≤C(Θ)log(e/ε)。有限 B 与 softmax 导致每个实词条件概率严格正，故不能不加桥接地覆盖 v10 允许零概率的全部核。
  • 式 (5) 的 in-sample 量是训练轨迹全部位置与全部轨迹上的条件 KL 平均；式 (6) 的 out-of-sample 量在独立新轨迹中均匀选时间求期望 KL。§3.2 说除 Theorem 4.2 外可非平稳初始化；4.2 的证明使用平稳性。单条轨迹的时间平均并不自动给实际末点的同轨迹预测风险。
  • Definition 3.6–3.8：mixing 控制任意两个 k-上下文之后的 k-块分布差的 TV；局部 mixing 仅比较相差一个坐标的上下文。论文还讨论多个假设类；单层 self-attention 是示例，复杂度依赖参数类及有界范数，不是全部 Transformer 的网络资源界。

逐项结论

结果 / 条件准确可用结论与 v10 的关系
Theorem 4.1；3.1–3.3、3.5；0<δ<e⁻¹概率 ≥1−δ，训练轨迹的平均条件 KL 为 Õ(B C(Θ)/(NT))；不显式依赖 mixing。对数项、参数 Lipschitz 常数及置信度见原文。附录 B 用 ERM 基本不等式、带条件方差的鞅浓度与覆盖网。已覆盖 N=1 下同一训练轨迹所有位置的平均，但不能据此直接推实际终点同轨迹 TV，亦不是有限前向网络的学习/推理成本结果。估计参数由整个训练轨迹拟合，不可混同于每时点只用此前历史预测。
Theorem 4.2；同一假设、平稳及 T 远大于 τmixlog T概率 ≥1−δ，独立新轨迹随机位置的期望 KL 为 Õ(τmix(B+log d) C(Θ)/(NT))。附录 C 用近独立分块、星形局部化和覆盖控制。平稳下新轨迹随机位置边际与新轨迹末位置相同，但 v10 的查询与拟合历史相关；相同边际不意味着相同联合风险。不能在缺少依赖性证明时把 fresh test 替换为训练轨迹的末对。
Example 4.3弱连通两块的首阶链：慢 mixing 且一条短训练轨迹可能只探索一侧，因而对论文独立新上下文的泛化不保证小。这是一个慢 mixing 泛化障碍示例，不是覆盖 v10 快速混合但稀有状态、全部网络的风险下界。
Theorem 4.4局部 mixing 版本；来源给出快项 Õ(BC/(NT)) 加慢项 Õ(τ̃mix(1/T)(B+log d)√[C/(NT)])，高概率。附录 D.1 用局部耦合控制上下文差异。说明 mixing 改进不是未研究方向；它仍是论文指定的 fresh/time-averaged KL 目标，而不是全网络终点 TV 或 rare-context 下界。
Assumption 4.5、Theorem 4.6要求对只相差一坐标的初始上下文，存在后续路径耦合，其期望分歧 token 数由 η(T) 控制；得到由类复杂度和耦合量而非全局 mixing 表示的 out-of-sample 界。“无 mixing”不意味着无额外结构：耦合假设及 η(T) 必须核对。索引文本的正文式写 η(T)，附录 D.2 重述/证明写 kη(T)；无法视觉核对时不把较强式当成已确认的精确 k 依赖，也不宣称此差异必是原 PDF 之错误。

资源和风险翻译。 预测 KL 对固定概率分布可用 Pinsker 转换为 TV（如需期望再用 Jensen 或尾部积分），但只在相同 query、同一概率空间及真核满足条件时可用；此变换本身不能把时间平均改成实际终点，也不能把独立测试改成依赖终点。即便 k 固定为 2，该论文未支付输入绑定、q/r/u 读出、深宽、头数、有限位数、累计与除法等 v10 真实电路成本。更强同历史终点界或有限通道下界仍需各自证明，并需继续对照其他文献和 v10 已有结果。

2. Izzo、Nichani & Lee：Transformer 长度泛化的定量界

ICLR 2026 官方条目；会议论文全文。已读 §§3–5、附录 A.2–A.3、B.1–B.3 和实验方法；利用原始 PDF 检索缓存阅读，直接 URL 有时返回 OpenReview 验证页。论文早期 workshop 文本不能替代 2026 会议版本。

主要命题比较两个给定 limit transformer f,g，而不是直接把网络输出与未知真实转移核比较。假设它们在所有长度 ≤N 的所有字符串上足够接近，再推出任意长字符串上的接近。这个强的确定性前提不由有限随机训练样本上的低损失、SGD 收敛或仅见过有限条短串自动满足。

结果 / 模型结果和证明要点限制及映射
§3.2；Theorem 4.1，一层、有限精度τ-local、平移不变相对位置偏差，Δ-周期位置编码；p-bit 规则下中间量绝对值 ≤2⁻ᵖ 截零，softmax 先减最大 logit，logits 以 log|x| 缩放。设 γ 是两个模型的最小非零分数间隔，Lnorm 是其范数常数之和，存在 N=O(max{2p/γ, Lnorm²Δ⁷|Σ|⁶τ²/ε²})；若任意 |x|≤N 都有 ‖f(x)−g(x)‖≤ε，则所有输入上为 O(ε)。附录 A.2 以短串模拟长串的 hardmax 类型比例和局部/周期信息。这是满足阈值后的充分长度，不是必要下界；精度规则加随长度增长的 logits 才产生极限 hardmax，不能当作任意 p-bit 固定温度 softmax 定理。输出范数也不能无桥接当作 v10 对真核的 TV。
Theorem 4.2，一层，分布平均先从 Dirichlet(α) 抽词概率向量 P，再条件于 P 独立同分布抽词；α₀=min αs。每个短长度的平均模型差 ≤ε，经指定门槛 N₀ 后推任意长度平均模型差 O(√ε)；N₀ 的 ε 指数约为 2+2/α₀（其余因子和对数见原文）。证明用概率质量可控的短串模拟，附录 A.3。这不是二阶 Markov 采样定理；作者将更一般依赖分布的扩展留待研究。输出从 ε 到 √ε 的损失不可省略；也不构成随机目标风险结果。
Definition 5.1、Theorem 5.2，两层、无限精度Fτ：局部平移不变、非负位置分数、第二层无位置项、一层 H 个头和二层一个头、单位有界 embedding；局部位置分数按 log(位置) 缩放。若两模型全短串 ε 接近，则存在 N ≲ (max{C(f),C(g)}/ε)max{1/γ(f),1/γ(g),3}，使任意长串上模型差 O(ε)。C 随首层范数指数增长；γ 是指定位置间隔。Lemma 5.3 / 附录 B 用短子序列模拟后缀与前缀直方图。这是特定两层及标度下的充分迁移界；不是任意深度、有限精度、同资源下界或 N 与推理深度的替代性定理。证明中用于抽取子序列的两状态 Markov 链是辅助构造，不是输入数据的一条 Markov 样本风险结果。
Definition 5.4、§5.4 和附录 B.3：in-context k-gram目标是末尾情境历史出现后继符号的经验分布；引用既有两层、k−1 个一层头的构造。误差草图含 T/[eβ×匹配次数]，仅在匹配次数 Θ(T) 的“典型”输入下简化为 O(e⁻ᵝ)，从而启发式给出 ε−Θ(k²) 复杂度。该工作直接触及与 v10 同历史经验参照相近的对象；不能将这种构造当作新发现。但稀有访问率进入常数，无法从典型条件直接得到稀有/零计数均匀风险。正文脚注允许零匹配时行为任意；分式本身此时未定义。正文显示情境索引与附录 τ=k−1 的表面口径需逐式对齐，不在此把特定 k 无条件等同某一 Markov 阶数。

实验附录 C 先抽转移表并生成轨迹，再把一个内部片段替换成终端情境以保证存在历史匹配，学习目标为经验 k-gram 而非真实未知转移核。该结果提供经验现象，不证明未修改的平稳轨迹上末情境 TV 风险或普遍训练可达性。论文给出了模型结构、精度和位置约束，不能将之直接替换为标准、任意位置编码及任意数值语义的 decoder。

3. 候选科学方向的逐项状态

候选方向由这两篇支持的判定
有限轨迹统计收敛 / 上界部分覆盖。 Yüksel 4.1 和 4.2 直接覆盖指定函数类、真模型可实现、训练轨迹平均或独立新轨迹平均的 KL；改为随机实际末点 TV，尤其共享轨迹，需要额外论证。
有限前向网络 q/r/u 恢复与偏差未由这两篇直接建立。 Izzo 包含相关经验 k-gram 构造，Yüksel 包含固定窗口自注意类；这不是对整个文献或项目的新颖性认证。核对 D’Angelo、Nichani、Rajaraman 及已有 v10 原始证明。
N–L–宽度–精度风险前沿部分邻近，非同题。 Izzo 的 N 是全短串拟合门槛，L 是范数常数，且结果是充分 transfer；不能把它改称 v10 的历史长度与推理深度下界。Yüksel 的 entropy 不是按实际有限网络资源清单计算的替代定理。
快速混合稀有状态 / 目标特定风险未被这两篇直接解决。 Yüksel 例子是慢 mixing 的新上下文泛化障碍；Izzo 的经验计数示例依赖典型匹配量或人工确保匹配。须分析固定查询和随机终点的不同权重、轨迹全信息及其已有项目结论，不由此推新颖性。
