Gate 0 原文核对：Rajaraman 与 Chen

2026-11-03。针对 T1/T2 的文献比较范围，对两篇 NeurIPS 2024 直接近邻的相关定理、假设、证明机制和量词做针对性核对；不是全部 Gate 0、全篇形式化审计或新颖性认证。已对照既有 central_prior_art_20261103/ATTENTION_PRECISION_AUDIT.md 与 prior_art/comparison.md，以下补足精确定理、数值、零计数、训练和罕见族边界。未做随机试验或公开写入。

1. Rajaraman 等：条件经验分布的表示能力

NeurIPS 2024 正式论文及附录；arXiv v1 可检索全文。两版本编号不同：正式论文 Theorems 2、3、4、5 对应 arXiv v1 Theorems 4.4、4.5、5.1、6.1；后述双编号避免混淆。

  • 目标和量词。§2.1 定义有限字母表、任意 k 阶 Markov 下一 token；论文表示性定理实际实现路径上的条件经验分布，对所有适用输入序列成立，不必把数据固定为某一个已知核。经验分母是此前出现末尾 k 长度上下文的次数；原式明确只在分母非零时定义。它与本项目同轨迹末位置查询、J_s>0 时的 C_s/J_s 是同一统计对象的具体 k=2 映射，而非未知真实 θ_s；零计数 fallback/平滑要单独规定。实验部分从 Dirichlet 先验抽样每个上下文的核，但表示构造不是只对该先验的平均结论。定义与数据设置
  • 网络与资源。正式论文 Theorem 2（v1 4.4）给 attention-only 两层、每层 k heads、宽度 (k+2)S+k+1；Theorem 3（v1 4.5）给相对位置编码、每层一头、层数 ⌈log₂(k+1)⌉、宽度 ≤2k(S+1)+S。若 k=S=2，分别是两层两头、d=11；两层一头、d≤14。Theorem 4（v1 5.1）给三层、每层一头、RPE、layer normalization、d=O(S)，附录 C.3 的明确嵌入 d=6S+3（S=2 时为 15）。这些资源中的 d 为论文嵌入维度，不能未经核算直接等同 v10 每头 d_k、d_v 或总 FLOPs。证明调整了 LN 顺序，论文称结论也适用于其标准图示版本；与暂定无 LN 的模型 D 并不完全相同。§4；§5；附录 C。
  • 证明机制与精度。附录 A/B 使用相对位置编码组织先前 token、历史与终端上下文匹配，并令 softmax 权重集中于匹配位置；附录 C 使用编码与规范化构造长度 k 的匹配，公式含依 k 增长的权重/位置值，末层以匹配历史的后继作输出。构造的极限/实数操作不是有限 logits 的无误差硬复制。正式论文 Remark 2（v1 5.2）明确说三层构造未给出有限位精度误差证明，并表示 Ω(log T+k) bits 应足以得到 O(1/T) 加性误差；这是作者预期，不能当作已证精度定理。attention-only 的 v1 Remark 4.2 另称 O(log T) 位可达 O(1/T) 误差，应用时仍需复核其具体数值模型及隐藏常数。计算位置存储、标准 softmax/LN 的计算与读取成本依然是本项目义务。
  • 下界与适用范围。正式论文 Theorem 5（v1 6.1）考虑一层、可含 LN/FFN 的模型，embedding 和未归一化分数以 p bits 计算，要求所有三元字母表长度 T 输入上将 conditional 3-gram 逼近至 1/(3T)，得 2pH+dp+2≥T/3；证明将 set disjointness 归约为通信复杂度（附录 D）。这不是二元随机二阶族、总体/条件 TV 风险下界。v1 Theorems 6.3–6.4 限 attention-only 且前层 attention pattern 与输入无关，目标是末层高阶 induction-head 图案而非任意实现条件计数的网络；作者明确不将其推成条件 k-gram 的一般下界。§6 与假设。
  • 训练与风险。本文有训练实验，但上述构造是存在性/表示性，不能称为一般 SGD 找到参数的理论。本文不在这些指定结果中给出对本项目未知二阶核、稀有实际末查询、N/L/精度全账本的非渐近总体 TV 界。它强烈覆盖“常深度表示经验二阶频率”，但并不单独证明或否定本项目所需统计风险、训练或同资源分离。

2. Chen、Sheen、Wang 与 Yang：训练动力学与广义 induction head

NeurIPS 2024 正式论文全文；arXiv v1 可检索全文。下述编号取 arXiv v1。

  • 数据与预测。§2.1：有限词表 d、固定共同父位置集合 pa={−r₁,…,−r_n}、初始长度 r_n 的分布 μ₀；核 π 从任务先验 P 抽样，给定核生成一条序列 x₁:L+1，使用 x₁:L 预测实际后继 x_L+1，不把末查询另从均匀分布抽样。目标 population CE 是对核和路径联合取期望的 −E log(f(x_L+1|x₁:L)+ε)，ε=L⁻¹/²。论文指出 ε=0 时扣去真实核熵可视为平均 KL；实际训练用了正 ε，不能将该等价式无条件搬到训练损失或升级为固定核、稀有状态条件 TV 风险。μ₀ 是一般初始分布，分析引入核对应平稳块分布并用混合处理；不能说生成默认平稳。§2.1，式 (2.1)–(2.2)。
  • 模型和实际可见信息。§2.2 是两 attention 层的特化解耦模型：追加零向量 query 位置 L+1；第一层 H 头仅用相对位置信息，窗口 M，mask 排除当前位置、未来及窗口外位置；每头输出 d 维，拼成 Hd。多项式特征 FFN 的维数 d_e=Σ_{S⊆[H],|S|≤D}d^{|S|}，再用 √(Σ c_S²) 作专用归一化，不是一般标准 LayerNorm；第二层一头按输出位置 query 与历史特征匹配，value 是原 token，经残差可见，并 mask 前 M 个位置。选取 M=H=3、d=2、D=2 时 d_e=1+3·2+3·4=19。实际计算、窗口 mask、复制和高维多项式特征均有资源成本；它不是 v10 无 LN/无特殊 mask 的标准 decoder 原样证明。§2.2，Lemma B.1。
  • 目标算法和边界。Definition 3.2 由任务先验平均的 modified χ² 信息选择大小≤D 的 S*；按终端父特征逐历史精确匹配，平均匹配位置的后继。无匹配时退回历史 token 平均。S* 是信息最优代理，不总是实际父集合；§3.4 仅在额外条件下论证一致。§3.2 的多项式核允许联合特征而非独立两条标量老/新坐标端口。它是对本项目 B 路径完整网络旁路的重要先例，故不能从两个边缘标量碰撞推全网下界。Definition 3.2 与式 (3.3)；§3.2。
  • 定理假设。Theorem 3.6 依赖 Assumptions 3.3、3.5：信息最优集合与其它集合有正的信息间隔；各头相应位置初始 RPE 已有显式正间隔；第二层系数 0<a(0)≤O(L⁻³/²)；核支持内的块链 primitive，第二特征值模统一≤λ<1，且每个允许后继的核概率统一≥γ>0；H≥M（具体分析使用 H=M），L 足够大。附录 C.1 把长度条件显式关联到信息 gap、1−λ、γ、父窗口 r_n 等，故不可把大 L 的阈值默认为统一常数。对每个固定 u>0 的 v10 罕见族所有合法后继概率正且块链 primitive；但 θ₁₀(0)=h=3ut/(1−u)→0，因此整个 0<u<1/4 族不存在共同的正 γ。快速混合本身不修复这一假设；论文若逐个固定 u 使用，界中 γ 及 L 条件可能随 u 退化。先验还必须满足信息 gap 和其它初始化条件，不能假定这些自动成立。Assumptions 3.3、3.5 与 Theorem 3.6；附录 C.1。
  • 证明与实际训练。三阶段 population gradient flow 依次只训练多项式权重 c_S、第一层 RPE、第二层标量 a：文中给阶段 I 选择器的指数型、阶段 II copier 的多项式型，以及阶段 III a 增长控制；最后的论证在 a 达 O(log L) 的范围内。Appendix C.5 Lemma C.6 还证明：在其假设及前两阶段误差 O(L⁻¹)、a=Θ(log L) 下，对每个核以至少 1−O(L⁻¹) 的概率，输出与 GIH 估计量 L¹ 距离为 O(L^{−a/log L})；这是有条件的非渐近/高概率网络到 GIH 近似，不能忽略，但不是对真实核风险的完整同资源结论。§4、附录 C/D 对动力学和混合近似给证明；同步训练、完整 Q/K/V 和更接近真实归一化的实验是经验支持，不等同一般 SGD 收敛定理。算术按实数模型分析，未找到逐操作浮点/累加/精度成本定理，不断言文中完全没有任何数值讨论。Lemma C.6 与证明；Appendix A 实验。

3. 对当前 A/B 的可操作结论

项目候选主张已有覆盖尚需自己的桥或核查
三层/常层数读取二阶频率Rajaraman 已给路径经验条件 k-gram 的常层存在构造；Chen 的 GIH 在 S*={1,2} 时读联合上下文，含无匹配 fallback。必须建立完整网络到原核风险、零计数、实际随机末位置、有限 score/精度与成本；不能将经验频率当真实转移。
联合特征能绕过两标量 port 的碰撞Chen 的多项式核和原 token 值显式使用联合父历史；Rajaraman 有更强全网络经验频率构造。限定可见接口的下界要排除其它 value、residual、heads、FFN 和位置路径；匹配预算才能讲架构分离。
固定浅层对未知核的统计学习两者均让历史随核变化；Rajaraman 表示性对序列构造，Chen 训练目标明确对核先验平均，且有训练动力学和网络到 GIH 的概率界。区分预训练依赖先验、每个固定核与最坏族；不能说“未知核”或“受训网络逼近 induction”整体无人研究。
稀有而快混合的有限 N 风险与资源Chen 与随机末查询、可混合块链和概率误差有直接重合。固定 γ 条件不覆盖整条 u→0 家族；需逐项比较其他文献、误差与依赖，不可仅凭两篇未给相同结论即宣称新颖。
