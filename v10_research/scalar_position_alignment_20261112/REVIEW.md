## Scope and limits
The source j and sequence length N are public network configuration inputs; coefficients may depend on them with O(log N) description length. There is a synthetic terminal row. The module aligns only this one source over its causal future. It does not give every row i its own predecessor, compute transition statistics, or implement a conditional-probability output. A parameter set independent of N,j, prohibition of scalar positions, a smaller prescribed norm cap, or a fixed total parameter-energy budget would require separate work. Copying the construction into a different width requires recalibration of all LN constants. No matching full-network root-N risk upper bound, novelty certification, external peer review or formal verification is claimed.
