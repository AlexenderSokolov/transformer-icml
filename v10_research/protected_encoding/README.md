# 可更换编码下的一次切口保护：阶段结果

**主稿：`protected_encoding_proof_v3.md`。** v1/v2 保留历史，其中 v2 的一般幅度 radix 算法费用漏计 `log(L+1)`，已在 v3 修复；主 SRC 构造不受此遗漏影响。新稿不是 Euler Fact、形式验证或论文新颖性证明。

## 核心结论

- 原始 master 的每个 h-grid 分子用 h+1 个 0/1 通道可逆编码，每个受损通道仍保留同一 h-grid、幅度 `[0,1]`，所有通道都可被攻击，没有新增干净侧端口。
- 任意相关的逐坐标扰动 **δ<1/2** 可以完全恢复原实际有限 master，因此逐路径输出等于干净 SRC，风险达到 `Θ(min(1,K^(5/2)/sqrt(M+1)))`。δ≤1/4 时清理器只需常数增益；临近1/2的全范围版本付出 O(h)-bit 增益并依赖有限网格。
- **δ≥1/2** 时，任意公开有限通道数、任意干净编码器都可被统一擦除为全1/2。按原准确侧信息合同，最多剩初始旗标 X2 与末对；两个 iid Bernoulli 源给 actual TV 风险至少 **5/64**。
- 通道、精度、encoder/decoder、全 n 位置、dense零项、移动、offline 与同时峰值全部付费。统一 p-bit 格式的额外 dense 参数为 `O(K²h³p)`，全位置工作为 `O(nK²h³p²)`；仍落在原 SRC 的渐近资源上界内，**不等于数值费用不增加**。
- 给出有限网格 l∞ 通道的精确零误差容量、final-V 全银行 L1 预算的付费重复编码，以及相同历史/同样保护能力的 direct 计数基线。没有 Transformer 特有优势或训练可达性结论。

## 含义与边界

034–035 的原未编码端口下界保持正确；不能将它们读成任意编码或全部网络的同资源可靠性必要条件。这里改变的是保存表示和错误边界，**不能修复编码前已被破坏的 scalar、历史符号或 head 运算**，也不保护有噪 decoder 算术。
