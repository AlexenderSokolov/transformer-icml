Pre-LN score interface clarification

3 November 2026. This supplements preln_actual_risk_obstruction_v1.html (SHA-256 037a0f737d8afc86ec65ebdd3321b9d324781dbf91c0c92229b7f593a6b030a7) and input_and_quantifiers_clarification_v1.html (SHA-256 b0e60b8b20d9224c0701f8e4f2e76b81f7d40e43c7366422d324037850e9ecbf). It leaves both immutable.

The score at unmasked row i, column j is exactly qᵢ·kⱼ/√dh, optionally plus a deterministic, source- and token-independent bias B(i,j,N) with a uniform absolute bound for all i,j,N. There is no other score side input. In particular this does not allow an arbitrary bounded bias depending on the sequence, unknown transition law, or hidden context. Causal masking is the only mask and all preceding keys are included. Inference is deterministic with fixed parameters; if dropout or randomized inference is wanted it must be specified and separately bounded.

The allowed bounded deterministic bias changes only the constant in the uniform logit bound and is identical for the two compared histories. The proof and fixed-network risk quantifiers are unchanged.
