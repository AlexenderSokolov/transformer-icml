Input and quantifier clarification

3 November 2026. This supplements preln_actual_risk_obstruction_v1.html, SHA-256 037a0f737d8afc86ec65ebdd3321b9d324781dbf91c0c92229b7f593a6b030a7; it does not modify it.

The admitted input at each location is exactly a fixed finite token embedding added to a deterministic position vector, plus any fixed special-token flag. Position vectors are independent of tokens and of the unknown source; they can grow without bound and may depend on N. In particular arbitrary token×position features, source-dependent encodings, precomputed context, and other preprocessing that depends on other tokens are excluded. A separate treatment is required for any such channels.

The proven order of quantifiers is: for every one fixed finite network satisfying the model assumptions, the same fixed explicitly specified source obeys liminfN→∞ risk ≥1/32; the O(1/N) constant may depend arbitrarily on that network. In particular, the result does not establish infnetwork riskN≥c for each finite N. An architecture with parameters, precision, score range or depth allowed to change with N is not covered by the conclusion and might evade it. All other stated restrictions remain in force.
