Explicit Q/K/V maps for the candidate structured-mask network

2026-11-03. Additive detail for unchanged Route A v1; all three correction/clarification addenda in the same folder apply. Status provisional, subject to independent review, exact-real attention logits and declared finite-error ports.

Write Praw, Pkey, Pquery for fixed coordinate projections from a token's residual state. At each legal historical token i≥3 after block 1, Pkeyhi=e(X_{i−2},X_{i−1}), Prawhi=Xi, while at terminal token N, PqueryhN=e(X_{N−1},X_N). The key and query are four-dimensional separately stored coordinates. Every mapping is shared across token positions.

Block 1, lag head a=1 or a=2:
  W_Q=0; W_K=0; W_V=P_raw, with output projection to a distinct lag-a coordinate.
  Structural mask at i≥3: {i−a}; at i=1,2: {i}.
  The scalar softmax output is exactly the selected token's raw bit.

Block 2, matching head A, with d_k=4 and 1/sqrt(d_k)=1/2:
  W_Q=2 log(2) P_query;  W_K=P_key;  W_V=P_raw.
  At terminal N the allowed key set is {3,…,N}; thus the score is
  log(2) <e_(X_{N−1},X_N),e_(X_{i−2},X_{i−1})>.

Block 2, uniform head B:
  W_Q=0; W_K=0; W_V=(P_raw,P_key), a five-coordinate value.
  It uses the same terminal mask {3,…,N}.
  Nonterminal queries can use self-only masks; their outputs are not used later.

Because the query and key one-hot dot product is 0 or 1, the matching weights are exactly 1 or 2 before normalization, yielding q=(C_all+C_s)/(m+J_s). Head B outputs r and all four J_a/m in its respective coordinates. The two heads run simultaneously from the first block's outputs. The last observed X_N is legitimately a historical successor at i=N and simultaneously part of the terminal query, in different coordinates; X_{N+1} is never read.

Feature construction, selection, spline widths, final projection and resource costs are as in the base report plus its addenda. These matrices are not an implementation for a model in which local singleton masks or early-key exclusion are forbidden; no dense-mask conversion, finite-bit realization, lower bound, training result or novelty certification is inferred.
