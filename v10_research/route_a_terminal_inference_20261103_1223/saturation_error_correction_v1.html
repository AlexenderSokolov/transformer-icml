Saturation error: exactness or separate charge required

2026-11-03. This correction applies to the unchanged Route A v1 and all previous addenda. In particular, the phrase “exact or otherwise range-preserving saturation” in scope_antecedents_addendum_v1.html was too weak. Range preservation alone does not preserve the ζ error guarantee.

Let p be the ideal clipped probability, x the numerical pre-saturation scalar with |x−p|≤ζ, and clip(x)=min(1,max(0,x)). The output must satisfy one of these two conditions:

  1. Exact clipping: the actual emitted scalar is clip(x), so |clip(x)−p|≤ζ.
  2. Approximate clipping: the emitted scalar A(x) lies in [0,1] and satisfies the separate, uniform numerical error bound |A(x)−clip(x)|≤ξ. Then |A(x)−p|≤ζ+ξ, so every bound in v1 with +ζ must replace it by +(ζ+ξ).

For example, the range-preserving map A(x)=0 can disagree with p=1 even when ζ=0, so range preservation by itself is insufficient. The final scalar saturation is an explicitly costed operation; its accuracy or exactness is a separate implementation obligation. Define the other probability coordinate as the exact complement 1−A(x), or separately implement and analyze normalization and its errors.
