一次真实注意力调用能够保留多少稀有转移信息

2026 年 11 月 6 日。T1/T2 统计资源桥梁研究。

结论与边界

本轮找到两种不同的单次调用反例。第一种只用固定宽度和标量 value：正 ε 的 LayerNorm 产生可区分全部历史的代数权重，最后的普通概率输出仍保留完整轨迹信息，但预测风险始终很差。第二种支付线性宽度和对数深度：一次宽向量读出后，在终端内部完成二阶计数，确实达到已有的 rare-A 条件统计率。

因此，上一轮的总通信位数下界不能直接转成多次注意力下界。“低维、分数有界、影响很小”也不意味着精确实值输出的 KL 信息很少。尚未解决的是同一固定宽度、付费解码能力和真实概率风险下的调用次数关系。

这些不是新的通用单层表达能力发现。单层甚至标量全上下文编码已有直接先例，本轮作用是验证更严格真实 PreLN 契约下的具体障碍，及检查一次调用的统计用途。

一 冻结模型与共同风险

二阶状态为 A=00、B=01、C=10、D=11，平稳分布为 (u,w,w,w)，w=(1-u)/3，q=ut/w。转移行为

(1−t,t,0,0), (0,0,1/2,1/2),
(q,1−q,0,0), (0,0,1/2,1/2).

本轮使用 0<u≤1/100、1/2≤t≤3/4。整体仍统一快速混合。真实预测时刻是同一条历史 X₁:N 的 N+1，终端状态为 T=(X_{N−1},X_N)，不是独立抽取的查询。总体主风险为 E[TV(Q_N,P(·|T))]；给定 T=A 的条件风险另行标明。

网络从原始符号与公共归一化位置出发，使用 ε=1、gain=2 的全特征 PreLN、残差、自包含因果 softmax、普通最终 LN 与词表 softmax。全向量范数、完整矩阵算子范数及单个算术阶段增益均受固定上界约束。长度相关公共参数允许使用，但宽度、value 维度、层数、参数描述与执行精度分别计费。

二 固定宽度的一次标量调用保留完整信息

令 P 为不小于 N+1 的最小二次幂。二元符号写成 σ_i∈{−1,+1}。使用宽度 8 的原始嵌入

h_i=(σ_i,−σ_i,i/P²,−i/P²,0,0,0,0).

原始公共位置 i/P 只需乘以 1/P。该变换是已计费的有界初始线性嵌入，参数描述 O(logN) 位。合成终端的符号坐标为零。

这些向量均值为零。真实 ε=1、gain=2 的 LayerNorm 后，把第一坐标除以 4 作为标量 value，正好得到

v_i=σ_i/√(5+i²/P⁴).

取 Q=K=0，则一次自包含均匀因果注意力在终端输出

M_N=P²/(N+1) · Σ_{i=1}^N σ_i/√(5P⁴+i²).

没有近似硬匹配、预制相邻特征、额外读出或未计费头。所有行的状态与 value 范数有界。

为什么这个标量没有丢失历史信息

整数 n_i=5P⁴+i² 都落在长度小于 N² 的区间里，而 N²<2√(5P⁴)。若两个整数有相同平方自由部分 d，它们是 da²、db²，其最小正间距大于 2√(5P⁴)，矛盾。因此这些整数具有互异平方自由部分。

不同平方自由整数的平方根在有理数上线性独立，倒数平方根也只是非零有理倍。因此两个不同符号历史不可能具有相同的 M_N。一次标量调用已经给全部 2^N 条历史不同编码。

把 M_N 和 −M_N 写入空的成对坐标，保留完整残差。最终 LN 的对应坐标是

4M_N/√(4+a_T²+M_N²)，a_T=(N+1)/P².

这是 M_N 的严格递增函数。再用普通二元 softmax，最终概率输出仍然单射。宽度、头数、深度、全范数及最终读出敏感性都可以固定；这没有证明逆向解码也具有固定敏感性。

与 rare-u 完整轨迹和末端条件的精确连接

对有限历史集合上的任何两个源分布，单射确定变换保持 KL 和 TV。因此这一个概率输出的 KL 就等于完整历史 KL：

(N−2)[u kl(t,s)+w kl(ut/w,us/w)].

N≥3 时它是 Nu(t−s)² 的量级，不是 Nu²(t−s)²。故普适的“一次固定宽度标量注意力只有 Nu² 信息”命题为假。

条件于真实终端 A 后，单射仍成立。反向符号过程仍是同一个二阶源，从已知 00 出发；前几步含常数级信息，随后 A 访问次数提供 Nu 级信息。因此 N≥3 时，条件完整轨迹 KL 为 (1+Nu)(t−s)² 的量级，具体上下界见附录。N=2 时条件历史固定，该 KL 为零。没有直接把无条件 KL 套到稀有条件事件。

信息全部存在却预测仍差

|M_N|≤1/√5，最终 logit 差的绝对值小于 1，故两个输出概率都大于 1/4。真实终端 C 的下一符号 0 概率为 q，因而该网络的总体风险至少

w(1/4−q)=(1−u)/12−ut ≥3/40.

所以它不是低风险预测器，尽管其最终概率数值在精确实数意义下保留了全部历史信息。该反例明确阻断的是错误的信息上界，不是统计计算下界本身。

精度没有免费消失

参数描述只有 O(logN) 位，但平方根及其和按精确实数计算。2^N 个码落在固定区间内，最小间距至多 O(2^(−N))。要无损区分全部历史，任何有限状态编码至少需要 N 位；这只是最坏历史重建要求，不能改称预测 t 需要 N 位。

因此不能把短系数描述写成短执行精度。也不能仅凭码间距推出任务风险下界：必须证明那些靠得很近的历史在目标概率上确实需要不同输出，并控制其源概率。

三 支付线性宽度的一次调用确实能够统计预测

第二个构造不依赖难以利用的精细标量编码。它复用已有的宽广播，在终端取得按位置排列的原始符号 bank，然后把原本需要第二次 attention 汇总的操作改放到终端内部的已计费 FFN 中。

取 R 为满足 R²≥N 的最小二次幂，s=1/R。一次宽向量均匀读出与已计费的对数深度放大后，各行可见位置的符号坐标为

a_{i,c}=s·1{X_i=c}，未来位置为零。

终端内部对每个 i≥3 和 c∈{0,1} 形成

τ_{i,c}=ReLU(a_{i−2,0}+a_{i−1,0}+a_{i,c}−2s).

它就是缩放后的 00c 三元组指示量。该门组的输入复用次数有界，完整 bias 范数也有界。用权重 s 汇总，得到 C_{00c}/R²；此聚合矩阵范数至多 1，不是未计费的 √N 放大。

随后使用原有的分母选择网格、逐阶段有界放大、归约树和普通 softmax 编译，计算 add-one 估计 (C_{001}+1)/(C_{000}+C_{001}+2)，投影到 [1/2,3/4]。真实正 ε PreLN 的全状态编译误差也计入。

结果：存在不依赖 u,t 的网络族，在 N≥6 时只用一次有效 attention，并满足

E[|Q_N(1)−t| | T=A]
   ≤min{1,157/√(1+(N−2)u)}+C/√N.

这里的估计器、常数 157 和同历史条件风险证明都是已有结果。本轮变化只是把局部三元组计数搬进宽终端，删除第二次有效调用。它仍是解析构造，未生成或执行网络参数。

与上一轮通信下界的关系

令 N 约为 u^(−2)，使用上一轮终端条件信息证明的局部参数先验。先验在终端 A 条件下不变，Bob 奇偶观测的基线信息至多 1/100。上式给条件绝对误差 O(√u)，由绝对损失的最大熵不等式，输出关于未知参数的条件信息至少 0.5 ln(1/u)−O(1)。

因此一次实际调用不仅能隐藏编码，也能支持确实有统计用途的输出。它支付了 O(N) value 维度、O(N) 宽度和 O(logN) 逐位置计算深度，不是固定宽度反例，也没有构造匹配最短的分布式协议。

补充 同一总体风险的完整上界保留输出范围地板

固定二进有理设计裁剪水平 α∈(0,1/4]，允许网络的完整范数常数依赖这个事先声明的 α，但不依赖 N,u,t。把宽终端计数扩充到 A、C 两行；A 用 add-one，C 用无平滑频率且零计数回退为零，B、D 用已知公平分布。真实末端二元组从读出后的第 N−1、N 个位置内部恢复，未外加查询端口。

分母为零由有限网格中的零分支处理，不插入外部除法。把所得预测投影到 [α,1−α] 后，再编译为普通 softmax。对任意实施容差 0<ε≤1/16，可得到

R_N≤1300u/√(1+(N−2)u)+w(α−q)₊+ε,
W=O_α(N+ε^(−1)),
D=O_α(logN+log(1/ε)), 完整value维度按O_α(N+ε^(−1))计费。

其中只有 O(N) 个 value 坐标非零；为不改变原模型，任意 ε 下完整 head 维度按全部宽度计费。仍然只有一次有效注意力。取 ε=1/(16N)，完整 value 维度和宽度均为 O_α(N)、深度 O_α(logN)，误差余项 O(1/N)。该上界使用同一条历史的真实末位置总体风险。旧统计率、投影不等式并非本轮新结果。

固定 α 且 u→0 时，范围项趋于 α/3，不能声称总体 rare-u 风险趋零。如果另行声明已知 u≥ρ 并把 α 取得足够小，可以消掉该项，但 α 所带来的范数、logit 与近似成本必须作为 ρ 依赖资源计入。α 是参考估计器的设计区间，不声称近似后的实际网络恰好具有同一个锐利 logit 跨度。

四 资源与证明依赖

标量构造：宽度 8，头数 1，value 维度 1，一次有效调用，常数深度与完整范数，O(logN) 参数描述位。全 N 行持久状态仍需 O(N) 实数槽位；若显式存储稠密注意力分数或权重，另需 O(N²) 临时空间。均匀注意力可以流式计算；朴素稠密计算为 O(N²)。精确执行含平方根和 softmax，没有有限字长实现保证。最终概率风险不收敛。

宽统计构造：一次有效头，value 维度 O(N)，模型及 FFN 宽度 O(N)，深度 O(logN)，全状态及单阶段矩阵范数固定。保守稠密计账为 O(N²logN) 个系数、O(N²log²N) 描述位、O(N²) 滚动激活槽位和 O(N³logN) 算术工作。它远比流式计数器昂贵，不能称总计算最优。

宽构造有 O(logN) 系数精度及多项式小误差半径的解析保证，但这不是完整浮点执行定理。所有 LN、softmax、累加器和舍入位数仍需另外定义。全 N 行更新没有被忽略。

五 先行工作和严格定位

Kajitsuka–Sato 的 ICLR 2024 论文 Theorem 2 已给出单层、单头、低秩 contextual mapping，正文也允许标量压缩全上下文。其 §2.2 模型省略 LN，附录构造通过 Q/K 缩放取得随长度增长的分数间隔，且输出分离可能极小。本轮不是新的通用表达能力结论，而是 ε=1、零分数、固定完整范数和短参数的具体实现与证明路线反例。

Hahn 的小影响界控制距离而非精确相等，所以与极细间距单射相容。Merrill–Sabharwal 的有限精度结论对实际执行状态计位，不能用短系数描述替代。完整来源定位附后。

宽统计构造继承已有广播、分母选择器、正 ε PreLN 编译、logit 近似和旧 Markov 估计率；不把组合这些工具称为新的估计率。

六 仍未解决的母问题

目前没有任意多次有效 attention 的源平均统计资源下界，也没有固定宽度下达到完整历史率的匹配调用次数前沿。一个有效的新命题必须同时限制或付费：可执行的状态精度、目标相关解码敏感性、value 维度、全部非终端状态更新和真实终端风险。

不能为了回避反例而悄悄改变原精确实数模型；有限精度模型若进入主定理，必须明确作为新量词契约。也不能把总体风险换成 A 条件风险。冻结普通输出范围在 C 行造成的旧概率地板仍是总体 rare-u 率的独立约束。

未训练、未仿真、未数值枚举、未形式验证或外部同行评审；独立审阅是解析证明与契约复核。全部失败与旧稿保留，没有公开上传或投稿。

附录 A 固定宽度标量的完整反例

One raw PreLN scalar can retain the entire rare-source experiment

1. Main result

Fix N>=3 and P=2^ceil(log2(N+1)). There is a genuine raw-symbol, full-prefix causal PreLN network with:

- physical width eight; - one useful head invocation, identically zero scores, and a scalar head value; - a bounded initial affine embedding, one complete ordinary PreLN block with zero FFN, a final full-feature LayerNorm, bounded affine logits and ordinary binary softmax; - every LayerNorm having epsilon=1, scalar gain two and shift zero; - fixed, N-independent full-state, full-matrix, full-bias, value and primitive-Lipschitz bounds; - O(log N) binary description length per coefficient, with only the dyadic coefficient 1/P depending on N;

whose final normalized probability vector is an injective function of the ENTIRE binary word X_1:N.

Consequently the exact law of that single scalar read, its complete terminal state, and its final probability output all retain the full finite-history KL divergence between any two positive source laws. The counterexample has constant continuation Lipschitz constant, not merely unbounded decoding gain. This refutes a universal O((1+Nu^2)(t-s)^2) KL bound for exact one-read outputs under fixed width, fixed depth, bounded scores, bounded primitive gains and short coefficient descriptions alone.

There is no contradiction with known statistical risk lower bounds: exact mutual information/KL permits arbitrarily fine tests of an observed real number. The network's bounded-Lipschitz output is not asserted to estimate the rare parameter. Finite activation precision, additive noise, or a restriction on the downstream estimator changes the observation experiment.

2. Exact raw implementation, retaining every register

Use binary raw symbol onehots. Put sigma_i=+1 for symbol 1 and -1 for symbol 0; the synthetic row T=N+1 has sigma_T=0. The only positional input is the public p_i=i/P. A counted affine embedding produces

h_i=(sigma_i,-sigma_i,r_i,-r_i,0,0,0,0),
r_i=p_i/P=i/P^2.

This embedding uses no adjacent-symbol feature, historical encoder, pair port, or precomputed statistical feature. Its full operator norm is at most two. All eight coordinates enter every LayerNorm. They have zero mean.

The cited standard-PreLN raw contract uses p_i=i/P. If instead the public coordinate is i/(N+1), the equally bounded dyadic embedding coefficient (N+1)/P^2 gives the same r_i and still has O(log N) description length. This is an initial counted affine embedding, not an assumption that a PreLN residual FFN performs an exact unnormalized rescaling.

For a real row i<=N, with LN denoting epsilon-one/gain-two LayerNorm,

||h_i||^2=2+2r_i^2,
LN(h_i)_1=4 sigma_i/sqrt(5+r_i^2).

Take W_Q=W_K=0 and W_V=(1/4)e_1^T. Thus the real-row scalar value is

v_i=sigma_i/sqrt(5+r_i^2)
   =P^2 sigma_i/sqrt(5P^4+i^2).

The synthetic value is exactly zero: its first coordinate is zero, whatever its different normalization denominator. Self is included in every full-prefix average. At physical row t the one head returns

A_t=(1/t)sum_(i<=min(t,N)) v_i.

Let W_O write A_t and -A_t into the previously zero fifth and sixth coordinates. The attention residual is therefore exactly

u_t=(sigma_t,-sigma_t,r_t,-r_t,A_t,-A_t,0,0).

The FFN branch is identically zero, but its full-feature positive-epsilon input LayerNorm remains present in the complete block. There is no residual deletion, normalization shortcut, or ignored stale register. In particular, the nonterminal rows retain their own raw-symbol and position pairs and their updated prefix averages. No later operation reads those rows; all remaining operations are positionwise and output is terminal-only.

All |v_i|<=1/sqrt(5), so |A_t|<=1/sqrt(5). Since r_t<=1/P and P>=4, every reached u_t has squared norm at most 2+2/P^2+2/5<3. W_O has norm sqrt(2); all other matrices and biases are bounded by fixed constants. The final full-feature LN and affine head also have fixed full-norm bounds. No coordinatewise bound is substituted for a full-vector bound.

At T the residual is public except for A=A_T. The final LN's fifth coordinate is

f_N(A)=2A/sqrt(1+(r_T^2+A^2)/4).

Choose ordinary vocabulary logits (f_N(A),0), followed by binary softmax. Thus

q_1(A)=1/(1+exp(-f_N(A))), q_0(A)=1-q_1(A).

Both coordinates are strictly positive and sum to one exactly on every word. This uses the actual final full-feature normalization, including both copies of A and the retained position pair. Since

f_N'(A)=2(1+r_T^2/4)/(1+(r_T^2+A^2)/4)^(3/2)>0,

the final probability is strictly increasing in A. Also f_N'<=2 globally, so the continuation A->q is globally 1/2-Lipschitz in binary TV. The primitive LN maps are globally two-Lipschitz. The useful attention count, complete sequential depth and every continuation gain remain constant.

Ablating W_O makes the terminal output exactly (1/2,1/2), whereas an all-symbol-1 input gives A>0 and q_1>1/2. The single invocation is genuinely useful to this map, though the map is not a good estimator of t.

The failure as a predictor is quantitative. Since |A|<=1/sqrt(5), its logit contrast has magnitude |f_N(A)|<1. Both predicted probabilities exceed 1/(1+e)>1/4. On the rare family's terminal C=10, the true next-zero probability is q_t<=1/44. Consequently its SAME-history averaged prediction risk is at least

w(1/4-q_t)=(1-u)/12-ut>=3/40.                    (0)

Thus this ordinary-softmax probability output simultaneously retains the complete exact-history experiment and has prediction risk bounded away from zero throughout the rare family. Exact information preservation is not an accurate task decoder.

3. A finite-coefficient algebraic injectivity proof

Set n_i=5P^4+i^2 for i=1,...,N. These are distinct positive integers. Write each uniquely as

n_i=d_i a_i^2,

where d_i is a positive squarefree integer and a_i is a positive integer. The d_i are pairwise distinct. Indeed, if n_i=d a^2<n_j=d b^2 had the same squarefree part, then b>=a+1 and

n_j-n_i=d(b^2-a^2)>=d(2a+1)
         >2 sqrt(d n_i)>=2 sqrt(5) P^2.

But n_j-n_i=j^2-i^2<N^2<P^2, a contradiction.

The square roots of distinct positive squarefree integers are linearly independent over Q. One proof takes the multiquadratic field generated by the finitely many primes occurring in those integers. Independent sign changes of the prime square roots are its automorphisms; the distinct squarefree radicals carry distinct characters of this sign group. Averaging a putative relation against each character isolates its coefficient. The squarefree integer 1, if present, corresponds to the trivial character. Equivalently these radical monomials form the usual rational basis of that multiquadratic field.

Since 1/sqrt(n_i)=sqrt(d_i)/(a_i d_i), the numbers 1/sqrt(n_i) are also Q-linearly independent. Therefore two distinct words sigma,tau in {-1,+1}^N satisfy

sum_i (sigma_i-tau_i)/sqrt(n_i) != 0.

The actual terminal scalar is

A(sigma)=P^2/(N+1) sum_i sigma_i/sqrt(n_i),

so it is injective. The final q_1 is strictly monotone in A and hence injective too. No generic transcendental coefficient, learned position table, exponentially many initial features, unbounded score, or unpaid positional precomputation is used. The irrational radicals arise from the mandatory ordinary epsilon-one LayerNorm applied to raw symbol and public position coordinates.

The multiquadratic fact is an algebraic lemma, not an assertion that a bounded-depth network implements the inverse map. No inverse is needed to identify the exact probability law of an injective statistic.

4. Full rare-source information survives, including the actual terminal

Use the same stationary rare family as RARE_PARITY_INFORMATION and RARE_TERMINAL_PARITY_INFORMATION v2:

pi=(u,w,w,w), w=(1-u)/3, q_t=ut/w,
P_t=[[1-t,t,0,0],[0,0,1/2,1/2],
     [q_t,1-q_t,0,0],[0,0,1/2,1/2]],
0<u<=1/100, 1/2<=t<=3/4.

States are A=00,B=01,C=10,D=11. The stationary initial-pair law pi is the same for the compared t,s at fixed u. Every finite binary word has positive probability. The exact path KL is

KL(P_t^X || P_s^X)
  =(N-2)[u kl(t,s)+w kl(q_t,q_s)].                 (1)

Here kl is Bernoulli KL; the coordinate orientation of the C row is immaterial. In this rectangle, Pinsker and the elementary chi-square upper bound give

2(N-2)u(t-s)^2 <= KL(P_t^X || P_s^X)
                 <= 8(N-2)u(t-s)^2.              (2)

For the upper, kl(t,s)<=16(t-s)^2/3. Also q_s<=1/44 and q_s>=u/(2w), so w kl(q_t,q_s)<(88/43)u(t-s)^2. Their sum is below eight.

Any injective deterministic map on this finite common sample space preserves KL exactly. Thus (1)-(2) also hold with X replaced by A_T, the full terminal state, or the final ordinary-softmax probability vector. The hidden all-row updates and final FFN/residual pathway have not been discarded.

More generally, for ANY parameter prior and any pre-existing side information B, injectivity gives the exact equality

I(Theta;Q_N | B,E)=I(Theta;X_1:N | B,E)

whenever the conditioning event E has positive probability. This equality, rather than a claimed mutual-information rate inferred solely from pairwise KL, is the corresponding MI statement.

4.1 Terminal A conditioning is not a free stationarity assumption

Let E={X_(N-1)=X_N=0}. Its probability is exactly u for every parameter. As proved directly in the terminal-parity note, reversing a stationary path conditional on E produces the same symbol source P_t initialized at pair A. It is an identity of conditional finite-history laws. Thus the conditional path KL is the sum of transition KLs along a P_t chain started at A, not equation (1) blindly divided by u.

For every state x,

P_t^2(x,D)>=1/4,  P_t^2(D,A)=q_t/2.

Therefore

P_t^4(x,A)>=q_t/8>=3u/16.                        (3)

For N>=3 the first reversed transition starts at A and contributes kl(t,s)>=2(t-s)^2. For each reversed transition whose pre-transition pair has taken at least four steps, (3) gives another contribution at least (3u/8)(t-s)^2. There are (N-6)_+ such transitions. Consequently

KL(P_t^(X|E) || P_s^(X|E))
  >=[2+(3/8)(N-6)_+ u](t-s)^2.                  (4)

For a matching order upper, the common atom P_t^2(x,D)>=1/4 implies

TV(P_t^j(A,.),pi)<=(3/4)^floor(j/2).

The expected number of A visits before the N-2 transitions is at most (N-2)u+8. Bound A-row KL by 16(t-s)^2/3 and every C-row KL by 7u(t-s)^2, using w>=33/100 and 88/(43w)<7. The other rows contribute zero. A loose consequence is

KL(P_t^(X|E) || P_s^(X|E))
   <=60(1+Nu)(t-s)^2.                            (5)

The scalar and final output remain injective on the restricted set of histories ending in A, so they preserve this conditional KL exactly as well. Thus the O(1) terminal transient does not rescue an O((1+Nu^2)(t-s)^2) exact-output bound. For example, N of order u^(-2) makes (4) grow as (t-s)^2/u, while the proposed parity-scale upper would remain O((t-s)^2).

These are observation-channel information claims. They neither turn the displayed network into a good next-token predictor nor provide an efficient inverse/estimator from its code.

5. Precision ledger: short coefficients are not short activations

Only the coefficient 1/P varies with N. It is dyadic with O(log N) ordinary binary description length. All other embedding/head/LN coefficients are fixed rationals. Nevertheless the intermediate values and final probabilities are evaluated with exact-real square-root, division and exponential semantics. Coefficient descriptions do not imply an O(log N)-bit state register.

Constant width and depth do not mean constant total distributed memory or work: there are N+1 physical rows and O(N) real activation registers. The one full-prefix head has O(N^2) dense work if evaluated by the usual all-row dense causal attention implementation. All of those rows and updates belong to the construction; no cached history-free replacement is assumed.

There are 2^N distinct A values in [-1/sqrt(5),1/sqrt(5)]. If delta_N is their minimum separation, then

delta_N <= (2/sqrt(5))/(2^N-1).                   (6)

To robustly reconstruct every word from an adversarial absolute-error observation A+e with |e|<=eta, one needs 2eta<delta_N (at equality, two permitted observation intervals can meet). Any finite-alphabet observation that is injective on every word must have at least 2^N symbols, hence at least N bits. These are all-history injectivity statements; they are not lower bounds on precision needed merely to estimate t under the rare source.

For completeness an extremely loose algebraic separation bound is available. Put n_max=5P^4+N^2 and B=2N n_max^((N-1)/2). For a nonzero difference vector e_i in {0,+2,-2},

beta=sum_i e_i product_(j!=i) sqrt(n_j)

is a nonzero algebraic integer in a field of degree at most 2^N. Every conjugate has absolute value at most B. Its nonzero integer norm has absolute value at least one, so

|beta|>=B^(-(2^N-1)).

It follows that

delta_N >= [P^2/(N+1)]
             B^(-(2^N-1)) n_max^(-N/2).           (7)

This only supplies a very inefficient sufficient precision of O(N 2^N log N) fractional bits for preserving all distinct scalar codes under sufficiently accurate evaluation. It is not a claim about finite-arithmetic implementation, a tight separation rate, or efficient parameter generation.

5.1 The informative fine distinctions are uniformly tiny

Let C=sum_i sigma_i and define the simple token-count code

A_0=C/[(N+1)sqrt(5)].

The mean-value theorem for z->(5+z)^(-1/2) yields, on EVERY word,

|A-A_0|
  <= [1/(2*5^(3/2))] N^2/P^4
  <= [1/(2*5^(3/2))] N^(-2).                    (8)

The final actual softmax output is consequently within

1/[4*5^(3/2) N^2]

in TV of q(A_0). The latter is computed by applying the same mathematical continuation to the count code. This is an approximation/comparison statement, not an additional uncounted neural operation.

At N of order u^(-2), this discrepancy is O(u^4), much smaller than the full-history rare-risk scale u^(3/2). Exact KL nevertheless retains all the Nu information. This sharply demonstrates why closeness of two scalar values, bounded continuation sensitivity, or equality of means cannot be converted into an exact-information statement without an explicit observation model.

6. Consequences and the correct stopping boundary

1. A fixed-dimensional additive statistic can have full rare-transition information. Equality of its one-symbol means, or a variance calculation, does not constrain its exact law enough. 2. Raw positive-epsilon PreLN itself supplies the position-dependent algebraic weights. One need not appeal to an expensive full-history positional encoder to refute a width-only exact-information claim. 3. Fixed paid continuation sensitivity does not bound unregularized KL: the final bounded-Lipschitz ordinary-softmax output here is injective. A lower bound on estimation by bounded-sensitivity decoders must retain that decoder restriction throughout its statistical comparison. 4. This does NOT contradict the old one-invocation gain/depth/risk theorem, the parity-channel theorem, or the total-bit lower. Those statements concern different observation/computation restrictions and do not grant arbitrary exact inversion for free. 5. A future resource bridge must specify the precision or permitted statistical use of the complete visible representation, rather than charging only its dimension. This note adds no observation noise and claims no noisy-model resource separation. The exact-model risk frontier remains open.

Precision has THREE distinct meanings:

1. Coefficient/public-input description lengths are O(log N). This alone is not an arithmetic guarantee. 2. The clean intermediate physical history-bank separation is at least a constant times eta/R=N^(-O(1)); immediately after the read and before paid saturation it is smaller by a further factor at most N+1. Thus sufficiently fine O(log N)-scale fractional resolution is consistent with distinguishability, but a free infinitely accurate bounded scalar is not the stated resource. 3. A sufficient adversarial execution-error radius can also be charged without claiming a floating-point implementation. Every complete actual sublayer is dimension-free Lipschitz in maximum-row Euclidean norm; uniform attention and epsilon-one LN retain this property. For additive perturbations of radius delta after each residual sublayer, output error is at most C delta L_*^(2D+1), with an enlarged fixed L_*>1. Since D=O(log N), choosing delta=N^(-A) for sufficiently large fixed A makes extra TV error O(N^(-1/2)). A larger fixed A also preserves intermediate history-bank separation. This is a robust error-radius statement p=-log2 delta=O(log N), NOT a machine word-length, rounded-LN/softmax, accumulator-size or complete finite-arithmetic theorem.

If all-dyadic parameters are wanted, round the rational table with zero support and paired antisymmetry preserved, to N^(-A) coordinate error. Operator errors cost at most d times this precision, and the polynomial continuation sensitivity is absorbed by a sufficiently large fixed A. This gives the same asymptotic approximate output, not exact ratio evaluation. It changes none of the information or invocation conclusions.

At N=Theta_order(u^(-2)), the paid width is Theta(u^(-2)), depth O(log(1/u)), and sufficient coefficient/error-radius exponents are O(log(1/u)). Dense storage/work costs remain as above. The construction therefore gives no fixed-width or equal-total-resource separation against repeated attention.

D=O_alpha(log N+log(1/epsilon)),                (E2)

and intermediate FFN width O_alpha(N+epsilon^(-1/2)) before ordinary constant-factor padding into d. All head, full-state, matrix, bias and primitive constants are bounded by C_alpha. LayerNorm epsilon=1, gain=2, shift=0 throughout; the final head is ordinary bounded affine-softmax. Its useful attention count is one, not its total sequential depth.

For epsilon_N=min{1/16,1/N}, (E2) reduces to width O_alpha(N), depth O_alpha(log N), and implementation remainder O(1/N). The whole physical value width is charged, including inert coordinates; no special permission for rectangular narrow value projections is needed. The constants can depend on alpha. This does NOT evade the frozen output floor as alpha tends to zero: requiring alpha to vary with rarity changes the declared norm/range resource, and C_alpha is not asserted uniform in alpha.

Alpha specifies the reference predictor's interval projection. Because the physical output approximates it, this note does not assert the exact sharp realized logit span log((1-alpha)/alpha). A strict exact-span theorem would need a reserved approximation margin or an additional range-preserving argument. The physical full norms and thus some fixed realized span remain bounded by C_alpha, independently of N and epsilon.

2. Reuse one wide read and compute both needed row counts locally

Use the conditional companion's Sections 2-3 without change. With R^2=Q>=N and s=1/R, after the unique read and paid saturation every row j has ordered prefix coordinates

a_(j,i,c)=s 1{i<=min(j,N)}1{X_i=c}.

Form, for (a,b) equal to A=00 and C=10, and c=0,1,

tau_(j,i,ab,c)=ReLU(a_(j,i-2,a)+a_(j,i-1,b)
                                     +a_(j,i,c)-2s),
f_(j,ab,c)=s sum_(i=3)^N tau_(j,i,ab,c),
v_(j,ab)=f_(j,ab,0)+f_(j,ab,1).

These equal C_(j,ab,c)/Q and J_(j,ab)/Q. Computing all four contexts would also cost only a constant factor, but is unnecessary because rows B,D are known fair. Every input coordinate is used in a bounded number of triple gates. Complete gate/bias norms and complete states remain bounded. Each count aggregation has norm at most one, as in the companion. No context features or adjacent-token access are given externally.

3. Different A and C ratio branches, including exact zero fallback

For A use the companion's exact add-one table, obtaining

r_(j,A)=(C_(j,A,0)+1)/(J_(j,A)+2),

where r denotes the next-ZERO probability.

For C use a separate 1/Q-grid selector h_m=s1{J_(j,C)=m}, m=0,...,N-2. Form

z_(j,m)=ReLU(s f_(j,C,0)+h_m-s).

If m is inactive the gate is zero because f<=1. If m=J it equals s C_(j,C,0)/Q. Set block m=0 identically to zero. For m>=1, amplify by the public factor

A_m=RQ/m,

through O(log N) diagonal stages of norm at most two, followed by the paid balanced sum tree. The output is exactly

r_(j,C)=C_(j,C,0)/J_(j,C) if J_(j,C)>0,
r_(j,C)=0 otherwise.                           (E3)

No discontinuous test or external division was inserted: zero is one branch of the finite-grid ReLU selector table. All rows have integer counts on the same grid, exactly one active selector, and 0<=C<=J. Consequently all intermediate active values are at most one and all inactive values are zero. This is a simpler all-row domain than the old terminal-only rational readout. The m=0 zero map is implemented with a zero diagonal entry; for m>=1 all multiplier factors are positive and at most two.

The rational table has O(N) entries, O(log N) coefficient-description bits per entry, O(log N) paid depth, bounded matrix norms at every stage and bounded complete states. A and C branches run in parallel with only a constant-factor full-norm increase. Set r_B=r_D=1/2 using the anchor.

4. Recover the actual terminal pair internally

Project the broadcast bank onto the four coordinates at indices N-1 and N. Restore their scale from s to one by log2 R paid diagonal doublings. Their complete norm stays at most sqrt(2) at every row: a coordinate is either zero or a partial amplification of one original symbol bit.

Write the resulting two symbol onehots as y_old and y_new. For each ab define

g_ab=ReLU(y_old(a)+y_new(b)-1).

At the synthetic terminal exactly one g_ab is one and it identifies the real pair (X_(N-1),X_N). At rows j<N, the final symbol is absent, so all g_ab vanish; at rows j>=N the pair is correctly available. This fixed-index local projection occurs AFTER the one global read, so it is not a free suffix port or structural local-copy mask.

Select the next-zero estimate continuously by

z_j=sum_ab ReLU(r_(j,ab)+g_ab-1)
                        +(1/2)(1-sum_ab g_ab). (E4)

Because g is either one-hot or all zero, (E4) equals the selected row estimate or the harmless nonterminal default 1/2. Every r is in [0,1], so the ReLU gates implement the binary selectors exactly on the reference domain. The finite sums have constant dimension and constant operator/bias norms. At the synthetic terminal this is precisely the OLD mixed estimator: add-one at A, unsmoothed zero-fallback at C, exact fair at B,D.

5. Projection, log preparation and physical compilation

Clip z_j to [alpha,1-alpha], yielding p_j=(clip(z_j),1-clip(z_j)). The reference is a probability vector at every row, including ablation. Use the old scaled-hinge approximation to log on [alpha,1] with

m=O_alpha(epsilon^(-1/2))

hinges per coordinate and uniform log error at most a fixed small multiple of epsilon. Input scaling 1/sqrt(m) controls fanout and full biases, while adjacent slope differences O_alpha(1/m) control the complete output row norm. Coefficient descriptions use O_alpha(log(1/epsilon)) bits. Thus growing log precision purchases width rather than unbounded primitive norms.

Pair all coordinates, append the complete output-bank copy and scratch clear, and keep a common bounded logical tube for original and single-read-ablated programs. The reference stage count before restoration is O(log N), while its width is O_alpha(N+epsilon^(-1/2)). The common fixed Lipschitz envelope is independent of epsilon because of the scaled hinges.

Apply exactly the conditional companion's small-amplitude actual-PreLN compiler. Select eta=2^(-M) so

C eta^2 L^(m_ref)/d <= c epsilon

and the common tube conditions hold. This requires M=O_alpha(log N+log(1/epsilon)). Add inert zeros so

d>=C_alpha (N+epsilon^(-1)).

The inherited radial restoration and final-LN logit error are bounded by

c epsilon+7(Z+c epsilon)^3/(12d).

With constants sufficiently large, the final ordinary-softmax prediction differs from the projected reference by at most epsilon in TV on EVERY input word, for both original and ablated network. No execution-time log/division primitive, nonzero sqrt(d)-norm padding, arbitrary terminal decoder, or uncharged clearing is added.

6. Statistical envelope and physical usefulness

The old full averaged theorem in `../u_blind_full_averaged_20261103_2147/full_averaged_tv_bound_v1.html` gives the mixed reference risk at most

1300 u/sqrt(1+(N-2)u).

The old projection comparison in `../rare_statistical_resource_reset_20261106/RARE_OUTPUT_RANGE_ASSESSMENT.candidate.v1.md` applies because alpha<=1/4: A and fair rows lie inside the allowed interval, while the C-row target q has the only possible range deficit. Pointwise projection therefore gives

R(projected reference)<=1300 u/sqrt(1+(N-2)u)
                                          +w(alpha-q)_+.

The pathwise implementation error proves (E1) without any independence assumption between terminal pair and counts. Statistical estimation, same-history dependence handling and this projection inequality are inherited results, not new proofs.

Deleting the single read removes all recovered symbols and counts. In (E4) all pair selectors then vanish and the reference returns 1/2 at every row. On the all-zero word the actual terminal pair is A, and the unablated next-zero estimate is (N-1)/N>=5/6. Its projected value is at least 3/4 because alpha<=1/4. Thus ideal separation is at least 1/4. With epsilon<=1/16, the two actual physical outputs remain separated by at least 1/4-2epsilon>=1/8. The attention is genuinely useful in this implementation.

7. Charged resources and limits

Let W=O_alpha(N+epsilon^(-1)), D=O_alpha(log N+log(1/epsilon)), and b=O_alpha(log N+log(1/epsilon)). Conservative dense accounting gives:

- parameter coefficients O(D W^2), parameter-description bits O(D W^2 b), including all LN gains/shifts; - rolling all-row real states O(NW), plus O(N^2) score slots if attention is materialized; - dense projections/FFN work O(D N W^2); - useful attention products O(N^2 W), charging the complete physical value width even though only O(N) value coordinates are nonzero; dummy slots densely evaluated cost O(D N^2 W); - public positions O(N log N) bits and explicit mask O(N^2) bits if stored.

For epsilon_N=min{1/16,1/N} these become the same O_alpha(N)-width, O_alpha(log N)-depth and O_alpha(N^3 log N) dense-work orders as the conditional witness, with an O(1/N) implementation remainder.

These are exact-real mathematical constructions. A sufficient additive sublayer error radius is polynomially small in N and epsilon by the same global Lipschitz propagation argument as the companion, so its negative logarithm is O_alpha(log N+log(1/epsilon)). This is not a finite machine arithmetic, accumulator, trained-network or emitted-parameter certificate.

If a known rarity floor rho is declared and alpha is chosen below every allowed q, the range term vanishes. The associated alpha-dependent norm and log-approximation constants must then be charged as rho-dependent resources. No uniform-in-rho fixed norm/range theorem is claimed. Conversely, for fixed alpha and u tending to zero, the floor tends to alpha/3 and cannot be removed by this or any other bounded-logit history processor.

The purpose of this extension is to show that one useful attention invocation can implement the old statistical-plus-range envelope under complete, explicitly paid actual-PreLN resources. It does not claim a better estimator, width optimality, a fixed-width separation, a matching information budget, or external novelty.
