The endpoint c=1/2 is wordwise safe

3 November 2026. This immutable analytic addendum supplements the fixed-c two-interval result, SHA-256 2d8d6b8c668d1726cd16673b161f8c4a779f3889ea9f13dc0ccc1381ae0d27d0. It awaits independent review. No experiments, enumeration or source overwrite were used.

Claim

For the exact same four-block no-LN graph, change only its lag-one Q coefficient to implement ηN=1/[2(N+2)]. For every N≥2 and every data word, the final binary vocabulary-softmax output is exactly the unperturbed model's output. Thus the positive fixed-c safe interval includes c=1/2; the failure result for each fixed 1/2<c<3/2 remains unchanged. This endpoint result is not a claim about c=3/2, sequences cN approaching either boundary, other perturbations, architectures or finite floating-point arithmetic.

Proof

Put L=N+2, η=1/(2L), r=i−1 and s(i,j)=2i(i−1)j−(1+η)ij². All important lag-one copies occur at 4≤i≤L. At the left neighbor j=r−1,

s(i,r)−s(i,r−1)=i[1−(2i−3)/(2L)].

The displayed expression is concave in i. On [4,L] its endpoint values are 4−10/L≥3/2 and 3/2, so this gap is at least 3/2. At the right neighbor j=r+1=i, the gap is i[1+η(2r+1)]≥i. For any remaining key with integer d=j−r and |d|≥2, use j,r≤L to obtain

s(i,r)−s(i,j) ≥ i[d²−2Lη|d|]=i|d|(|d|−1).

Write S for the sum of the exponential weights of all incorrect keys relative to the correct key. There is at most one key at each signed integer distance; including extra impossible keys only increases the bound. For i≥4,

S ≤ e^(−3/2)+e^(−4)+2e^(−8)/(1−e^(−8)) < 1/3.

For a purely elementary verification, e^(3/2)>4 and e⁴>32 by their first positive series terms, hence e⁸>1024. Thus the right side is less than 1/4+1/32+1/256=73/256<1/3. The actual wrong attention mass is S/(1+S)<1/4, so the unchanged fixed snap returns the correct bit exactly at every required copy location.

At every valid historical candidate the lag-one and unchanged lag-two snaps therefore match the unperturbed graph. Invalid candidate gates remain zero; the terminal query at i=L, including N=2, sees the correct previous data bit. The dependency audit in the companion safe-window proof then gives identical anchor gates, terminal query, BOS contributions, length marker, selected p, fourth-block logits and final softmax. Raw copied values and unused residual slots need not be identical. This establishes the wordwise output identity for all N≥2. ∎
