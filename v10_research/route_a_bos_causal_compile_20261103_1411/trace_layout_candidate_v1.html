Proposed coordinate layout for the one-hot trace

2026-11-03. Design only; no checker or test executed. The schema was separately reviewed, but this concrete layout and checker implementation require independent review before running.

At fixed N≥3, set D=ceil sqrt(N+33), h=D², d=2h. Use zero-indexed state coordinates: 0 constant 1, 1 input bit x_i, 2 v_i=1{i≥3}, 3 z_i=1{i=1}, positions e_i occupy 4,…,N+3 (e_j at 3+j). Let a=N+4. Coordinates a,a+1 hold copy outputs for lag 1,2; a+2,…,a+5 hold historical key K in order 00,01,10,11; a+6,…,a+9 hold query Q in the same order; a+10 holds Y_i; a+11 is output p. Every remaining initial coordinate is zero. These indices are below d because h≥N+33.

First-head Q/K have dimension h, scaling 1/D. For ℓ=1,2 and output coordinate r∈{0,…,N−1}, (W_Q^ℓ)_{r,3+(r+1+ℓ)}=D c ln2 when r+1+ℓ≤N, and all other coefficients are zero. Thus its Q_i has coefficient D c ln2 at r=i−ℓ−1 if i−ℓ≥1, otherwise zero. (W_K^ℓ)_{r,4+r}=1 for 0≤r<N, all other entries zero. A scalar value projection selects state coordinate 1. W_O writes the two head outputs to a and a+1 respectively; residual adds to their zero initial values. As usual score scaling is 1/D; test records encode Q's coefficients of ln2 and exact K/V entries.

The shared FFN sets K and Q using G(A,v)=ReLU(2A+2v−9/2)−ReLU(2A+2v−11/2), where A is the sum of the two selected bit-or-complement values. Historical K uses lag-2 then lag-1; Q uses lag-1 then raw x_i. The FFN also writes Y=ReLU(x_i−z_i)+z_i/2. Each FFN output writes a previously zero work coordinate, and residual carries all input features and two copied fractions unchanged. The checker should save preactivation, each hinge output and exact output for all eight gates, Y calculation, and all state coordinates.

For block 2, active Q/K again have dimension h and scale 1/D. Query projection has (W_Q)_{r,a+6+r}=D b ln2 for r=0,…,3 and (W_Q)_{4,0}=D(b+1)ln2. Key projection has (W_K)_{r,a+2+r}=1 for r=0,…,3 and (W_K)_{4,3}=1. The scalar V projection selects a+10. Thus the score divided by ln2 equals b<Q_i,K_j>+(b+1)z_j. W_O selects the scalar head result and writes to initially zero coordinate a+11; the other head and this block's FFN are zero. The output vector is the exact linear readout (1−p,p).

Pre-run reviewer should verify matrix dimensions and indices, every initial zero/residual assignment, projection map, causal visibility, bit/complement order, symbolic scores and the backend/test scope. After code is written, the reviewer must separately inspect that it actually applies these sparse matrices rather than substituting hand-coded logits; no execution until both layout and checker are approved.
