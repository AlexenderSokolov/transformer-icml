Two-layer causal no-BOS add-one baseline with finite scores

2026-11-03. Candidate consequence of prior mechanisms, not a novelty claim. Independent review of the central architecture and margins received; the full exact-rational bit ledger remains under review. No training, source publication, random sampling, LayerNorm, language-model output softmax, or fixed-word floating-point guarantee is claimed. No BOS token is added. The earliest input position instead serves as a pseudo-count value in the second attention block; its input bit remains available to the first block and in residual state. The architecture has two ordinary causal attention/FFN residual blocks, absolute positions and two heads per block, with the second head of the second block set to zero. Its much larger positional dimension makes no efficiency claim over existing constructions.

1. Target and fixed construction

Given X₁,…,X_N∈{0,1}, N≥3, use exactly these N input positions, with no added BOS token. Write m=N−2 and s=(X_{N−1},X_N). For i=3,…,N let the historical key be (X_{i−2},X_{i−1}) and value X_i. Let J be the number of historical keys equal to s and C the sum of their values. The comparator B=(C+1)/(J+2) is the same-history add-one estimator, including J=0.

Choose η∈(0,1], integers b=⌈log₂(max{1,N/η})⌉ and c=⌈log₂(32(N+1))⌉. Let s₀=ln2. Give each position j=1,…,N a fixed absolute one-hot vector e_j, flag v_j=1{j≥3}, first-position flag z_j=1{j=1}, and token-bit input x_j=X_j. Both flags can be computed from the public positional representation. D=⌈√(N+33)⌉, d_head=D², d_model=2D². Allocate disjoint residual coordinates for features and reserve zero coordinates for each head/FFN write; position features and all outputs are ordinary input embeddings and tokenwise features, not an attention mask.

In block 1, head ℓ∈{1,2} has key e_j, query c s₀ D e_{i−ℓ} when i−ℓ≥1 (and zero otherwise), and value x_j. The standard dot-product scaling by 1/D gives logit c s₀ at j=i−ℓ and zero at all other visible j≤i. For i≥3 the target exists, and the total wrong-key mass is at most (N+1)2⁻ᶜ≤1/32. Two distinct heads write the two approximate lag bits to distinct residual coordinates.

The first FFN forms historical one-hot K_i and query one-hot Q_i using the two copied bits and x_i. For any two chosen bit-or-complement signals a,b′, define A=a+b′ and

G(A,v)=ReLU(2A+2v−9/2)−ReLU(2A+2v−11/2).

If v=0, each copy lies in [0,1], so G=0. If v=1 and both copied inputs are within 1/16 of their intended binary bits, G equals exactly 1 on the selected pair and exactly 0 on every other pair. This covers all i≥3 and makes K_i,Q_i exact. Invalid i∈{1,2} have K_i=Q_i=0. The same FFN writes Y_i=ReLU(x_i−z_i)+z_i/2 to a fresh coordinate: Y₁=1/2 while Y_i=X_i for i≥2. The input bit X₁ is not lost: it was available to the first-block copies at positions 2 and 3 and remains in a separate residual coordinate. The linear output transform writes these features to fresh coordinates; the residual carries x_i, z_i and v_i.

In block 2 one head uses the ordinary full causal mask j≤i, score

 b s₀ ⟨Q_i,K_j⟩ + (b+1)s₀ z_j,      value Y_j computed by the first FFN.

The first-position flag is implemented as a key coordinate and a constant query coordinate. Both terms are standard bilinear query/key scores with 1/D scaling. At i=N, Q_N is one-hot. Full matches have weight 2ᵇ, position 1 has weight 2ᵇ⁺¹, and every other position has weight 1; the invalid positions are not structurally excluded. Output p is this head's scalar attention output, copied to an output coordinate. The second block FFN can be zero, and the final binary probability vector is (1−p,p). This is a probability-valued decoder readout, not a vocabulary logit followed by an additional softmax.

2. Pathwise comparison, including no match

The full-match plus position-1 pseudo-count component has numerator 2ᵇ(C+1) and denominator 2ᵇ(J+2), hence equals B. Every remaining position has value in [0,1] and weight 1. Their number is N−1−J, including the other early position. A mixture of two [0,1] values differs from B by at most its contaminating mass. Thus on every word,

|p−B| ≤ (N−1−J)/[2ᵇ(J+2)+(N−1−J)] ≤ N 2⁻ᵇ/2 ≤ η/2.  (1)

This is valid at J=0 and N=3; no fallback approximation is asserted. The pseudo-count term, causal alignment, and original previous-row count J refer to the same X₁:N path.

3. Finite-bit model and custom numerical softmax

Store a dyadic s with |s−ln2|≤2⁻ᵖ where p=⌈log₂(128 max{b+1,c}/η)⌉. Set all score coefficients using s, not an irrational parameter. If exact real softmax were applied to these dyadic logits, every corresponding logit differs from the ideal symbolic-ln2 logit by at most a=max{b+1,c}2⁻ᵖ≤η/128. Softmax vectors then differ in total variation by at most (e²ᵃ−1)/2≤2a≤η/64; the latter bound uses η≤1. The first-copy total wrong mass is at most 1/32+η/64≤3/64<1/16, so all Boolean gate conclusions remain exact in the real-softmax dyadic-parameter network. The second-head scalar error versus (1) is at most η/8. Therefore the mathematical dyadic-logit standard decoder has |p−B|≤5η/8 pathwise.

A concrete finite arithmetic implementation is a specialized approximate softmax backend, not a claim that exp(k s)=2ᵏ. All possible logits in this architecture are k s, with k∈{0,c,b,b+1}; the backend replaces exp(k s) by the stored exact rational 2ᵏ and performs the normalization and subsequent ReLU/linear operations as exact rational arithmetic. Its output equals the symbolic-ln2 computation and satisfies (1). Its per-head probability vector differs from the true softmax of the actual dyadic logits by at most (e²ᵃ−1)/2, and its first-copy gates remain within margin. No arbitrary real logits or generic exp routine are covered. A final rounding to the nearest dyadic with p_out fractional bits adds ≤2⁻ᵖ_out to the scalar; clipping and exact complement then preserve a valid probability vector and this error.

Exact rational arithmetic is finite-bit, but is not conventional fixed-word floating point. One deliberately loose explicit upper bound follows by evaluating all reductions as balanced binary trees. Let n=N+3, M=10⁵ n⁴ rational operations, T=100⌈log₂n⌉ arithmetic depth, and B₀=p+b+c+10⌈log₂n⌉+100 bits. Binary rational addition, subtraction, multiplication, division by a known nonzero denominator, and comparison increase the maximum numerator/denominator bit length from B to at most 2B+2. Thus P=(B₀+2)2ᵀ bits per integer suffice, including all intermediates; all attention normalizers are positive. Schoolbook arithmetic gives the deliberately conservative O(MP²) bit operations and O(MP) bits of work storage, plus O(p_out) output bits. Rounding and writing the output are charged separately, giving total O(MP²+(P+p_out)²) bit operations and O(MP+p_out) bits of storage. This is a finite polynomial-in-N, b, c, p upper bound (with huge exponent), not a practical precision recommendation. Stored exact position embeddings use O(N²) bits in dense one-hot form; a sparse representation may instead be separately charged. The dyadic ln2 approximation is an input parameter, obtainable deterministically from ln2=2∑_{j≥0}[(2j+1)3^{2j+1}]⁻¹ by truncation and rational rounding.

4. Actual-terminal conditional TV

For the stationary rare family specified in Route A v3, with π₀₀=u∈(0,1/4), θ₀₀=t∈[1/4,3/4], v=mu≥60, and any δ∈(0,1), the source report proves the same-path count bound

E[|B−t| | S_N=00] ≤ min{1, δ+1220/v+√(ln[2(m+1)/(uδ)]/v)+1/(v/2+2)}.  (2)

It uses the actual terminal event, a reverse-chain common-atom bound for J and a forward martingale tail before division by P(S_N=00)=u. Combining (1) pointwise with (2) gives, for the custom exact-rational implementation, conditional binary TV at most the right side of (2) plus η/2 and output rounding, capped at 1. For the mathematical dyadic-logit real-softmax decoder replace η/2 by 5η/8. If v<60 the general TV bound 1 remains valid. No independence between the query and its prefix is assumed. This is an upper bound for the stated rare family, not a lower bound or a rate improvement over ordinary counting.

5. Resource and evidence ledger

Sequence length N with no BOS; L=2; H=2 per block, three active head instances; d_model=2⌈√(N+33)⌉²=O(N); standard key head dimension D²; one FFN of constant hidden width and one zero FFN. Dense learned projection storage O(N²), dense positional table O(N²) bits, dense token state O(N²) scalar words, and unoptimized dense arithmetic O(N³), ignoring bit cost. The largest score is O(log(N/η)); maximum projection coefficient O(√N log(N/η)); first-layer gate coefficients are O(1). Precision cost is the explicit P bound above. Weight-table representation, arithmetic, the position-1 pseudo-count, input positions, and output readout are all paid. A streaming classical counter uses the exact same input, O(N) updates, O(log N) bits per each of a fixed number of counters, and a final exact division; it computes B exactly. The neural construction is not an efficiency improvement.
