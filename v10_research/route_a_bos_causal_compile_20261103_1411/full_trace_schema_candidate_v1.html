Proposed full-trace schema: review before any execution

2026-11-03. This is a proposed schema only. No rerun or additional test was executed. The original 1,008 records remain unchanged and cannot be replaced retroactively. This schema targets a new deterministic check of the one-hot-position no-BOS v4 backend, not the separate compact-position construction, and tests the specialized ideal powers-of-two approximation, not exact exponential of dyadic logits or generic floating point.

Coverage: every bit word for N=3,…,8 and η∈{1/4,1/32}, exactly 1,008 cases if setup succeeds. One JSONL record per case in a new exclusively created file. A separate immutable setup/summary log records exact script and artifact hashes, complete command, schema ID, intended and written record counts, exit status and stderr; a global setup failure is reported separately, not treated as a passed test. The runner catches per-case errors, writes their exception type/message and stage, marks all affected assertions failed and continues to retain every case. No previous artifact is overwritten. Rationals are exact signed numerator and positive denominator; integers are exact and scores in this symbolic test are integer multiples of ln2.

Required per-case fields

  1. Identity and inputs: schema version, checker version/hash, canonical case index, N, full bit string and vector, exact η, b, c, head dimensions, declared full coordinate layout and sparse projection maps, and immutable report hash.
  2. Input and layer-1 trace: for every position i, complete or losslessly sparse-encoded input/residual state including raw token bit, one-hot position and first/valid flags. For both lag heads, save actual Q_i and, for every visible j, actual K_j and V_j, their exact dot product, scaling factor, resulting raw integer score coefficient, row maximum, row-centered coefficient and row shift, symbolic exact weight, numerator and denominator contribution. Save exact aggregate denominator, numerator, and output for each head. Sparse arrays declare dimensions and all absent coordinates are zero; verify reconstructed vectors and projections against the model definition.
  3. First FFN and residual: for each token and all eight pair indicators, actual rational bit-or-complement inputs, their sum, both affine hinge preactivations, both hinge outputs, resulting indicator, and intended Boolean oracle. Save the first-position Y and flag calculations, every pre/post residual work coordinate and retained x_i, plus copies' exact errors where the lag exists. This explicitly checks the declared projection/residual flow rather than only a hand-coded score formula.
  4. Layer-2 terminal trace: actual terminal Q vector; for each visible j its actual K/V vectors, first-position and match flags, exact dot product, scaling and raw/centered score and shift, exact weight, value, numerator/denominator contributions and exact sums; save the selected output and both probability coordinates.
  5. Independently indexed oracle: explicit target pair and, separately by raw-substring comparisons from the original bits, the list of candidate indices and each match/value, J, C, exact add-one comparator, exact final absolute error and contamination bound. Do not compute oracle counts from network keys or scores. Explicitly retain J=0 and N=3 cases.
  6. Assertions and status: individual boolean checks for projection reconstruction, masks, row maxima and normalization, each gate and indicator, retained input, valid values, independent match identity, output/simplex, exact comparison and error bounds; aggregate pass/fail plus per-case exception details. Summaries must count both passed and failed records and retain failures.

Adversarial pre-run review must verify that this schema and the concrete layout fully cover the quantities above, that the checker implements the actual declared Q/K/V maps rather than only formula outputs, and that errors and setup failures remain visible. Approval of this schema is not a proof of the theorem, prior-art novelty, or a claim about standard fixed-bit backends.
