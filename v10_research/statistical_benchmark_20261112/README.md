# Standard statistical benchmark consolidation

General stationary binary second-order sources with fixed positivity c, same-history terminal-row prediction, and the spin subclass. This is a consolidation with explicit constants and same-trajectory indexing, not a new estimator or statistical rate. It does not supply a neural compiler.

The source proof and independent analytical review were compared; the word-RAM caveat is included. A separate replay of check.py matched results.json byte-for-byte: 5472 general-source paths, 20 spin risk identities and 4 binomial lower-bound comparisons. Rational arithmetic is used except displayed square-root upper-bound comparisons. These finite checks do not prove the universal bound or test a trained network.

Run `python check.py`; output is JSON. No CI or full-repository verifier was run. The original L2 architecture reference is ../tag_l2_information_20261112/l2/THEOREM.md. Its common source-independent endpoint template is essential; allowing a source-dependent template invalidates the comparison. Existing 293 undeclared historical files and previous inventory rows are preserved.
