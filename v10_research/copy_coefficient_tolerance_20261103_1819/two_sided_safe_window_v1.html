A two-sided O(1/N) safe window for one copy coefficient

3 November 2026. Analytic candidate for independent review. It combines a new deterministic gate calculation with the separately reviewed end-to-end drift example and finite-N error bound. It concerns one coefficient of one specified exact-real graph, not general network robustness. No test, enumeration or source overwrite was used.

Result. In the specified four-block graph with L=N+2 and N≥2, replace the lag-one score −ij² term by −(1+η)ij², changing no other entry. For either sign of η, if |η|≤1/(8L), then the final binary vocabulary-softmax distribution is exactly identical on every data word to the unperturbed model. This is stronger than retaining the original rate, but applies only to this one-entry perturbation and the graph's exact dependency wiring.

1. Model and score gap

Use exactly the four-block decoder, its boundary clarification and final-output rate addendum: two BOS tokens with value 1/2, data Xₖ at position k+2, positional features (1,i,i²,ln i), standard causal mask, and final two-logit softmax. The unperturbed lag-one head score is 2i(i−1)j−ij²; the perturbation is

sη(i,j)=2i(i−1)j−(1+η)ij²,   1≤j≤i≤L.

This corresponds to changing its Q-projection coefficient −4 to −4(1+η); its absolute scalar-weight change is 4|η|≤1/(2L). The lag-two head, all other parameters and inputs remain exact. η can depend on the public N but not on data; no other perturbation is allowed.

Fix i≥4 and the correct lag-one key r=i−1. For j≠r put d=j−r. Since j,r≤L, |j²−r²|≤2L|d|. Therefore

sη(i,r)−sη(i,j)
 = i[d²+η(j²−r²)]
 ≥ i[d²−2L|η||d|] ≥ (3i/4)d².

The last step uses |d|≥1 and 2L|η|≤1/4. At most two keys lie at each nonzero integer distance from r, hence the attention mass outside r is bounded by

2 Σ_(d≥1) exp(−3i d²/4)
 ≤ 2 exp(−3i/4)/(1−exp(−3i/4))
 ≤ 2/(e³−1) < 1/4.

The final inequality holds, for example, because e³>9. Every value is in [0,1], including BOS values. Thus the head's copied value differs from the target bit by less than 1/4 whenever r is a data position. The fixed ReLU snap T(a)=2ReLU(a−1/4)−2ReLU(a−3/4) returns that bit exactly. This conclusion is uniform over every word, every i≥4 through L, both signs of η, and every N≥2; no asymptotic or stochastic argument is used.

2. Why the complete outputs are identical

For each valid historical candidate i≥5, snapped lag-one and unperturbed lag-two data bits are exactly the same as in the original graph. The valid flag and the candidate-context gates gh are therefore identical. At i≤4 the valid flag is zero, so every candidate-context gate is zero regardless of the possibly changed early lag-one snap; BOS flags and token values are unchanged. The initial marker mᵢ used for the uniform length head depends only on position and is unchanged.

At terminal i=L≥4, the lag-one target r=L−1 is the data symbol XN−1, so the snapped previous bit and actual-query onehot qh are exactly identical to the original, including N=2. The head's raw copied-value slot can differ; this slot is not read by the subsequent specified context, anchor, reciprocal-length, final-logit or vocabulary-readout maps after the snap. In particular, earlier-position query qh and selected outputs, if different, are not read by the terminal fourth-block keys/values, which use only the unchanged positional coordinates j,j²,ln j. This is a direct dependency audit of this graph, not a generic property of residual Transformers.

Accordingly all block-3 terminal anchor scores and values, both BOS pseudocounts, the four anchor outputs, the selected terminal scalar p and length marker z are unchanged. Both block-4 terminal Gaussian heads then have identical queries, keys and values, and the final linear logits and ordinary vocabulary softmax are identical. Thus Pη,N(·|X₁:ₙ)=P0,N(·|X₁:ₙ) for every word. The model's complete residual vectors need not be equal, and neither the attention distribution nor unused slots are asserted equal.

At N=2, L=4, the terminal previous-bit query is valid and there are no observed triples; the unperturbed add-one reference is 1/2, but its finite-score model output need not itself equal 1/2. The exact equality just established is between the perturbed and unperturbed network outputs.

3. Consequences and the remaining window

The output identity makes every source-specific and worst-source TV risk identical to that of the unperturbed graph at the same N, and the established pathwise O(N⁻¹/²) vocabulary-output approximation and fixed-binary-alphabet statistical bound transfer verbatim. A sequence ηN satisfying this inequality uses N-dependent perturbed weights; it is not one fixed nonzero perturbation for every N.

Conversely, the separately reviewed drift example, read with its triangular-quantifier clarification, gives a particular sequence qN=⌊N/[ln(N+2)]²⌋→∞ and ηN=1/(2qN)∼ln²N/(2N). For the one fixed all-positive, stationary fast-mixing second-order source in that note, its actual-terminal average TV risk tends to 3/16. Thus the present proofs show an O(1/N) two-sided sufficient window and a particular O(log²N/N) one-sided failing sequence. They do not establish a sharp threshold, a monotone dependence on |η|, a lower bound for every η outside the safe window, or a robustness statement for other perturbation coordinates or architectures.

4. Prior work and numerical scope

Liu et al., NeurIPS 2023, Appendix C.3, Proposition 4 already analyze exact constraints on position QK interactions and long-length failure under position drift in a specified flip-flop setting. Position-coefficient perturbation causing long-sequence failure is not a new discovery. Chen et al. and Castin et al. provide related but differently scoped copier/output and attention-smoothness analyses. The present contribution is only the explicitly scoped all-word exact-equality calculation and its comparison to the stated fixed-source, final-output risk example; no priority or broad literature claim is made.

All arguments use exact real arithmetic and a single scalar weight change. Ordinary finite precision, rounding, parameter storage, simultaneous perturbations, overflow and training require separate analysis. The specialized integer backend stores this particular coefficient exactly; it is not an analogue-noise model.
