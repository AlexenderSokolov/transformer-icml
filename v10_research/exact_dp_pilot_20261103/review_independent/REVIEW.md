# Independent audit: gated-DP microbenchmark

3 November 2026. Scope: both sealed local protocols, C++ selected-row gate DP, tests, saved case/result records, and additive corrections. This is a few-history exploratory benchmark of the fixed gate Q, not a learned-pooling model, population-risk experiment, or exact-real comparison certificate. No author file was changed.

## Findings

The integer-state DP exactly enumerates reachable selected-row (J,C1,D,last-pair) states up to minimum legal edit cost, within its domain M=4…128 and absent caps. The gate and clean target match the original pilot's Q(z) and B(h). Source tables and true-source scores enter only after both selectors return. Its terminal scores, however, use C++ double-precision sqrt/log and strict floating comparison; no directed-rounding or exact-real tie certificate was saved. The reported maxima are exhaustive-state, float64-selected results, not certified real-number CE optima. The author's TIMING_AND_NUMERIC_CORRECTION.md correctly makes this distinction.

The pre-run SHA lists verify against current files and their local timestamps precede the respective runs. These are local consistency/order evidence, not external timestamps, and the runner does not enforce a read-only seal check. The nine-case follow-up was selected only after the initial 36 results and is explicitly exploratory. It is not an independent, preregistered confirmation.

All 45 retained records contain the input word, clean B, all 20 training/heldout proposal entries and their scores, selected proposal, DP status, chosen witness and bank, timing/resource counts, and post-selection true-source scores. Independent reconstruction confirms every proposal entry, selection, objective, legal endpoint/budget and saved source score; maximum recomputed CE discrepancy is zero under this environment. All 45 DP runs report completion; the DP numerical objective is at least the proposal union's within 1e-12. Thirty-six cases exceed it by >1e-12, nine tie. Complete DP reachable-state sets and their scores were not saved contemporaneously: only the final chosen witness, aggregate node/layer counts and resulting objective remain. They should not be described as retained raw candidate-state data.

The initial 36-case grid has positive float64 CE gaps in 27 and ties in nine. Its source-TV comparison favors the DP witness in 22 cases, favors the proposal in four, and ties in ten. These four reverse examples demonstrate that higher conditional CE does not ensure greater source-TV error. All nine follow-up cases have positive numerical CE gaps and higher post-selection source-TV, but are chosen on previously observed histories and do not establish a distributional improvement. Independent full mask enumeration at M=16 and M=32, k=4, for all six histories agrees with the recorded *numerical* maxima. The 448 retained small test rows, their brute mask optima and the 5,976-entry retrospective oracle-candidate archive also independently check out.

The reported follow-up `entire_case_wall_s` is **not** isolated subprocess wall time: it includes Python proposal generation/scoring, process launch and wait, result parsing and validation. The C++ wall time excludes process launch. No separate child-process elapsed measurement was retained, so the specified isolated measurement cannot be recovered from these logs. The timeout is checked during state expansion, not as a hard end-to-end deadline covering every initialization, final scoring, tracing, process launch or operating-system pause; no recorded run hit a cap, so this does not change observed results. The compiler's misleading-indentation warning is archived; under C++ syntax the guarded break exits before the subsequent layer swap, so the completed cases' control flow is consistent with the source.

## Preservation and reproducibility

The initial run contemporaneously saved the twelve generated words, source tables, start pairs, code and seed. It did not save each raw random uniform or PRNG state then. `randomness_replayed.json` was reconstructed after observing initial results and is not the original raw draw log. The small test words and test summary were saved; `test_random_states.json` and `test_oracle_candidates.jsonl.gz` were reconstructed afterward. All 20 proposal entries per actual case were contemporaneously retained; all DP intermediate/terminal state candidates were not. The author's PRESERVATION_CORRECTION.md distinguishes these facts.

A separate review-only bitwise probe used 700,000 random words whose actual generated words and PRNG states were not preserved. Other transient diagnostic model initializations were also not archived. The precise seeds, counts, scripts, and my own before-stop replays are disclosed in `ADDITIONAL_PRESERVATION_AUDIT.md`. No regenerated values should be relabeled as originals. This issue is separate from, and does not repair, missing data in earlier experiments.

Recomputed aggregate results: initial internal C++ time 0.061–7.376 ms, maximum completed layer 1,433 states and maximum nodes 43,273; follow-up internal C++ time 1.189–237.127 ms, maximum layer 41,726 and maximum nodes 1,833,734. Timings are platform-specific and do not measure the trained pilot, backpropagation or a controlled end-to-end speed ratio.

`check_records.py` and `check_records.log` contain the independent deterministic arithmetic checks and the already-completed retrospective seed replay; do not rerun its random-number reconstruction under the subsequent stop instruction. All original output files remain unchanged.
