# Additional preservation disclosure: diagnostic probes

3 November 2026. This is a retrospective audit of diagnostics performed before the instruction to stop random sampling. It does not reconstruct missing random values, label a replay as an original, or modify earlier artifacts. The counts below refer to generated values, not necessarily distinct values or independent parameter settings.

## Seven-batch bitwise probe

`v10_research/exact_dp_pilot_review_20261103/bitwise_probe.py` initializes NumPy `default_rng(318038)` once, then generates 100,000 random binary words for each M in 6, 8, 10, 16, 32, 64 and 128, a total of **700,000 words** containing **27,800,000 binary symbol values**. It tests whether equal selected endpoint and four-counter banks produce exactly equal pilot half-model input vectors in each batch. The script, seed, selected lengths, batch size and aggregate `bitwise_probe.log` are retained. The log reports no mismatch in any batch; since it prints individual words only on mismatch, it contains no generated word examples. The actual 700,000 sampled words, PRNG state snapshots, and underlying integer-generation values/states were not retained. A separate probe-specific NumPy/platform environment receipt was not found. The seed permits an attempted compatible replay, but replay would be a new reconstruction, not the missing original records. The probe is not proof of bitwise equality for all words.

The same script also constructs `pilot.Model(seed=0, mode='half')` once per length. Each construction samples 16 pooling, 288 first-layer and 32 output weights, i.e. 336 normal-valued parameter entries. The seven constructions therefore generated 2,352 entries using the same seed each time; those weight arrays and their RNG states were not saved. This is seven repetitions of the same seeded initialization, not seven independent model initializations. The diagnostic input vectors do not depend on the random readout weights; its q values would only have been printed if a mismatch occurred.

## Exhaustive four-counter verifiers

The author's `four_counter_dp_20261103/verify.py` constructs `pilot.Model(seed=123, mode='half')` separately for each M=2…6. My independent `four_counter_dp_20261103/review_independent/check_theorem.py` similarly constructs one model with seed 203 per M. Each script therefore generated 5×336=1,680 normal-valued parameter entries, repeating the same initialization each time, without preserving those arrays or RNG states. Across these two scripts and the seven-model probe above, **5,712 model parameter entries** were generated in total, including repetitions, not 5,712 distinct settings. The cached input rails checked by these two verifiers are determined before the random readout weights and their equality evidence is unaffected, but the random values themselves cannot be claimed to have been preserved. Both scripts, seeds and aggregate logs remain available.

## Benchmark and audit replays

The original benchmark saved its 12 words, source tables and initial pairs but not the 720 transition-uniform draws or generator state snapshots as contemporaneous raw records. The 720 figure is 3×(16+32+64+128). The later author-created `randomness_replayed.json` contains deterministic reconstruction after results were observed, correctly named as replay. The original test generated 32 seeded binary histories, producing 8×[(5+2)+(6+2)+(7+2)+(8+2)]=272 returned binary symbol values; those words are retained in test records, but contemporaneous random states and underlying generator bits were not. The subsequent test RNG-state/candidate archive is also retrospective.

Before the stop instruction, my `check_records.py` was run three times as it was extended. Each execution independently reconstructed the *same* seeded benchmark sequence of 12 starts and 720 transition uniforms in memory and checked it against the already-retained retrospective archive. These were three deterministic replays, not three new independent benchmark datasets. My checker did not separately save its transient replay draws or its before/after states. Its final script and log are retained. No further random sampling or regeneration was undertaken after the stop instruction.

These omissions affect archival completeness, not the basic arithmetic inference that the retained observed outputs match the saved words. They must remain visible in any delivery. The stopped probe's aggregate log and seed are not a substitute for the unpreserved 700,000 original words.
