Fixed-alphabet causal prediction with paid growing resources

3 November 2026. Candidate extension to an arbitrary fixed finite alphabet; the source alphabet size A≥2 is public. The separately specified model and specialized integer backend require independent review. No random or numerical test was performed; no source was overwritten. This is not an originality, training, fixed-word IEEE or architecture-lower-bound claim.

Result to check. For every fixed A, one set of parameters depending on A but not on source or N defines a fixed-width/depth causal decoder with an ordinary A-way final vocabulary softmax. With the paid position features and numerical model below, it approximates the same-history actual-terminal add-one predictor pathwise and, using the separately established all-K R011 bound, has uniform expected TV risk O_A(N−1/2) over all homogeneous order-two tables and arbitrary initial laws. For A growing with N, the same bound is only sufficient when A⁵/N→0 and the architecture itself grows with A.

1. Model, dimensions and positional assumptions

Let alphabet V={1,…,A}, N≥2, M=N−2 and L=N+A. Positions i=1,…,A are A distinct BOS tokens with values e₁,…,e_A; position i=A+k contains the data onehot x_i=e_{X_k}. The final query is S_N=(X_{N−1},X_N), not an independent sample. Input features are (1,i,i²,ln i,x_i). Positional values are prescribed source-independent functions; ln i is numerically generated and charged in §5. No i×symbol, i×state or i×source statistic is supplied as preprocessing.

Fix H_heads=A²+1 heads in each of four standard full-causal attention/ReLU blocks. Set

m=⌈√(A+10)⌉,   D=4m²,   d_model=H_heads·D.

Each head has dimension D≥A and score Q·K/√D=Q·K/(2m); all maps are fixed as N varies. This is an explicit O(A³)-width choice, not optimized. Reserve disjoint residual coordinates for the four positional features, symbol onehot, two raw copied A-vectors, two snapped A-vectors, BOS/valid/first-BOS flags, A² candidate-context and A² actual-query onehots, A³ anchor outputs, an A-vector p, a scalar z and A final attention outputs. At most A³+2A²+7A+8 slots are needed; d_model is larger. Each block uses a single-hidden-layer ReLU FFN with a residual connection and no LayerNorm. All masks are ordinary causal j≤i. The numbers of active attention heads in blocks 1–4 are 2, 0, A²+1 and A, respectively; unused allocated heads have zero value/output maps.

2. Copies, onehots and boundaries

In block 1, for h=1,2 use Q_i=√D(2i²−2hi,−i,0,…), K_j=(j,j²,0,…), and A-dimensional value x_j. Its score is the fixed-parameter positional bilinear

2i(i−h)j−ij² = i(i−h)²−i(j−i+h)².

At a valid lag, the wrong mass is ≤2e^(−i)/(1−e^(−i)); the target token’s every coordinate differs from its copied value by at most that mass. At terminal i=L≥4 the lag-one data symbol is snapped exactly, and at candidate i≥A+3≥5 both lags are snapped exactly, using componentwise T(a)=2ReLU(a−1/4)−2ReLU(a−3/4). For any invalid copy the snapped coordinate remains in [0,1].

The first FFN also writes the exact integer-position flags

b(i)=ReLU(A+1−i)−ReLU(A−i),  v(i)=ReLU(i−A−2)−ReLU(i−A−3),
m(i)=ReLU(2−i).

Thus b=1 on exactly A BOS positions, v=1 exactly when i≥A+3, and m=1 only on the first BOS. The first FFN needs at most 4A+5 hidden ReLUs. Block 2 has zero attention output; its width-2A² FFN writes, for each (r,s)∈V²,

g_rs=ReLU(v+T₂[r]+T₁[s]−2),     q_rs=ReLU(T₁[r]+x_i[s]−1).

At a valid candidate g is the exact onehot predecessor pair; at invalid positions it is zero even if copies are fractional. At the terminal data position q is onehot for the actual pair (X_{N−1},X_N). At N=2 there are no valid triples but the terminal query remains valid.

3. A² anchor heads and BOS add-one counts

Block 3 has one head h=(r,s) for each context. Let its query’s first coordinate be √D(i−A), its key’s first coordinate be g_h+b, and its value be x_j∈ℝ^A. At the final query i=L the scores are N for every BOS and every matching candidate, and 0 for all other data positions. Let J_h be the number of observed triples with predecessor h, C_{h,a} their number followed by a. Then the head’s output vector is exactly

o_{h,a}=[C_{h,a}+1+e^(−N)D_{h,a}]/[J_h+A+e^(−N)K_h],
K_h=N−J_h,    Σ_a D_{h,a}=K_h,    D_{h,a}≥0.

The A BOS onehots contribute +1 to each coordinate and +A to the denominator. This is a convex mixture of add-one B_h and a distractor distribution with mass at most Ne^(−N)/A, even when J_h=0. A width-A³ FFN writes p_a=Σ_h ReLU(o_{h,a}+q_h−1), so p is exactly the anchor distribution for the actual terminal context. A further uniform head (zero logits) with value m_j writes z=1/L at the terminal. There is no state×position input feature: N(g_h+b) arises in the standard Q·K score.

4. A-way vocabulary softmax and statistical bound

For each symbol a, a block-4 head has query √D(2p_a,−z), key (j,j²), value ln j and full causal support. Its score is 2p_a j−j²/L. The final linear readout uses these A head outputs as the A ordinary vocabulary logits. The binary construction’s uniform Gaussian lemma applies separately to each p_a∈[0,1]: writing G_a=exp(E ln J_{p_a}),

|G_a/L−p_a|≤42/√L.

Since p is an exact simplex, δ=Σ_a|G_a/L−p_a|≤42A/√L. When δ≤1/2, normalization changes the distribution in TV by at most δ/(1−δ)≤2δ; when δ>1/2, TV≤1. Thus the ordinary A-way vocabulary-softmax output P obeys, for every input word,

TV(P,B_{S_N}) ≤ Ne^(−N)/A + min{1,84A/√(N+A)}.

This includes every zero-count query and N=2. The 1/√N claim below is for fixed A; this pathwise bound has explicit, non-optimized A dependence.

Located all-A statistical source. R011’s exact theorem states the original full-history add-one risk for every integer K≥2, every M≥1, any homogeneous order-two table and arbitrary initial pair law subject to its mixing class. Set K=A and its mixing parameter β_mix=0. The P²≥0 condition is vacuous, and a finite pair kernel always has a stationary law, so this includes every table and initial pair law. Its actual-terminal unconditional expected half-L1 TV upper is

sup_source risk(B_{S_N}) ≤ min{1,2¹³√[A⁵/(N−1)]},   N≥3.

Fingerprints do not provide public access. For N=2 use the trivial TV≤1. Combining the pathwise and statistical bounds yields uniform O_A(N−1/2) for fixed A, not a fixed-row conditional claim.

If A=A_N grows, the displayed R011 bound and pathwise bound yield consistency under A_N⁵/N→0. This is a sufficient condition from a non-sharp stated upper, not an optimal alphabet-growth threshold. The head count, width, weights and input vocabulary change with A_N, so it is not one fixed-width, fixed-parameter network across growing alphabets.

5. Specialized finite-bit evaluation: explicit A accounting

The following extends the binary integer backend; it is a specified arbitrary-precision algorithm, not IEEE inference. Set s=⌈log₂(AL)⌉, b=32s, H_grid=2^b, F=H_grid². Generate each λ_j≈ln j using the same source-independent range-reduced atanh series and exact F-grid integer routine as that backend. Since j≤L≤2^s, its proven estimate gives |λ_j−ln j|<1/H_grid with 0≤λ_j≤s+1. The lookup is a paid numerical positional feature, not a log of p_a.

For every nonnegative dyadic attention gap d=X/H_grid use the same exact-integer repeated-squaring routine: if X>bH_grid return 0; otherwise initialize Z=F−X, square-and-floor at F scale b times and convert to H_grid scale. For every gap the absolute unnormalized-weight error is bounded by

ε_w=(2b²+2)/H_grid,     weight(0)=1 exactly.

All maxima, score products and row supports are evaluated exactly on integer/dyadic inputs. Attention numerators and denominators are summed exactly; each denominator has a weight-one maximizer. The first two A-vector copy heads round each coordinate to the H_grid. Each coordinate’s output error is ≤2Lε_w+1/H_grid, which is strictly within the 1/4 copy-gate margin for L≥4 and this choice of b. Hence all valid snapped onehots, position flags, context indicators and terminal query remain exact.

For each A-dimensional anchor head, its values are onehots and the true and approximate normalized weight distributions are within TV≤Lε_w. Floor the first A−1 numerical probability coordinates to the grid and set the last to 1 minus their sum. This yields a nonnegative H_grid simplex and adds TV at most (A−1)/H_grid. The selected p̃ is therefore an exact simplex, with

TV(p̃,B_{S_N}) ≤ Ne^(−N)/A + Lε_w +(A−1)/H_grid.

The uniform first-BOS marker head returns z̃=⌊H_grid/L⌋/H_grid. Gaussian scores using p̃ and z̃ are computed exactly as dyadics; relative to ideal z=1/L at that same p̃, each score error is ≤L²/H_grid. By the sharp softmax-TV bound, and adding log-feature, numerical-weight and output-rounding errors, each Gaussian logit differs from its ideal value by at most

E_h = { (s+1)[L²/2+2L(2b²+2)] + 2 }/H_grid.

The dimension-free softmax stability inequality contributes at most E_h/2 in TV to the exact A-way vocabulary distribution. Evaluating the final A-way softmax by the same integer weight routine contributes at most Aε_w, and flooring A−1 outputs with a residual final coordinate contributes at most (A−1)/H_grid. Consequently, for every word, the numerical distribution P̃ obeys

TV(P̃,B_{S_N}) ≤ Ne^(−N)/A + Lε_w +(A−1)/H_grid
   + min{1,84A/√L} + E_h/2 + Aε_w +(A−1)/H_grid.

This is an explicit specialized-backend error budget, not a generic hardware-softmax theorem. The A-coordinate rounding rule is part of the algorithm, not an uncharged normalization assumption.

6. Time, bits and parameter scaling

The model has H_heads=A²+1 heads of dimension D=4⌈√(A+10)⌉² and d_model=H_heads D=O(A³); it has A²+A+3 active head instances across four blocks. The largest FFN hidden width is A³. A densely stored set of its fixed sparse-pattern projection/FFN matrices has at most O(A⁶) entries, with O(log(A+2))-bit rational/integer coefficients in this implementation; sparse storage can be cheaper but is not assumed. These are A-dependent resources, even though parameters are fixed across N for each A.

Exact i,i² need O(log L) integer bits; log-position values, fixed-point outputs and scores require O(b+log L) bits. F-grid squaring intermediates use O(b) bits up to constant factors; sums add O(log L) bits. With schoolbook integer arithmetic, evaluating every causal row gives the conservative bit-operation upper

O((A²L²+L)b³ + (A³L²+A⁶L)b²),    b=Θ(log(AL)).

The b³ term charges repeated-squaring exponentials and log-feature generation; the b² term charges head dot products, vector-valued aggregation and dense projections/FFNs. Row streaming, stored per-position activations/positions, a paid log table, and dense parameter storage use

O(A³Lb + b² + A⁶ log(A+2)) bits.

This includes unbounded positional magnitudes and length-growing precision. It is not a bounded-logit, constant-precision, generic floating-point, learned-training, optimal-compute or fixed-width-growing-A result.

7. Prior art

Ekbote et al., Rajaraman et al. and D’Angelo et al. already give conditional k-gram, position-copy or smoothed attention mechanisms in their stated models and limits; He et al. use quadratic position scores. The targeted source comparison describes further qualifications. Extending the binary candidate and locating a local statistical theorem are not novelty certification.
