1. No-BOS construction and causality

Position j=1 is an input position, not an added token. In the first block the two heads copy from i−1 and i−2 for i≥3, using the original Xj; hence X1 is available when needed. The original bit also remains in a distinct residual coordinate. With zj=1{j=1}, the subsequent tokenwise first FFN computes Yj=ReLU(Xj−zj)+zj/2, equal to 1/2 at position 1 and Xj otherwise. This does not overwrite the original bit.

The gates form historical Ki=e(Xi−2,Xi−1) and current Qi=e(Xi−1,Xi) for i≥3 and set both to zero at 1,2. The key at j counts the transition indexed j−1, including j=N; the query is the terminal SN. No future input is used. At j=1 the separate positional flag selects the pseudo-count score and K1=0, so it cannot simultaneously count as a match. A constant query coordinate may be generated from the one-hot position sum. Distinct residual slots and D²-dimensional keys/queries provide room for the position, matching and flag channels. The non-BOS claim still relies on a public designated first position and explicit positional features.

2. Gates and copy margins

For G(A,v)=ReLU(2A+2v−9/2)−ReLU(2A+2v−11/2), copied values and complements lie in [0,1]. If v=0, A≤2 and both hinges vanish. If v=1 and each relevant copied bit has error at most 1/16, a true two-bit pattern has A≥30/16, giving G=1; a false pattern has A≤17/16, giving G=0. The current bit xi is exact, so query-pattern margins are no worse. The statement remains true at i=3 and for every input word.

In the symbolic-ln 2 model, at most N−1 wrong keys have relative weight 2−c, so the report's looser (N+1)2−c≤1/32 copy error is safe. For dyadic s with |s−ln2|≤2−p, a=max{b+1,c}2−p≤η/128. The standard likelihood-ratio bound gives attention TV≤(e2a−1)/2≤2a≤η/64. Therefore copy error ≤1/32+η/64≤3/64<1/16, and the true real-softmax dyadic model produces the same exact gate outputs. Since second-block query and key gates agree, its final attention-coordinate error relative to the symbolic model is ≤η/64; the stated η/8 allowance is conservative.

3. Same-path add-one error

The match positions have weight 2b and sum of values C. Position 1 has weight 2b+1 and value 1/2. Thus their combined numerator is 2b(C+1), their denominator 2b(J+2), and their average is B=(C+1)/(J+2). Among N positions, the remaining N−1−J positions each have weight 1 and values in [0,1]. Hence

|p−B| ≤ (N−1−J)/(2ᵇ(J+2)+N−1−J) ≤ N·2⁻ᵇ/2 ≤ η/2.

This proof explicitly includes J=0 and N=3. Adding the report's conservative dyadic-softmax allowance yields 5η/8. Both scalars are probabilities, so adding these pointwise terms to the quoted same-path conditional risk and capping at one is valid; no query–prefix independence is introduced.

4. Rational arithmetic and resource scope

The exact-rational backend maps the finite score set {0,c,b,b+1}s to {1,2c,2b,2b+1} and evaluates normalized outputs, ReLUs and projections as rational operations. It reproduces symbolic-ln 2 attention, but is a specialized approximate exponential, not exact exp of the dyadic parameters. The logit-category property relies on the already verified exact gates. Output saturation and exact complement preserve normalization. The output-rounding cost is separately charged; an O(MP²) bound alone would omit an arbitrarily large pout.

For the report's n=N+3, M=10⁵n⁴, T=100⌈log₂n⌉ and B₀=p+b+c+10⌈log₂n⌉+100, a straightforward dense evaluation has polynomially many rational operations and O(log n) arithmetic depth when reductions are balanced. The large stated constants are consistent with the two attention blocks, constant-width FFN, and d=O(N). A binary rational arithmetic operation or cross-product comparison increases a uniform numerator/denominator bit bound B to at most 2B+2. Thus P=(B₀+2)2T is a loose conservative induction bound. This assumes exact rational operations, comparisons, positive softmax normalizers, input-provided dyadic s and stored lookup values; it does not itself cost the separate generation of s or a generic exponential routine. Under that accounting, the report's O(MP²+(P+pout)²) schoolbook bit-operation bound and O(MP+pout) storage allowance are conservative. This is not a practical fixed-precision or empirical timing bound.

With dense matrices and d=Θ(N), O(N²) parameter and token-state words and O(N³) unoptimized scalar arithmetic are appropriate. If the attention score matrix is retained, it also uses O(N²) words; training activations, masks and position encodings must be charged under the chosen executor. There are two physical head slots per block and three active head instances; the second FFN is zero.
