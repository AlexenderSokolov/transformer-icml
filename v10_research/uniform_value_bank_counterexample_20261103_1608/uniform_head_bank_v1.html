Uniform-head count bank and charged readout

3 November 2026. This companion gives an even simpler counterexample under richer value and nonlinear-readout assumptions. It is an analytic construction, not a Transformer lower bound, implementation certification or novelty claim. No random or numerical tests were used.

1. Exact pathwise identity

Let M=N−2≥0 and let J_r,C_r be same-history predecessor-pair and successor-one counts for the four binary contexts r. Grant each candidate the eight-dimensional value vector indexed by r

v_i(r)=(1{predecessor pair=r}·X_i, 1{predecessor pair=r}),
BOS value v_BOS(r)=(1,2)  for every r.

Give all M candidates and the one BOS the identical finite logit 0. A single head averages its M+1 values, producing for every context r

u_r=(C_r+1)/(M+1),     v_r=(J_r+2)/(M+1).

Keep the actual final pair s=(X_{N−1},X_N) in a separately available residual/query channel. The readout selects the pair of coordinates for s and computes u_s/v_s=(C_s+1)/(J_s+2), including when J_s=0 or M=0. Every logit is 0; there is no growing context-match temperature. Eight output coordinates, BOS value 2 in each count channel, query selection, and a nonlinear division are essential parts of this specified interface. The value range is [0,2], not the probability simplex.

Generating 1{predecessor pair=r}·X_i requires access to the previous two bits and a context-successor interaction. A prior causal copy/feature mechanism, an explicit augmented token or a separately charged nonlinear feature stage is needed. Exact lag copying, valid candidate masks, position access, multiplication/gating, selector and division are not provided for free. A one-head assertion at this intermediate interface is not a one-layer, fixed-width, standard Transformer implementation theorem.

2. Precision required at the value-bank boundary

Suppose each selected head-output coordinate is known to absolute error ≤η, the true denominator satisfies v_s≥2/(M+1), and the readout projects approximate coordinates to v′≥2/(M+1), 0≤u′≤v′. Coordinate errors after this projection remain at most η: denominator clipping cannot increase error relative to v_s, and clipping u to [0,v′] cannot move it more than the larger coordinate error because 0≤u_s≤v_s. The ratio identity and u′/v′≤1 give

|u′/v′−u_s/v_s| ≤ (|u′−u_s|+|v′−v_s|)/v_s ≤ (M+1)η.

Thus boundary accuracy η=O(M−3/2) suffices to preserve a pathwise O(M−1/2) output approximation, with O(log M) absolute fractional bits under a specified fixed-point interface. Output rounding and division error require separate budgets. This is a sufficient interface condition, not a claim that O(log M) is necessary for every alternative algorithm, and it does not establish an end-to-end floating-point calculation or training procedure.

3. Interpretation and prior art

The fixed-temperature lower bound for the single scalar D’Angelo-style interpolator remains true in its declared class. This bank lies outside that class: its values directly encode all four context-successor features, and its readout selects coordinates and divides. It therefore refutes extending that scalar-port result to all multihead or multivalue architectures. Any implementation comparison must count additional value dimensions, BOS encoding, positional and feature computation, readout arithmetic, numerical precision and all active attention work.

Histogram and counting primitives in attention have established antecedents. Weiss, Goldberg and Yahav, Thinking Like Transformers, describes histogram programs; Behrens, Biggio and Zdeborová, Counting in Small Transformers, §4.1, studies counting with attention, BOS and feed-forward mechanisms. These are not asserted here to prove this exact same-history add-one ratio with the same finite-precision model. The existing research-program finite-bank companion also already pays for context features and uniform attention. No originality claim is made from a different presentation of the count-bank idea.
