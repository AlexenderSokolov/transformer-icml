# Addendum to Izzo primary audit: Definition 5.4 and scope

2026-11-03. This is a separate correction to `REPORT.md`; the original report is unchanged. Primary source: the official ICLR 2026 conference PDF, pp. 8 and 37–38: https://proceedings.iclr.cc/paper_files/paper/2026/file/4a765a1bbf8332154e58bf452fbf806c-Paper-Conference.pdf#page=8 and #page=38.

1. **Zero matches.** In Definition 5.4 the displayed empirical ratio is 0/0 if no earlier matching context exists. The accompanying footnote 3 explicitly permits arbitrary behavior of f* in that case. My report's statement that the ratio is undefined unless a fallback is added is algebraically true but omitted this express provision and must not be read as saying that the paper failed to specify how the definition treats zero matches. A particular v10 oracle-risk estimator would still need a specified output and analysis on this event.
2. **Off-by-one notation, unresolved.** Definition 5.4's displayed comparison uses x_(t−k:t−1) against x_(T−k+1:T), both k symbols under inclusive-index conventions. But the same paragraph says τ=k−1 and k−1 first-layer heads; Appendix B.3 compares τ-token contexts x_(i−τ:i−1) against x_(T−τ+1:T); Appendix C samples a transition conditioned on k−1 tokens. These exhibit an apparent indexing mismatch. Do not silently resolve it or confidently identify paper k=3 with second-order in the main definition; count indices separately in each formula and verify author clarification or a corrected version before transferring an exact construction. The main report's unqualified k=3 interpretation is retracted.
3. **Access and verification qualification.** Primary paper text was accessed through the web retriever's full-document indexed extraction, initially a cached OpenReview reference and subsequently the official 39-page conference PDF above. I inspected the displayed statements, definitions, proof sketches, selected proof passages and Appendix B.3. I did not check every proof line or mechanically verify the mathematics; the report is a focused source audit, not a complete independent proof verification. The accessible official conference PDF should be used instead of relying on OpenReview, which can present a verification challenge.

The other central distinction remains: the paper's k-gram construction bounds softmax approximation by a ratio involving the match count, and its ε-scaling simplification assumes typical linearly frequent matches. This does not alone provide a uniform rare-context oracle-risk bound.
