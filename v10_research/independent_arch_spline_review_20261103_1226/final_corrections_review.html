Previously identified saturation wording blocker: resolved

The correction explicitly supersedes the weak phrase allowing any range-preserving saturation. Let the ideal scalar p lie in [0,1], with |x−p|≤ζ. If exact clipping is used, nonexpansiveness gives |clip(x)−p|≤ζ. If the actual scalar A(x) is in [0,1] and |A(x)−clip(x)|≤ξ uniformly, the triangle inequality gives |A(x)−p|≤ζ+ξ. Thus bounds containing +ζ must instead include +(ζ+ξ), unless ξ has already been expressly included in the declared budget. Range preservation by itself is insufficient. The correction correctly requires an exact complement 1−A(x), or an independently specified normalization with its own error budget. The correction is a conditional implementation obligation, not proof that a particular finite-bit implementation achieves either tolerance.

Explicit QKV maps: checked

The raw bit, four-coordinate historical one-hot key and four-coordinate query are distinct retained residual projections. With singleton masks {i−1} and {i−2} at i≥3, zero Q/K maps and the raw-bit value map exactly copy the corresponding bit; self-only masks at i=1,2 are harmless because these positions are excluded from the terminal candidate set. The shared feature map can then form historical keys and current query without reading a future bit.

For the matching head, the stated standard score scaling is 1/√d_k=1/2 with d_k=4. Thus W_Q=2 log(2) P_query and W_K=P_key yield score (1/2)·2 log(2)·⟨Q,K⟩=log(2)·⟨Q,K⟩. One-hot keys give unnormalized weights exactly two for matches and one otherwise. With terminal mask {3,…,N} and value X_i, the output is (C_all+C_s)/(m+J_s). The zero-Q/K uniform head averages (X_i,K_i), giving C_all/m and all four J_a/m. Both heads read the same block-1 states in parallel, while terminal X_N may be both the last observed historical successor and part of the separate query. The output-projection and selection/residual channels must remain available as specified in the base construction. Common head value sizes, if imposed, can be padded without changing the result.

Scope: This is an algebraic specification under the given explicit causal structured masks and ideal-real parameters. It does not establish equivalence under ordinary dense-causal masks, numerical implementation, end-to-end finite-bit accuracy, training attainability, or novelty. No source artifact was changed.
