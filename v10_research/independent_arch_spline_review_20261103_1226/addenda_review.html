Open precision issue. The scope addendum permits “exact or otherwise range-preserving saturation.” Range preservation alone does not guarantee the nonexpansive error claim in the projection addendum. A map that always returns 0 is range preserving; for ideal p=1, pre-projection p̃=1 and ζ=0, its output has error 1. Require exact clipping, or explicitly bound the implemented saturation's deviation η from exact clipping and include η in the numerical budget; alternatively directly assume |p_num−p|≤ζ and p_num∈[0,1].

Zero row and finite spline

The addendum's N=3, X=001, K=1 example is exact: the terminal query 01 has no matching historical departure, whereas the sole historical successor is one. Thus q=r=1, h=0 and B=1/2. Since S_1(x)=x, P_1(x,y)=0 throughout [0,1]²; Aclip=0, z=1/3, and the final finite-spline output is 0. Equation (2) allows this case. The clarification correctly distinguishes the ideal rational fallback from the finite-K network. It does not follow that an additional gate is the only possible remedy: the addendum appropriately says “or another proof.”

Output projection and simplex

For exact projection onto [0,1], p∈[0,1] and |p̃−p|≤ζ imply |clip(p̃,0,1)−p|≤ζ. The output probability vector (1−p_num,p_num), when formed with an exact complement, is exactly in the binary simplex and has TV distance |p_num−p| to the ideal output. Nonnegativity is needed for the bad-event loss cap one; two independently rounded coordinates need not sum to one. A merely range-preserving approximate clipping step is not sufficient for the quoted error budget, as shown above. For a specific implementation with |p_num−clip(p̃,0,1)|≤η and p_num∈[0,1], the bound becomes ζ+η, unless η has already been explicitly included in ζ. If complement formation or normalization is also approximate, its simplex and TV effects need their own bound, not merely a scalar claim.

Timing, heads, memory

The corrected comparator processes the final observed X_N as the successor for row S_{N−1}, then selects the query S_N from X_{N−1},X_N. Both operations use the same observed prefix; X_{N+1} is not read. Four J counters and four C counters use O(log N) bits each, a constant number of counters, with O(N) updates and a paid final division. The architecture's four head instances are two copy heads and two terminal heads, so adding the uniform head costs one extra terminal head versus a direct-q architecture sharing the same copying backbone. The token-state O(N) memory claim does not include storing all token-by-hinge activations for training; the separate O(K) spline parameters and mask/position representation remain necessary. A streaming inference implementation must schedule hidden computations to avoid retaining O(NK) activations.
