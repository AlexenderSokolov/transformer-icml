Deterministic integer backend for the four-block vocabulary-softmax decoder

3 November 2026. Analytical algorithm specification; no random, numerical or exhaustive tests were used. This is a specialized arbitrary-precision integer backend, not IEEE floating-point inference, a trained model, a hardware benchmark, formal verification or a novelty claim.

Result to review. With L=N+2≥4, the fixed-parameter four-block graph and ordinary final two-logit softmax from the exact-real candidate can be evaluated by the deterministic routines below. They pay for ln j positional features, dyadic scores, exponentials, sums, divisions and rounding. The independently checked Gaussian estimate and an inherited statistical bound then give uniform O(N−1/2) actual-terminal average TV risk. Parameters are fixed; position ranges and numerical precision grow with N.

1. Integer format and source graph

Let s=⌈log₂L⌉≥2, b=32s, H=2^b, F=H² and K=b+2. An H-grid value is an integer divided by H; an F-grid value is an integer divided by F. All specified integer operations, comparisons, shifts, floors and intermediate storage below are exact. The input consists of two BOS values 1/2 followed by N binary values, with exact position integers i,i². The architecture is the four-block width-128, eight-head graph of the linked candidate; the first three blocks are the zero-extended fixed-parameter causal count graph, with one additional uniform BOS-marker head in block 3. Each attention row uses the ordinary exact causal support j≤i. Model weights do not depend on N.

Relative positional copy scores in block 1 and context-anchor scores in block 3 are exact integers, using scaled dot-product cancellation exactly as in the graph. First-block raw scores are O(L³); their sign, row maximum and score differences fit in O(log L) integer bits. Rounded first-block outputs are H-grid values. Rational FFN constants 1/4, 3/4, 1/2, 1 and 2 and all gate arithmetic are exact on that grid with enough integer range.

2. An arbitrary-dyadic exponential primitive

For a nonnegative H-grid gap d=X/H, X∈ℕ, compute an H-grid weight E(X) as follows:

if X > bH: return 0
Z ← F−X                         # F-scale base 1−d/H
repeat b times: Z ← floor(Z²/F) # approximates (1−d/H)^H
return floor(HZ/F)              # H-scale weight

All Z remain in [0,F] because H≥2b. At X=0 every operation is exact and E(0)=H. For X≤bH, put a=1−d/H. The bounds −d−d²/(H−d)≤H ln a≤−d imply |a^H−e^(−d)|≤2b²/H. Each F-grid squaring adds <1/F and doubles previous error, so after b squarings the accumulated error is <H/F=1/H; final conversion to H-grid adds <1/H. If X>bH, truncation gives e^(−d)<e^(−b)<2^(−b)=1/H. Therefore, for all X≥0,

|E(X)/H−e^(−X/H)| ≤ ε_w=(2b²+2)/H.

This routine uses no transcendental library call or approximate input to the squaring primitive.

3. Paid position feature ln j

Generate one source-independent H-grid approximation λ_j for every 1≤j≤L, not log of any data-dependent probability. Set k=⌊log₂j⌋ and t=(j−2^k)/(j+2^k)∈[0,1/3]. The identity

ln j = k ln 2 + 2Σ_(n≥0) t^(2n+1)/(2n+1),
ln 2 = 2Σ_(n≥0) (1/3)^(2n+1)/(2n+1)

allows all work to be integer fixed-point. For either rational t, set T=⌊Ft⌋, Q₀=F; compute Q_n=⌊Q_(n−1)T/F⌋ for n=1,…,2K−1, and S(t)=2Σ_(n=0)^(K−1) ⌊Q_(2n+1)/(2n+1)⌋. These are F-scale integers. The recurrence gives |Q_n/F−t^n|≤2n/F; summing with denominators and the individual floors gives at most 6K/F error, while the tail is at most 3·9^(−K). Compute kS(1/3)+S(t) exactly at scale F and round to the nearest H-grid point; ties use a fixed deterministic rule. For s≥2,

(s+1)[6K/F+3·9^(−K)] < 1/(2H),    so  |λ_j−ln j| < 1/H.

For example, K≤33s, 24(s+1)K<H and 12(s+1)<H² suffice to verify this inequality. All terms are nonnegative, so λ_j≥0; and λ_j≤ln L+1/H≤s+1. In particular λ₁=0. Exact rational t is used only through integer divisions such as ⌊F(j−2^k)/(j+2^k)⌋. No source information or length-dependent learned position table is used.

4. First three blocks and the length marker

For each causal row, subtract its exact maximum and apply E(X) to each nonnegative score gap. Sum integer weights exactly; at least one weight equals H. For values in [0,1], comparison of numerator and denominator shows that normalizing the approximate weights changes an output by at most 2Lε_w. Floor the final weighted value to the H-grid, adding <1/H. Since 2b²+2≤2^(16s),

2Lε_w+1/H ≤ 3L^(−7),   L≥4.

The exact-real lag-copy leakage is at most 2/(e⁴−1)<2/15 at each position where the copied bit is needed. The extra numerical error is at most 3/4⁷<1/15. The total <1/5 stays strictly inside the 1/4 snap margin. Therefore the fixed ReLU gates recover exactly the predecessor bits at all valid candidate positions and the terminal query; invalid positions have g=0. The two BOS flags remain exact. In block 3 all anchor scores are consequently the same exact integers as in the real construction, and its terminal selector is exactly one-hot. Let p̃∈[0,1] be the H-grid selected head. Its pathwise error relative to B_N satisfies

|p̃−B_N| ≤ (N/2)e^(−N)+3L^(−7).

The added BOS-marker head has all scores 0, E(0)=H, one marker value 1 and L−1 values 0. Exact normalized integer division and flooring yield z̃=⌊H/L⌋/H, so 0≤1/L−z̃<1/H. It is computed in block 3, before either block-4 query uses it. The N=2 boundary has L=4 and no valid triples; all the same statements apply with B_N=1/2.

5. Fourth-block Gaussian heads and final softmax

At the actual terminal position use the exact H-grid p̃,z̃. Each of the two head scores 2p̃j−z̃j² or 2(1−p̃)j−z̃j² is a dyadic number with denominator H and numerator computable by exact integer multiplication and addition; the raw magnitude is O(L²), requiring O(log L) integer bits in addition to b fractional bits. Row maxima and differences are exact H-grid values, so E(X) applies directly. Relative to an ideal Gaussian head at the same p̃ and exact z=1/L, every score error is ≤L²/H. The exact-softmax weight perturbation is therefore ≤L²/(2H) in conventional TV by Cohen–Fausti Theorem 5.1, with its full-ℓ1 norm divided by two. Numerical normalized weights differ from exact softmax at the dyadic scores by at most 2Lε_w in the conservative scalar expectation bound. λ_j has error <1/H and range [0,s+1]; floor the weighted output to H-grid, adding <1/H. Each produced logit Ã,B̃ therefore differs from its ideal logarithmic Gaussian counterpart by at most

E_h = { (s+1)[L²/2+2L(2b²+2)] + 2 }/H.

The ideal final two-class softmax changes by at most E_h/2 when both logits move by E_h. To evaluate the numerical binary softmax, compare the two H-grid logits, apply E(X) to their nonnegative H-grid gap, form the appropriate integer ratio and floor it to the H-grid. Its additional probability error is at most 2ε_w+1/H; output the exact complement for the other class. No log(p̃) or explicit source-dependent preprocessing is used.

The uniform Gaussian bound applies to every p̃∈[0,1], including endpoints; no Lipschitz estimate in p̃ is needed. Combining all errors gives, for every input word and every N≥2,

|P̃_N−B_N| ≤ (N/2)e^(−N) + 168/√L + 3L^(−7)
                  + E_h/2 + 2ε_w + 1/H.

All numerical terms other than 168/√L decay faster than N−1/2. The result is a wordwise bound. Using the separately inherited R011 add-one theorem for N≥3, and TV≤1 for N=2, it yields uniform actual-terminal average risk O(N−1/2) over all homogeneous binary order-two tables and all initial pair laws. It does not imply a per-source conditional rate without the additional assumptions of that statistical theorem.

6. Complete resources and numerical scope

  • Position table: i and i² use O(log L) integer bits, λ_i uses O(log L) fractional bits and O(log log L) integer bits. Storing all three costs O(L log L) bits. The log routine uses K=O(log L) fixed-point recurrences and O(log L)-bit arithmetic per position; no exact irrational is stored. The generation work is included below.
  • Intermediate widths: H-grid activations and positional/logit magnitudes have O(b+log L)=O(log L) bits. F-grid variables have O(b) bits; squaring produces at most O(4b) bits before exact division. Summing at most L weights/weighted values requires O(b+log L) bits. Signed Gaussian scores have O(b+2log L) bits. No fixed-word range is assumed.
  • Bit operations: schoolbook multiplication and division on O(b)-bit integers cost O(b²). Each arbitrary-gap exponential uses b squarings, O(b³); a full dense causal evaluation has O(L²) score/value visits over a fixed number of heads, giving O(L²b³). The log-feature generator adds O(Lb³), included in O(L² log³ L). Computing only the final fourth-block row is allowed as a separate optimization, not required by this bound.
  • Working storage: O(Lb+b²)=O(L log L+log² L) bits suffice by storing constant-width residuals and positions, generating or retaining the log table, and streaming attention rows after an exact maximum pass. Dense L² score storage is not assumed.
  • Masks and final output: causal support j≤i is exact, max-shift is performed on exact integer/dyadic scores, and gaps >b are deliberately truncated with their error included. The last operation is a numerical two-logit softmax, not a direct probability readout. This specialized fixed-point scheme is not a proof about conventional IEEE operations, fixed precision, training convergence or general architectures.

7. Provenance and claim boundaries

The construction builds on the three-block candidate and the integer backend, adapting the latter’s repeated-squaring technique to arbitrary dyadic gaps. The fixed-parameter vocabulary graph and the 168/√L lemma are in the two linked companions at the top. Statistical uniformity uses inherited R011; prior-art and corrected N=2 caveats are in the boundary/prior addendum. Fingerprints and reviews must accompany an external package.
