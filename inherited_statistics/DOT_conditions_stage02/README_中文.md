# 数据条件与二阶预测难度 阶段二阅读指南

## 当前问题

同一条二阶轨迹的实际末行预测中，初始化、混合、共享行与有限 reset 条件怎样改变平均 TV 的最优难度，以及原完整历史 add-one 是否跟着改善。

## 结论及证据状态

已接纳的九个审查工作单元 S001–S009 给出：

- 真正平稳初始化的 minimax 阶是 `a=min{1,sqrt(K³/(M+1))}`；原逐 context add-one 达到该阶，允许零边、可约、周期与非唯一平稳律。
- 初始律距某个平稳律的 TV 不超过 η 时，匹配阶是 `max{a,η b_gen}`，其中 `b_gen=min{1,sqrt(K⁵/(M+1))}`。原规则仍达到该阶，η≤1/K 时所有 horizon 都保留平稳阶。
- 任意初始律下，suffix 与原完整历史规则有不同的有限混合界；原规则的界有独立的原计数/原 stack 证明，不能从 suffix 风险直接移植。
- 两步完全 reset 强制所有转移行相同，最优阶下降到 `b_iid=min{1,sqrt(K/(M+1))}`，由 pooled 算法达到；原规则存在同目标常数风险反例序列，故并不统一最优。
- 平稳近 IID 的公开半径 ρ，以及平稳全 pair 两步 minorization β，分别有统一匹配阶 `F(ρ)` 与 `F(1−β)`，`F(z)=max{b_iid,min{z,a}}`。选择器只比较公开上界，不读未知共同中心或源半径。
- **三步完全 reset 与两步有真实结构分界。** 三步类即使允许任意初始化仍有完整 K³ 难度，`a/100000 ≤ R₃ ≤ R₃⁺ ≤ min{1,80sqrt(K³/(M+1))}`。原规则达到该阶；合法下界族真正平稳初始化，且 K≥6 时满足 P³=Π 但 P²≠Π。

- **只加定性正性不改善任何固定算法的最坏风险。** 对每个有限 K,M 和每个共同随机算法，合法符号转移严格正的子类与完整类的风险 supremum 精确相等；任意初始化和平稳初始化分别成立。minimax 与原 add-one 的风险因此都不变。这是标准有限实验连续性推论，不延伸为 TV-close 初始化类的已证等式。

- **存在某个有限全 pair 精确 reset 即足够。** S009 从 `A=P−Π` 的幂零性和完整核链推出统一 reset 指数不超过 K²（派生结论，不是已知源信息）。任意初始化下 `a/100000 ≤ R_fin ≤ R_fin⁺ ≤ min{1,68sqrt(K³/(M+1))}`，原规则仍使用全部观察。该项是标准有限维及已接纳统计定理的推论，不是一般核分类或近似混合锐界。

以上均有完整证明与独立上下文 LLM 数学审查；不是形式验证。数值常数未优化，不作文献首创声称。正文中的“精确过渡”是带截断、常数统一的匹配率函数，不是精确 minimax 数值。

## 数据条件 允许信息 风险

整数 K≥2、M≥1；每条轨迹内源 θ 固定，pair 转移仅 `(a,b)→(b,c)`。观察完整 `X₁,…,X_{M+2}`，预测尚未观察的 `X_{M+3}`，目标始终是实际末对 `Y_M` 的行 θ_{Y_M}。风险为 `E TV(A(H),θ_{Y_M})`，TV 是半 L1。

共同算法可用完整历史、K、M、明确公开的类参数及源独立种子；不读隐藏 θ、μ、π、未知共同中心、混合标签或未来。源可随固定 K,M 的 supremum 改变，但轨迹内不改源。平稳与任意初始化的范围逐定理写明。

## 相比直接先例的新内容

HJW 高阶定理覆盖平稳二阶 actual prediction，但为 forward KL 与 suffix-mixture 算法；其直接 Pinsker 推论有平方根对数因子。不能反转 KL 下界，不能把 E[TV²] 当作 E[TV]，不能把 suffix-mixture 结论归给原 add-one。本阶段无对数实际平均 TV、初始化匹配过渡、同目标算法分离和精确 reset 结构边界按各自已证范围陈述；标准工具与继承推论均明确归属，不作优先权判断。

## 不能使用的推断与未证明范围

- 平稳不等于混合；混合不是平稳保证或固定 K 一致预测的必要条件。
- 全 pair q=1 minorization 类为空；两步 β=1 端点不能套用固定 β<1 的 K³ 下界。
- 共享行的更低最优率不保证原逐 context 规则自动最优。
- pooled 鞅引理允许任意初始化，不意味着平稳 F 匹配定理也允许任意初始化。
- 不用独立 query、固定行、随机时间、TV² 或预测 KL 偷换目标。
- 不宣称原 IID 规则全 K,M 风险匹配式、一般近似 reset 的锐参数率、网络实现或资源最优。
