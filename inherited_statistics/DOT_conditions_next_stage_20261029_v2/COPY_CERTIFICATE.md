# 科学复制证书与证据边界

本包的 COPY_MAP.json 对每份完整原件做零基半开字节区间分割：复制区间加省略区间恰覆盖原件；复制输出区间加明确编排区间恰覆盖输出，没有重叠或缺口。复制区间同时记录源／目标偏移、首末触及行（从一计、末行包含）和 SHA-256；复制正文拼接另有摘要。完整原件身份和科学副本身份分别保存，不能混用。

保留全部新数学论证、反例和相应科学审查推理；省略身份控制、私有执行定位、旧提交状态、管理性哈希表和运行日志。科学版本、直接依赖和历史判断在 SOURCES.md 及各副本明确说明；原件完全不改。删略的原文管理区间只记录位置与哈希，不公开其内容。英文原编号及原件行号可能跳跃，按命名章节与公式定位。

S021 v1 的合法局部反例及完整五单元科学审查为 v2 复核所需，科学上原样保留；其原错误不因 v2 通过而追认。CORRECTION_S021.md 是标明转述的自足中文更正，不是新独立证明；v2 全文保留修复后的四条件假设。S020 的开发期旧证书比较错误也保留准确更正，但不附执行日志。

一个既有 v2 科学归档逐字节复制，记录源与目标相同大小／哈希及其清单身份；所有嵌套清单、文件库存、安全路径和 CRC 可递归核验。先前归档保持历史原貌，不能将历史阶段结论误作本轮结束。

运行 `python3 verify_copies.py` 可核对当前公开库存、清单、输出区间、原件分割结构及全部嵌套归档。没有给出原件时，它只验证交付内部一致性，不声称比过原件。持有原件时加 `--sources /path/to/provided-originals`，才会按名称与全文哈希匹配原件，逐段比较实际字节和行号。脚本只读、仅 Python 标准库、不联网；沿用先前已审的同字节版本，没有新增平台。

清单不列其自身，其余公开文件必须精确等于清单条目。目录树不允许任何 symlink，ZIP 不允许重复名、绝对路径、上跳路径或 symlink。哈希不证明数学、不认证自改过的清单，也不防御恶意并发文件修改。
