本阶段交付三个不同性质的科学结果：

1. **S020**：原完整历史 add-one 的稀有事件加权上界。N1 对全部 K≥2、M≥1、0<β<1 有效；N2 仅在明确的中等对数域 D1。K⁶ 射线上消去旧证书的平方根对数损失，但没有风险匹配；K⁵ 指定窗口仍未闭合。
