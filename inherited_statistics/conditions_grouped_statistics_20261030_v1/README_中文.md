## 当前结论
同一个不读取 beta 的固定选择器，在全部整数 K>=2、M>=1 及 beta∈[0,1] 上，风险不超过真实公共 beta minimax 风险的 `2^33 sqrt(log(eK))` 倍。因此 `1 <= Gamma_all <= 2^33 sqrt(log(eK))`。这不是匹配的适应代价，不证明对数必要，也不排除常数适应。
