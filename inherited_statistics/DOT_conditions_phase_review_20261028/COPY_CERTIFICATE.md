# 精确科学复制说明

本说明为编排新增。当前八份科学副本覆盖 S016–S019 四个实际接纳工作单元，保留全部 19 个局部证明及对应独立审查科学推理；旧原件不修改。原数学审查是历史已有审查，不冒称本次新执行。本证书和脚本只证明字节、来源与闭包一致性，不认证数学。

## 区间规则

COPY_MAP.json 使用 UTF-8 零起点左闭右开字节区间 [start,end)。辅助行号为一基 inclusive touched lines，末行按 end−1 字节计算；半行同样计入。主要依据是字节而不是排版行号。

每个原件由 spans 与 omitted_source_spans 完整无重叠分割；每个副本由 spans 与 editorial_output_spans 完整无重叠分割。每个来源全文、目标全文、复制片段、拼接复制正文、删略区间和新增区间均单独哈希绑定。删略文字只披露区间和哈希，不公开私有管理内容。

删除仅限身份、私有路径／控制记录、行政哈希表／纯身份核对项、读写记录、提交时 pending 状态和已完整保留的重复框架。所有承重条件、量词、常数、cap、边界、科学检查数字与限定保留。跨段空行、中文标题、时序／证据说明与行号导航都明确标为新增，不伪装成原文字节。

## 可复核与公开范围

`python3 verify_copies.py` 只检查交付内部的完整分割、字节和嵌套清单；`--sources /path/to/provided-originals` 才额外比较确切原件区间和所有 touched-line 注释。没有原件时不能把前者称作原件比较。脚本只读、不联网、不写文件，也不验证数学。

公开集合严格为 SHA256SUMS.txt 条目加清单自身；原件／日志／控制／失败／构建／审计快照不在公开集合。完整冻结快照与新装配审计记录另外保留，不能用原数学接纳替代它们。清单不自含其哈希；最终冻结身份由独立审计和交付绑定。
