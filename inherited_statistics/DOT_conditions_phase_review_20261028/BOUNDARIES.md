# 科学条件 记号和算法边界索引

本索引是新增编排，不替代被引用定理。所有风险为完整 `N=M+2` 符号历史、固定整数 `K≥2,M≥1`、实际末行 `θ_{Y_M}` 的无条件期望 `TV=½L1`。`n=M+1` 是率分母；算法均源盲并可有独立种子。

## 统一记号

- 字母表 A={0,…,K−1}；Π(s,t)=π(t) 表示每行同为 π 的核。
- `g=min(1,sqrt(K⁵/n))`：一般任意初始化基线。
- `a=min(1,sqrt(K³/n))`：平稳二阶基线。
- `i=min(1,sqrt(K/n))`：IID 基线。
- `η∈[0,1]`：初始 pair 律至某隐藏平稳律的 TV 上界，不是谱隙或密度比。
- 近 IID 页的 `ρ∈[0,1]` 是所有行至某共同中心的半径；固定射线页的 `ρ∈(3,4]` 是 horizon 指数。二者是不同角色，不能混用。
- `β` 是全状态两步 minorization 的公开下界；`δ=1-β`。
- 平稳邻域 `F(z)=max(i,min(z,a))`；S016 的 `F=F(δ)`。
- `h*=min(1,sqrt(K⁴/n))`，`D=δⁿg`，`T=δ^(M/2)h*` 是 S016 下界项。
- `h_b=δ^floor(b/2)` 在 β<1 时定义；β=1 时 b<2 取 1、b≥2 取 0，避免 0^0。
- S019 的 `v=δ^(M/2)`、`H=max(a,v)` 是率函数；这里 H 不是数据历史。星形精确计数 `H_M`、burn 因子 `h_b` 也不是 H 或 h*。
- `R_C=inf_A sup_C L_A` 是共同 minimax；`R_C^+=sup_C L_(p+)` 是一个固定规则的最坏风险。`R_C≤R_C^+` 不可反向使用。

## 算法不得互换

1. ORIGINAL：在实际末对 s 上，用全部 M departures 的 `(C_s(c)+1)/(n_s+K)`。S001/S003/S007/S009/S018/S019 明确给它上界。
2. SUFFIX：只计确定 burn 后的 departures，仍预测同一个 Y_M；S011 的 `U_suf` 专属它，不是原计数规则的上界。公开优化 b 不读隐藏源风险。
3. POOLING：跨上下文汇总 X₃,…,X_(M+2)。S005 使用 pooled add-one；S006/S011 使用 empirical pooling。两者不是原行式 add-one。
4. S011 公共选择器：比较 U_+、U_suf、U_pool；原规则、suffix、pooling 有固定公共平手顺序。优化 U_+ 中的分析 burn 不改变原规则；优化 U_suf 则真的改变所计数据。
5. S018 pair-split 标签与 S019 ε=1/K 只用于分析，不是算法输入或数据增强。canonical 单符号刷新不等于 pair 重置。

## 样本与域边界

g、a、i 的阶量分别给 K⁵、K³、K 乘目标误差平方倒数的预算尺度，必须使用 cap 和定理常数。η≤目标尺度时 ηg 自动满足，不能强行引入 η²K⁵ 项。

S019 只在原域内：对 0<τ<1、0<β≤1/2，`H≤τ` 等价于 `n≥K³/τ²` 且 `M ln(1/δ)≥2ln(1/τ)`。β=0 时 H=1。此 iff 是 H 的代数，不是 `R≤τ` 的精确充要判据；风险上下常数需缩放阈值。精确 δ 指数不能被全域统一换成 exp(-βM/2)。

未将 S019 的原规则 H 公式外推至 M>K⁴ 或 β>1/2；S011 仍给所有 β≥1/2 的共同 minimax F 匹配及其其他已匹配域。未宣称完整联合率、一般 q 近似混合锐率、未知参数适应、邻域交集、η 类的正性等式、IID 原规则全参数风险或硬件／网络／codec／故障扩展。已有全路径实现接口仅可继承引用，未在此导出新资源结论。

当前选定的条件层比较、算法区别及必要临界续题已形成完整科学阶段；较长历史弱混合可另立有界合同，不是本阶段未完成的数学前提。这不表示全部有价值研究穷尽或调度已暂停。
