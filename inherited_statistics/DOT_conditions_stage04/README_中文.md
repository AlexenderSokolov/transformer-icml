# 首次符号刷新障碍与对数弱混合窗口的匹配结果

## 当前结论

本阶段只有 **S014、S015 两个已接纳工作单元**，共 18 个局部证明单元，不把工作单元数当作定理数。S015 已证明在

`M=K⁴，β=ln(K)/(4K⁴)，整数 K→∞`

时，公共算法的全类 minimax 风险是 **Θ(K⁻¹⁄⁸)**。这明确更新所附 Stage03 早期审查归档中“该对数窗口仍开放”的历史叙述；旧归档和原证明字节不改写。Stage03 此前未单独交付；它内含的 Stage02 ZIP 才是已交付的更早阶段包。

## 数据条件与允许信息

源是固定齐次二阶表，只作合法 `(a,b)→(b,c)` shift；初始 pair 任意。隐藏平稳律 π 满足对所有起点、终点的 `P²(s,t)≥βπ(t)`，允许零边、稀疏 π 和与 π 奇异的初始律。算法保留全部 `M+2` 符号，使用公开 `K,M,β` 和独立随机种子；目标仍为同轨迹实际末行，损失为期望半 L1 TV。不给算法源表、π、潜在刷新标签或未来。

## 两个结果及先后关系

- **S014：真正的统计障碍。** 一次平稳符号刷新、或仅使第二初始符号有平稳边缘，均不足以保证统一的 `O(a+√β)` 预测风险。完整前缀没有被丢弃。即时刷新条件下的下界转成无条件贡献时必须乘事件概率 β。原 add-one 的无刷新贡献上界仍成立。这个发射族没有否定 aggregate 提议：B₀ 的 weighted-family 上界覆盖全族，而 total-scale 比较只在其对齐序列、`g_M=1` 时成立。
- **S015：不同星形族解决了上述更强问题。** 安全的零输出相位允许刷新而不改变任何硬观察；只需脆弱相位的币为零。精确计数 H_M 给出有限下界 `δ^(H_M+1)α/8`，其中 `δ=1−β`。新下界与原有公开后缀选择器上界匹配，闭合指定窗口；同一族还否定明确的 aggregate 上界 `C(a+√β)` 和总风险上界 `O(a+δ^M g+√β)`。这不是撤销 S014，也不是否定所有上界方法。

这里 `a=min(1,√(K³/(M+1)))`、`g=min(1,√(K⁵/(M+1)))`。刷新 aggregate 是无条件的指示函数加权风险，不能擅自除去事件概率。

## 证据与剩余缺口

两个原版本都经独立上下文 LLM 数学审查并获接纳；这不是形式验证、外部同行评审或文献首创认证。有限检查保留原事实与数量，本次编排没有重跑或升级它们。下界常数与上界常数不同，未声称精确 minimax 极限常数。

**完整联合 `(K,M,β)` 率，以及新窗口中原始全历史 add-one 的匹配上界，仍未证明。** 原 add-one 的既有证书此处最终等于 1，不意味着其真实风险等于 1。后续科学问题应继续区分算法与源族，不能再用已否定的两个提议作为目标结论。
